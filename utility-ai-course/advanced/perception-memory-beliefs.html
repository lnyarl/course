지각·기억과 불확실한 정보

선수 장 · 기존 1장 · Sense–Think–Act

Hamlet의 consideration은 세계 객체를 직접 읽습니다. 늑대가 벽 뒤로 갔는데도 정확한 좌표를 계속 안다면 주민은 실제 지각이 아니라 전지적인 정보를 쓰는 셈입니다. 세계의 사실과 주민이 마지막으로 관측한 내용을 분리하고, 기억이 오래될 때 점수를 어떻게 바꿀지 설계합니다.

세계 상태와 관측 사실을 서로 다른 자료로 두기

지각 레코드는 대상 ID, 마지막 관측 위치, 관측 tick, 관측 종류, 신뢰도, 현재 관측 가능 여부를 담습니다. consideration은 world.threat의 현재 좌표 대신 agent.beliefs를 읽습니다. 가림·시야·소리 같은 sensor가 새 레코드를 만들고, 관측하지 못한 정보는 조용히 최신 세계 값으로 바꾸지 않습니다. 상태가 없다는 것과 안전하다는 관측은 서로 다릅니다.

예를 들어 마지막 관측 이후 Δt초의 신뢰도를 c=exp(-Δt/4)로 낮추고, 기본 위협 점수 0.8에 곱하는 교육용 정책을 정합니다. Δt=0이면 0.8, Δt=4이면 약 0.294입니다. 이 식은 통계적으로 보정한 확률이 아니라 이 단원에서 선택한 게임 설계값입니다. 실제 확률처럼 사용하려면 관측 데이터와 보정 검사가 따로 필요합니다.

정보 노후화와 재관측 행동 연결하기

최대 기억 나이 5초를 넘기면 Unknown으로 두는 정책을 비교합니다. Unknown을 곧바로 위협 점수 0의 안전 상태와 합치면 모퉁이 뒤 늑대를 잊자마자 같은 길로 되돌아갈 수 있습니다. 조사·우회·보수적 대기 같은 행동을 후보로 남길지 정하고, 생존에 필수인 강제 조건과 부드러운 효용 점수를 구분하세요.

센서가 갱신될 때만 재평가하면 불필요한 계산을 줄일 수 있지만 시간 경과에 따른 신뢰도 감소도 갱신 사건입니다. 인스펙터에는 실제 위치와 belief 위치, 마지막 관측 시각, 점수에 사용한 신뢰도를 나란히 표시합니다. Unreal AI Perception의 stimulus age·Max Age 같은 개념은 관측 수명을 분리하는 참고 사례이며 현재 uai.js에 해당 시스템이 구현된 것은 아닙니다.

실습과 예상 관찰

늑대를 마지막으로 본 시각이 0초이고 기본 점수가 0.8이라고 둡니다. 0·4·6초의 결과를 먼저 예측한 뒤 조건을 선택하세요. 확장 실습에서는 벽을 둔 작은 지도 사본에서 sensor 입력을 고정하고, consideration이 숨은 실제 좌표를 읽지 않는지 로그로 검사합니다.

방금 관측, Δt=0

신뢰도 1, 위협 점수 0.8입니다. 현재 관측 정보와 판단 입력이 일치합니다.

실습의 경계와 다음 장

신뢰도 식과 기억 상한은 명시한 교육용 정책입니다. 실제 시야 raycast·Bayesian 추정·Unreal 센서를 브라우저에서 실행한 결과가 아닙니다. 현재 Hamlet은 세계를 직접 읽는 구조를 유지합니다. 다음에는 8장의 context에 belief를 넣었을 때 대상 순위가 어떻게 달라지는지 비교하세요.
