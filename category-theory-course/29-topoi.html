1. 부분객체는 포함 사상의 동치류

Set의 부분집합 S⊆X를 주입 m:S↪X로 표현할 수 있습니다. 같은 부분집합을 다른 이름의 집합 S′로 표시할 수 있으므로 정의역의 동형 h:S≅S′와 m=m′h를 만족하는 모노사상들을 같은 부분객체로 봅니다. 일반 범주에서는 단사 함수 대신 모노사상을 사용합니다.

m:S→X가 모노라는 뜻은 임의의 g,h:Y→S에 대해 mg=mh이면 g=h라는 소거 조건입니다. 원소를 합치지 않는다는 직관은 Set에서 맞지만 일반 범주에서는 이 사상 조건이 정의입니다. 공역 X를 고정한 부분객체들의 동치류를 Sub(X)라 씁니다.

실험 1 · Set의 특성 함수

X={0,1,2}. 선택한 부분집합과 Ω로 가는 함수, true의 역상을 계산합니다.

2. 부분객체 분류자의 당김 보편성

부분객체 분류자는 객체 Ω와 true:1→Ω입니다. 모든 모노사상 m:S↪X에 유일한 χ_m:X→Ω가 있어 S→1, m:S→X, true:1→Ω, χ_m:X→Ω의 사각형이 당김이 되어야 합니다. 사각형의 가환만으로는 부족하며 당김의 보편 성질까지 요구합니다.

Set에서는 Ω={false,true}이고 χ_m(x)는 x가 S에 속하는지입니다. S는 χ_m의 true에 대한 역상입니다. 임의의 Y와 g:Y→X가 χ_m g=true !를 만족하면 유일한 h:Y→S가 m h=g를 만족합니다. 모든 g(y)가 S 안에 있으므로 포함 사상 뒤의 h 값이 강제로 정해지는 것이 유일성의 이유입니다.

3. 토포스의 세 조건

이 장의 초등 토포스(elementary topos)는 유한 극한을 갖고, 카르테시안 닫혀 있으며, 부분객체 분류자를 갖는 범주입니다. 유한 극한에는 말단 객체와 당김 등이 포함됩니다. 카르테시안 닫힘은 모든 A,B에 지수 객체 B^A가 있어 Hom(X×A,B)≅Hom(X,B^A)인 것입니다.

Ω 하나와 Bool을 흉내 낸 타입 하나가 있다고 곧 토포스가 되는 것은 아닙니다. Set과 유한 집합 범주 FinSet은 이 조건을 만족합니다. 일반 토포스에서 Ω는 반드시 두 원소 집합처럼 행동하지 않으며, Set의 원소 수준 추론을 그대로 옮기려면 조건을 확인해야 합니다.

실험 2 · 부분객체를 입력 앞으로 당기기

X={0,1}, Y={y0,y1,y2}. 선택한 g와 S에 따라 g⁻¹S 및 χ∘g를 계산합니다.

4. 입력 변환에 따른 조건의 당김

g:Y→X와 부분집합 S⊆X가 주어지면 당김 부분집합은 g⁻¹S={y | g(y)∈S}입니다. 그 특성 함수는 χ_S∘g:Y→Ω입니다. 데이터베이스의 필터를 입력 변환 앞쪽으로 옮기는 구체적인 패턴과 닮았지만 범주 정의는 함수의 실행 비용과 무관합니다.

두 번째 위젯은 Y={y0,y1,y2}, X={0,1}와 g=(0,1,1) 또는 (1,0,1)을 씁니다. 부분집합을 바꾸면 선택되는 Y 원소와 특성 함수 합성 결과가 동시에 바뀝니다. 당김의 원소는 y와 대응하는 S 원소를 묶은 쌍이며, 주어진 g(y) 때문에 그 두 번째 성분은 유일합니다.

5. 내부 논리는 일반적으로 직관주의적이다

토포스의 부분객체들은 Heyting 논리를 이루며 일반 토포스가 Boolean일 필요는 없습니다. 특히 p∨¬p=true라는 배중률이 자동으로 성립하지 않습니다. C# bool의 2값 논리를 일반 Ω의 완전한 구현이라고 할 수 없습니다.

세 번째 위젯은 세 원소 Heyting 사슬 0<u<1에서 ∧=min, ∨=max, p⇒q=(p≤q이면 1, 아니면 q)를 계산합니다. 이는 Sierpiński 공간의 열린집합 격자와 같고 그 위 층 토포스의 전역 진릿값을 설명하는 예입니다. 세 원소 사슬 범주 자체를 토포스라고 주장하지 않습니다. u의 부정은 0이고 u∨¬u=u이므로 배중률이 실패합니다. 실행 C# 프로그램은 Set의 특성 함수와 이 작은 논리 계산을 구분해서 보여 줍니다.

실험 3 · 세 값 Heyting 논리

0은 거짓, 1은 참, u는 중간 열린집합입니다. 함의·부정·배중률을 계산합니다.

6. 실행 가능한 전체 C#

C# 12 / .NET 8의 BCL만 사용하는 전체 Program.cs입니다. examples/Ch29/Program.cs에 같은 프로그램이 있습니다. 웹 위젯은 같은 수학 규칙의 JavaScript 계산이며 C# 실행기가 아닙니다.

using System;
using System.Linq;
int[] x = [0, 1, 2];
bool Chi(int n) => n >= 1;
Console.WriteLine($"subset = {string.Join(",", x.Where(Chi))}");
int[] g = [0, 1, 1];
Console.WriteLine($"pullback indices = {string.Join(",", Enumerable.Range(0, 3).Where(y => Chi(g[y])))}");
static int Implies(int p, int q) => p <= q ? 2 : q;
int u = 1, neg = Implies(u, 0);
Console.WriteLine($"u OR not u = {Math.Max(u, neg)} (top=2)");

기대 표준 출력:

subset = 1,2
pullback indices = 1,2
u OR not u = 1 (top=2)

8. 직접 구현하는 실습

실습 A · 부분집합의 유일 분류

X={0,1,2}의 8개 부분집합과 8개 Bool 함수 표가 일대일 대응하는지 열거하세요.

기대 결과:

characteristic tables = 8
힌트

각 마스크의 세 비트가 특성 함수 값입니다.

해답 · 별도 Program.cs로 실행하는 전체 프로그램
using System;
using System.Linq;
var tables = Enumerable.Range(0, 8).Select(mask => string.Concat(Enumerable.Range(0, 3).Select(i => (mask >> i) & 1))).Distinct().Count();
Console.WriteLine($"characteristic tables = {tables}");

Set에서 부분집합은 각 원소의 소속 여부로 정확히 결정됩니다.

실습 B · Heyting 부정

세 원소 사슬의 모든 p에서 p∨¬p를 출력하세요. 아래 코드는 진릿값 0, u, 1을 정수 0, 1, 2로 인코딩합니다. 따라서 출력의 정수 1은 중간값 u, 정수 2는 최상위 참을 뜻합니다.

기대 결과:

0: 2
1: 1
2: 2
힌트

¬p는 p⇒0이고 join은 max입니다.

해답 · 별도 Program.cs로 실행하는 전체 프로그램
using System;
static int Imp(int p, int q) => p <= q ? 2 : q;
for (int p = 0; p < 3; p++) Console.WriteLine($"{p}: {Math.Max(p, Imp(p, 0))}");

중간 진릿값 1에서 결과가 최상위 2가 아닙니다. 이 계산은 C# bool의 진리표와 다른 Heyting 대수의 계산입니다.

핵심 요약
