엔드와 코엔드

여러 타입에서 고른 값들이 서로 호환되는지 검사하는 일과, 서로 다른 표현을 같은 것으로 합치는 일은 다릅니다. 엔드는 호환되는 가족을 고르고 코엔드는 관계로 표현을 몫집합화합니다.

1. 프로함자의 두 입력

이 장에서는 작은 범주 C와 Set 값 함자 H:Cᵒᵖ×C→Set을 사용합니다. 첫 인수는 반변, 둘째는 공변입니다. f:a→b가 있으면 H(id_a,f):H(a,a)→H(a,b), H(f,id_b):H(b,b)→H(a,b)라는 두 함수가 같은 공역으로 갑니다. 대각 원소 사이에 직접 화살표가 있다고 가정하지 않습니다.

일반 프로함자 P:Dᵒᵖ×C→Set은 두 범주를 연결합니다. 함수 프로함자 Hom의 dimap은 입력에 전합성하고 출력에 후합성합니다. 단순 관계가 참·거짓만 남기는 것과 달리 Set 값은 관계의 여러 증거도 보존합니다.

실험 1 · 자연변환으로 얻는 엔드

F(a)=F(b)=G(a)=G(b)={0,1}. F(f)는 상수 0, G(f)는 항등입니다. 성분 후보와 자연성 양쪽을 계산합니다.

2. 쐐기와 이자연성

쐐기(wedge)는 꼭짓점 E와 사영 π_a:E→H(a,a)의 가족이며 모든 f:a→b에 대해 H(id_a,f)∘π_a=H(f,id_b)∘π_b를 만족합니다. 두 경로가 H(a,b)에서 만납니다. 이 조건은 상수 프로함자에서 H로 가는 이자연변환의 특수 경우입니다.

일반 이자연변환 α:H⇒J는 대각 성분 α_a:H(a,a)→J(a,a)만 가지며, f:a→b에 대해 J(id_a,f) α_a H(f,id_a)=J(f,id_b) α_b H(id_b,f)입니다. 두 경로는 H(b,a)→J(a,b)입니다. 모든 (a,b)에 성분을 가지는 보통 자연변환과 같지 않고, 일반 이자연변환의 합성이 언제나 이자연이라는 가정도 피해야 합니다.

3. 엔드는 보편적인 쐐기

엔드 ∫_a H(a,a)는 쐐기 (E,π)로서 다른 모든 쐐기 (X,α)에 유일한 h:X→E를 주며 π_a∘h=α_a입니다. Set에서는 대각 집합들의 곱 ∏_a H(a,a)에서 모든 쐐기 방정식을 만족하는 가족만 고른 부분집합으로 만들 수 있습니다. 작은 C여야 이 곱을 보통 집합 수준에서 다룰 수 있습니다.

F,G:C→Set에 대해 H(a,b)=Set(Fa,Gb)를 두면 엔드가 Nat(F,G)가 됩니다. 쐐기 방정식은 Gf∘τ_a=τ_b∘Ff라는 자연성입니다. 첫 위젯은 두 객체와 화살표 하나인 유한 범주의 가능한 성분 함수를 모두 열거합니다. 유한 표본이라기보다 그 특정 작은 범주의 엔드 전체를 계산하는 예이며, 모든 범주의 자연변환을 계산하는 것은 아닙니다.

실험 2 · 대각 표현의 코엔드 몫

H의 네 집합은 {0,1}. H(f,id)는 항등이고 H(id,f)를 선택합니다. 생성 관계와 동치류를 계산합니다.

4. 코엔드는 보편적인 쌍대쐐기

코엔드 ∫^a H(a,a)는 주입 ι_a:H(a,a)→Q를 가지며 ι_a∘H(f,id_a)=ι_b∘H(id_b,f):H(b,a)→Q입니다. 다른 모든 호환 가족 j_a:H(a,a)→X가 유일한 h:Q→X를 통해 j_a=h∘ι_a로 인수분해되어야 합니다.

Set에서는 대각 집합들의 서로소 합을 만들고 (a,H(f,id_a)(x))∼(b,H(id_b,f)(x)) 관계가 생성하는 동치관계로 나눕니다. 원래 관계만 한 번 적용하는 것이 아니라 반사·대칭·추이 폐포까지 필요합니다. 두 번째 위젯은 H의 모든 네 집합을 {0,1}로 두고 한 인수의 화살표 작용을 항등 또는 뒤집기로 정한 예입니다.

5. 프로함자 합성과 C# 한계

원문의 방향 관례 P:Dᵒᵖ×C→Set을 C↛D로 읽습니다. Q:Eᵒᵖ×D→Set과 합성하면 (Q⊙P)(e,c)=∫^d Q(e,d)×P(d,c)입니다. 가운데 d의 표현을 코엔드 관계로 합칩니다. 가운데 범주가 이산이면 관계가 없으므로 단순한 서로소 합으로 줄어듭니다.

C#은 모든 타입에 대한 rank-N 다형 값을 직접 표현하지 않으며 제네릭 메서드가 있다는 것만으로 매개변수성이 보장되지 않습니다. 아래 프로그램은 특정 유한 범주의 함수 표를 검사합니다. 배열의 함수 동등성은 모든 입력의 출력으로 비교합니다. delegate 참조 동등성이나 모든 .NET 타입에 대한 엔드 구현이라고 설명하지 않습니다.

실험 3 · 이산 가운데 범주의 프로함자 합성

가운데 객체 d₀,d₁에는 항등만 있습니다. 각 경유 증거쌍은 별개이며 개수는 q₀p₀+q₁p₁입니다.

6. 실행 가능한 전체 C#

C# 12 / .NET 8의 BCL만 사용하는 전체 Program.cs입니다. examples/Ch26/Program.cs에 같은 프로그램이 있습니다. 웹 위젯은 같은 수학 규칙의 JavaScript 계산이며 C# 실행기가 아닙니다.

using System;
using System.Linq;
int count = 0;
for (int a = 0; a < 4; a++)
    for (int b = 0; b < 4; b++)
    {
        int[] ta = [a / 2, a % 2], tb = [b / 2, b % 2];
        if (Enumerable.Range(0, 2).All(x => ta[x] == tb[0]))
            count++;
    }
Console.WriteLine($"natural families = {count}");

기대 표준 출력:

natural families = 4

7. 확인 문제

쐐기 방정식의 두 경로가 만나는 곳은?
반변·공변 작용으로 두 대각 집합을 공통 공역 H(a,b)에 보냅니다.
엔드의 Set 구성이 하는 일은?
가족의 선택과 모든 화살표에 대한 방정식이 모두 필요합니다.
코엔드의 생성 관계에는 무엇을 더해야 하는가?
몫집합을 만들려면 반사·대칭·추이 조건을 만족해야 합니다.
가운데 범주가 이산일 때 합성은?
비항등 사상이 없으므로 추가 코엔드 식별 관계가 없습니다.

8. 직접 구현하는 실습

실습 A · 이산 엔드

두 대각 집합의 크기가 2,3이고 범주가 이산일 때 엔드의 모든 가족을 열거하세요.

기대 결과:

end size = 6
힌트

호환 조건이 없으므로 각 집합에서 하나씩 고릅니다.

해답 · 별도 Program.cs로 실행하는 전체 프로그램
using System;
int count = 0;
for (int a = 0; a < 2; a++) for (int b = 0; b < 3; b++) count++;
Console.WriteLine($"end size = {count}");

비항등 사상이 생기면 이 곱의 일부 가족이 제거될 수 있습니다.

실습 B · 코엔드 동치류

네 태그 a0,a1,b0,b1에서 a0~b1, a1~b0의 몫을 계산하세요.

기대 결과:

coend classes = 2
힌트

작은 union-find로 생성 관계를 합칩니다.

해답 · 별도 Program.cs로 실행하는 전체 프로그램
using System;
using System.Linq;
int[] p = [0, 1, 2, 3];
int Find(int x) { while (p[x] != x) x = p[x]; return x; }
void Union(int x, int y) => p[Find(x)] = Find(y);
Union(0, 3);
Union(1, 2);
Console.WriteLine($"coend classes = {Enumerable.Range(0, 4).Select(Find).Distinct().Count()}");

몫은 태그를 무조건 지우는 작업이 아니라 지정된 생성 관계에 따른 식별입니다.

핵심 요약

엔드는 호환되는 대각 가족의 보편적 객체이고 코엔드는 대각 표현을 관계로 식별하는 보편적 객체입니다. 자연성과 프로함자 합성이 각각 이 구성의 중요한 예입니다.
