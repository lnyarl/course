시작하기 전에 · C# 예제

C#의 제네릭, 람다, Func<A, B>를 읽을 수 있으면 시작할 수 있습니다. Haskell이나 범주론 선행 지식은 요구하지 않습니다. 수식은 의미와 타입을 함께 설명합니다.

예제는 C# 12와 .NET 8의 기본 라이브러리만 사용합니다. 웹 실습은 브라우저에서 실행되며 C#을 브라우저에서 컴파일하지는 않습니다. 같은 합성 규칙을 JavaScript로 구현한 모형입니다. 각 장의 전체 실행 프로그램은 C# 예제 안내에서 내려받아 별도로 실행하세요.

모델의 범위를 구분합니다타입을 집합, 함수를 순수 전함수로 보는 모델에서 시작합니다. 예외, 비종료, 공유 상태, I/O를 포함하는 모든 C# 프로그램이 이 모델에 들어가지는 않습니다. 위젯의 유한 표본 검사는 수학적 증명을 대신하지 않습니다.
