수반

튜플을 받는 함수와 인자를 하나씩 받는 함수는 같은 정보를 담습니다. 이 자연스러운 전단사를 일반화하면 수반이 되고, 단위와 쌍대단위가 그 왕복을 설명합니다.

1. 문제에서 출발하기

설정 s와 입력 a를 함께 받는 서비스 함수 f:(a,s)→b를, 설정을 나중에 주입하는 a→(s→b) API로 바꾸려 합니다. 결과 타입만 비슷한 것이 아니라 모든 함수 f를 손실 없이 왕복 변환하고 입력·출력 함수와도 일관되어야 합니다.

수반은 두 범주가 같다고 주장하지 않습니다. 한쪽 범주의 특정 Hom 집합과 다른 쪽 Hom 집합 사이의 자연스러운 전단사입니다. 자유 자료구조, 곱, 함수 객체, 모나드를 이 하나의 형식으로 연결할 수 있습니다.

2. 정의와 타입

이 장은 L:D→C, R:C→D라고 표기합니다. L⊣R이면 모든 d∈D,c∈C에 대해 φ_d,c:Hom_C(Ld,c)≅Hom_D(d,Rc)가 있고 d에 반변, c에 공변으로 자연스럽습니다. p:d′→d, q:c→c′와 f:Ld→c에 대해 φ(q∘f∘L(p))=R(q)∘φ(f)∘p입니다.

단위 η:Id_D⇒RL은 η_d:d→RLd이고 쌍대단위 ε:LR⇒Id_C는 ε_c:LRc→c입니다. φ(f)=R(f)∘η_d, φ⁻¹(g)=ε_c∘L(g)로 전단사를 복원합니다. 임의의 η,ε 두 개만 있다고 수반은 아닙니다. 자연성과 두 삼각 항등식이 필요합니다.

ε_Ld ∘ L(η_d)=id_Ld
R(ε_c) ∘ η_Rc=id_Rc
η_d=φ(id_Ld), ε_c=φ⁻¹(id_Rc)

3. 계산에서 일반 논증으로

Set에서 고정한 S에 대해 L(A)=A×S, R(B)=Hom(S,B)로 두면 φ(f)(a)(s)=f(a,s), φ⁻¹(g)(a,s)=g(a)(s)입니다. 두 식을 연속 대입하면 모든 a,s에서 원래 결과를 얻습니다. 이를 커링과 언커링이라 부릅니다.

단위는 η_A(a)(s)=(a,s), 쌍대단위는 ε_B(k,s)=k(s)입니다. 첫 삼각 항등식은 (a,s)를 (η_A(a),s)로 바꾼 뒤 평가하면 (a,s)가 된다는 뜻입니다. 둘째는 k:S→B를 s↦(k,s)로 넣고 평가를 map하면 s↦k(s)로 돌아온다는 뜻입니다. 양쪽 모두 함수의 입력별 동등성입니다.

곱이 모든 객체 쌍에 존재하는 범주에서는 대각함자 Δ:C→C×C가 곱 함자의 왼쪽 수반입니다. (C×C)(ΔX,(A,B))≅C(X,A×B)의 왼쪽은 공통 정의역을 가진 사상 두 개, 오른쪽은 그 둘을 묶은 유일한 사상입니다. 곱 범주의 객체 쌍과 C 안의 곱 객체를 구분해야 합니다.

4. 직접 조작하는 세 실험

1. Curry와 Uncurry 왕복

f(a,s)=a+s 또는 a×s에서 a를 고정합니다. s=3에서 원래 함수와 왕복 함수를 비교합니다.

2. 첫 삼각 항등식

(a,s)에 Lη를 적용한 뒤 ε로 평가합니다. s를 바꾸어도 원래 쌍을 복원합니다.

3. 자연성: 입력·출력 변경

p(a)=a+1로 입력을 바꾸고 q(b)=2b 또는 −b로 출력을 바꿉니다. f(a,s)=a+s, s=3입니다.

5. 실행 가능한 C#

아래는 C# 12 / .NET 8 전체 프로그램입니다. BCL만 사용하며 examples/Ch18에서 실행할 수 있습니다. JavaScript 실험은 이 계산을 시각화한 별도 모형입니다.

Func<(int, int), int> f = p => p.Item1 + p.Item2;
var curried = Curry(f);
var roundtrip = Uncurry(curried);
Console.WriteLine(curried(4)(3));
Console.WriteLine(roundtrip((4,3)));
Func<int, (int, int)> unit = s => (4,s);
var original = (Value: 4, State: 3);
// Lη_A(a,s) = (η_A(a),s), then ε evaluates the function.
var lifted = (Function: unit, State: original.State);
var triangle = lifted.Function(lifted.State);
Console.WriteLine($"{triangle.Item1},{triangle.Item2}");
static Func<A, Func<S,B>> Curry<A,S,B>(Func<(A,S),B> f)
    => a => s => f((a,s));
static Func<(A,S),B> Uncurry<A,S,B>(Func<A,Func<S,B>> g)
    => p => g(p.Item1)(p.Item2);

기대 표준 출력:

7
7
4,3

6. 모형의 경계

수반을 범주의 동형이나 동치와 혼동하면 안 됩니다. 단위와 쌍대단위는 일반적으로 역가능하지 않으며 서로 역함수인 것도 아닙니다. 서로 다른 범주의 서로 다른 타입을 갖습니다. 삼각 항등식은 L과 R의 왕복 중 특정 경로가 항등이라는 조건입니다.

C# 예제는 Set의 곱–지수 수반을 순수 전함수와 유효한 값에 제한해 나타냅니다. delegate의 ==는 함수의 외연적 동등성을 검사하지 않습니다. C#에는 모든 함수의 동등성을 결정하는 일반 알고리즘이 없으므로 작은 유한 입력 검사와 식에 의한 증명을 구분합니다.

7. 확인 문제

L:D→C, R:C→D일 때 단위의 타입은?
단위는 d를 RLd로 보냅니다.
곱–지수 수반의 왼쪽 수반은?
Hom(A×S,B)≅Hom(A,S→B)입니다.
η와 ε가 있으면 항상 수반인가요?
단위·쌍대단위 정의에는 일관성 법칙이 포함됩니다.
자연성은 어느 변수에 필요한가요?
Hom 전단사는 입력 d에 반변, 출력 c에 공변으로 자연스럽습니다.

8. 구현 실습

실습 A · 둘째 삼각 항등식

k(s)=s²에 η_RB 후 Rε를 적용한 함수와 k를 s=−2,0,3에서 비교하세요.

기대 출력:

4=4
0=0
9=9
힌트

η_RB(k)는 t↦(k,t)입니다. Rε는 각 쌍을 평가합니다.

해답 · 별도 Program.cs 전체
Func<int,int> k = s => s*s;
Func<int,(Func<int,int>,int)> eta = s => (k,s);
Func<int,int> result = s => { var p=eta(s); return p.Item1(p.Item2); };
foreach(int s in new[]{-2,0,3})
    Console.WriteLine($"{result(s)}={k(s)}");

이 유한 검사는 구현 검증이며 일반 등식은 ε(k,s)=k(s) 대입으로 증명합니다.

실습 B · 곱의 Hom 대응

p(x)=x+1, q(x)=2x를 묶고 두 사영으로 복원하세요.

기대 출력:

4,6
True
힌트

pair(x)=(p(x),q(x))로 만듭니다.

해답 · 별도 Program.cs 전체
Func<int,int> p=x=>x+1, q=x=>2*x;
Func<int,(int,int)> pair=x=>(p(x),q(x));
var v=pair(3);
Console.WriteLine($"{v.Item1},{v.Item2}");
Console.WriteLine(v.Item1==p(3) && v.Item2==q(3));

두 사영이 사상 쌍을 복원하며 튜플은 각 성분으로 결정되므로 대응이 전단사입니다.

9. 핵심 정리

  • 수반은 Hom_C(Ld,c)≅Hom_D(d,Rc)의 두 변수에 자연스러운 전단사입니다.
  • 단위 η와 쌍대단위 ε는 서로 다른 타입을 가지며 두 삼각 항등식을 만족합니다.
  • 곱–지수 수반은 Curry/Uncurry, 단위는 쌍 만들기, 쌍대단위는 평가입니다.
  • 전역적인 곱의 보편 성질은 대각함자와 곱 함자의 수반으로 표현됩니다.
