작은 영역에 정의한 함자를 더 큰 영역으로 옮길 때 임의의 빈칸 채우기로는 선택을 정당화할 수 없습니다. 칸 확장은 다른 모든 비교 후보가 유일하게 인수분해된다는 기준으로 선택합니다.

1. 세 범주의 역할

함자 D:I→C와 K:I→A를 고정합니다. 원하는 결과는 F:A→C입니다. K가 실제 부분범주 포함일 수도 있지만 객체들을 합치거나 사상 정보를 잊을 수도 있습니다. 따라서 F∘K=D라는 엄격한 등식이나 동형을 항상 요구하지 않습니다.

오른쪽 칸 확장은 비교 자연변환 ε:(Ran_K D)∘K⇒D를 포함합니다. 왼쪽 칸 확장은 반대 방향 η:D⇒(Lan_K D)∘K를 포함합니다. 함자 하나만 제시하고 이 비교 사상과 보편성을 생략하면 칸 확장의 정의가 되지 않습니다.

실험 1 · Ran: 곱으로 원뿔 인수분해

I는 이산 두 객체, K:I→1. X={x}에서 각 집합으로 고른 값이 곱의 매개 함수를 결정합니다.

2. 오른쪽 칸 확장의 보편 성질

R=Ran_K D와 ε:R K⇒D에 대해, 임의의 F:A→C 및 ε′:F K⇒D마다 유일한 σ:F⇒R가 있어 ε′=ε∘(σ K)를 만족해야 합니다. σ K는 K에 대한 whiskering이며 세로 합성의 결과가 ε′입니다. 모든 변환의 성분은 자연성을 만족해야 합니다.

K:I→1이 유일한 함자이면 F:1→C는 객체 하나를 고르고 ε′는 그 객체에서 D로 가는 원뿔입니다. 따라서 Ran_K D의 유일한 값은 lim D입니다. 이 예는 일반 정의에서 곱과 극한을 복원하며 K가 포함 함자가 아니라는 점도 보여 줍니다.

3. 왼쪽 칸 확장의 보편 성질

L=Lan_K D와 η:D⇒L K에 대해, 임의의 F:A→C 및 η′:D⇒F K마다 유일한 σ:L⇒F가 있어 η′=(σ K)∘η를 만족합니다. 오른쪽 정의의 화살표가 뒤집힙니다. K:I→1일 때는 L(*)=colim D이며 η의 성분들이 쌍대원뿔의 주입입니다.

C=Set, I가 두 객체의 이산 범주라면 Ran의 값은 두 집합의 곱이고 Lan의 값은 태그가 붙은 서로소 합입니다. 첫 두 실험에서 각각 사영을 재현하는 매개 함수와 주입을 재현하는 경우 분석 함수를 계산합니다. 유일성은 순서쌍의 두 성분과 서로소 합의 두 분기가 출력을 모두 결정해서 성립합니다.

실험 2 · Lan: 주입 이후의 처리

A={a0,a1}, B={b0}. 주입을 거친 처리 함수는 태그별로 정해집니다.

4. 순서 범주에서 실제 확장 계산

A는 0<1<2이고 I는 양끝 0,2와 그 사이 사상을 가진 부분범주입니다. K는 포함 함자입니다. C는 {0,…,5}의 ≤ 범주이며 D(0)=l≤u=D(2)를 지정합니다. 확장 F가 원래 값과 정확히 일치하려면 가운데 값 x는 l≤x≤u여야 합니다.

이 경우 Lan의 가운데 값은 l, Ran은 u입니다. 작은 값 l은 모든 유효한 x로 유일한 사상을 보내며 큰 값 u는 모든 x에서 유일한 사상을 받습니다. poset에서는 사상이 최대 하나라 유일성은 자동이지만 존재 부등식은 반드시 확인해야 합니다. 이 유한 예에서의 최소·최대 선택을 임의의 범주의 수치 외삽 공식이라고 일반화하지 않습니다.

5. 수반과 점별 계산 공식

고정 K에 대한 모든 확장이 존재하면 전합성 K*: [A,C]→[I,C]에 대해 Lan_K⊣K*⊣Ran_K입니다. 대응 Nat(Lan_K D,F)≅Nat(D,F K), Nat(F,Ran_K D)≅Nat(F K,D)가 바로 위의 유일 인수분해입니다.

작은 I와 Set 값 D에 대해 점별 공식은 (Ran_K D)(a)=∫_i Set(A(a,Ki),Di), (Lan_K D)(a)=∫^i A(Ki,a)×Di입니다. Hom의 방향이 서로 다릅니다. 일반 C에서는 해당 가중 극한·쌍대극한의 존재 조건이 필요합니다. Ran_K Id가 수반을 준다는 주장에도 K에 의한 보존 조건이 필요하므로 이를 무조건적인 역함수 공식으로 읽으면 안 됩니다. C#에서는 유한 곱·합 사례를 구체적으로 구현합니다.

실험 3 · 순서 범주의 가운데 값

l≤u인 데이터만 허용합니다. 정확한 확장의 후보 가운데 값과 Lan/Ran의 인수분해 부등식을 계산합니다.

6. 실행 가능한 전체 C#

C# 12 / .NET 8의 BCL만 사용하는 전체 Program.cs입니다. examples/Ch27/Program.cs에 같은 프로그램이 있습니다. 웹 위젯은 같은 수학 규칙의 JavaScript 계산이며 C# 실행기가 아닙니다.

using System;
int lower = 1, upper = 4;
int count = 0;
for (int x = 0; x <= 5; x++) if (lower <= x && x <= upper) count++;
Console.WriteLine($"exact extensions = {count}");
Console.WriteLine($"Lan(1) = {lower}");
Console.WriteLine($"Ran(1) = {upper}");
var mediator = (A: 1, B: 2);
Console.WriteLine($"Ran projections = {mediator.A},{mediator.B}");

기대 표준 출력:

exact extensions = 4
Lan(1) = 1
Ran(1) = 4
Ran projections = 1,2

7. 확인 문제

Ran의 비교 자연변환 방향은?
오른쪽 확장은 원뿔의 사영처럼 확장된 값에서 원래 데이터로 갑니다.
Lan의 매개 변환은?
주어진 η′:D⇒F K는 (σ K)η로 인수분해됩니다.
K:I→1이면 Ran은?
1→C가 꼭짓점을 고르고 비교 자연변환은 원뿔이 됩니다.
l=1,u=4인 순서 예의 Lan 가운데 값은?
가장 작은 허용값은 다른 모든 허용 후보로 유일한 사상을 보냅니다.

8. 직접 구현하는 실습

실습 A · 곱 매개 함수

X={0,1}, f(x)=x, g(x)=1-x에서 X→{0,1}² 매개 함수를 구현하고 사영을 검사하세요.

기대 결과:

factorization = True
힌트

매개 함수는 x↦(f(x),g(x))입니다.

해답 · 별도 Program.cs로 실행하는 전체 프로그램
using System;
using System.Linq;
static (int A, int B) M(int x) => (x, 1 - x);
Console.WriteLine($"factorization = {Enumerable.Range(0, 2).All(x => M(x).A == x && M(x).B == 1 - x)}");

곱의 두 성분이 고정되어 다른 매개 함수가 값을 다르게 고를 자리가 없습니다.

실습 B · 순서 확장 전체

l=2,u=3인 경우 모든 가운데 값을 출력하고 Lan≤x≤Ran을 검사하세요.

기대 결과:

2,3
factors = True
힌트

유효한 x는 경계값을 포함합니다.

해답 · 별도 Program.cs로 실행하는 전체 프로그램
using System;
using System.Linq;
int l = 2, u = 3;
int[] xs = Enumerable.Range(0, 6).Where(x => l <= x && x <= u).ToArray();
Console.WriteLine(string.Join(",", xs));
Console.WriteLine($"factors = {xs.All(x => l <= x && x <= u)}");

poset의 각 사상은 존재하면 유일합니다. 유효하지 않은 x를 후보로 포함하면 비교 조건을 잃습니다.

핵심 요약

칸 확장은 함자와 비교 자연변환, 유일 인수분해의 묶음입니다. 오른쪽은 극한, 왼쪽은 쌍대극한을 포함하며 존재 조건과 화살표 방향이 핵심입니다.
