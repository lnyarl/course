1. 도식도 함자다

곱을 정의할 때 객체 두 개를 골랐습니다. 이 선택 모양을 작은 범주 I로 만들고, 선택된 실제 객체와 사상을 함자 D:I→C로 지정하면 임의의 도식을 말할 수 있습니다. I의 합성·항등을 D가 보존해야 하므로 그림에 그린 경로 사이의 관계도 함께 정해집니다.

두 이산 객체를 고르는 도식은 곱의 모양이고, 평행한 두 사상을 고르는 도식은 등화자의 모양입니다. 빈 범주를 인덱스로 쓰는 도식도 가능합니다. 단순히 화살표 수를 세는 것과 인덱스 범주의 모든 합성 관계를 지정하는 것은 다릅니다.

2. 원뿔과 자연성

상수 함자 ΔX:I→C는 모든 객체를 X, 모든 사상을 id_X로 보냅니다. 원뿔은 자연변환 α:ΔX⇒D입니다. 각 i에 다리 α_i:X→D(i)가 있고, u:i→j에 대해 D(u)∘α_i=α_j여야 합니다. 아무 객체에 여러 화살표를 그렸다고 원뿔이 되는 것이 아니라 도식과 호환되어야 합니다.

D(u)∘α_i=α_j
α:ΔX⇒D

원뿔 사이의 사상 h:X→Y는 모든 다리를 보존합니다. β_i∘h=α_i가 되어야 합니다. 이렇게 만든 원뿔 범주에서 말단 원뿔이 극한입니다. 따라서 모든 다른 원뿔에서 극한 원뿔로 가는 유일한 사상이 존재합니다.

3. 극한의 보편적 성질과 자연동형

극한 (L,λ)이 있으면 원뿔 α의 각 다리가 λ_i∘h로 유일하게 분해됩니다. 이를 집합의 대응으로 쓰면 Hom_C(X,L)≅Nat(ΔX,D)입니다. X→L 하나를 고르면 다리를 합성해 원뿔을 얻고, 원뿔을 고르면 유일한 h를 얻습니다.

Hom_C(X,Lim D) ≅ Nat(ΔX,D)

이 동형은 X에 자연적이며 양쪽 모두 X에 반변입니다. X′→X를 앞에 합성하면 사상도 원뿔도 같은 방식으로 바뀝니다. 14장에서 표현 가능 함자로 다시 만나게 됩니다. 모든 도식에 극한이 있다는 보장은 없으며, 존재한다면 다리들을 보존하는 유일한 동형까지 정해집니다.

4. 등화자: 두 함수가 같은 부분

평행한 f,g:A→B의 등화자는 e:E→A이며 f∘e=g∘e를 만족합니다. 같은 조건을 만족하는 h:X→A는 e를 통해 유일하게 분해되어야 합니다. Set에서는 E={a∈A | f(a)=g(a)}와 포함 함수입니다.

정의역 전체에서 두 함수를 같다고 하는 것이 아니라 같아지는 값들을 골라냅니다. X의 각 값이 이미 이 부분에 들어간다면 매개함수는 그 값을 그대로 E의 원소로 보는 유일한 함수입니다. 위젯은 유한한 정의역에서 해를 모두 검사합니다.

실험 1 · 등화자 해와 매개 조건

정의역은 −3~3이고 f(x)=x², g(x)=k입니다.

5. 당김: 다른 두 정의역을 맞추기

f:A→B와 g:C→B의 당김(pullback)은 P에서 A와 C로 가는 사영 p,q를 가지며 f∘p=g∘q를 만족합니다. 모든 호환되는 두 다리는 P를 통해 유일하게 분해됩니다. Set에서는 P={(a,c) | f(a)=g(c)}입니다.

따라서 공통 키로 두 입력을 연결하는 데이터 조인의 구조를 생각할 수 있습니다. 하지만 중복값과 각 쌍을 보존하는지 같은 계약을 명확히 해야 합니다. 당김은 결과 키를 집합으로 중복 제거해 버리는 연산이 아니라 조건을 만족하는 입력 쌍의 집합입니다.

실험 2 · 당김을 쌍 격자로 계산

두 사상은 길이 3의 0/1 결과표입니다.

6. 쌍대극한: 원뿔을 뒤집기

모든 화살표를 뒤집으면 쌍대원뿔 D⇒ΔX와 쌍대극한이 됩니다. 쌍대극한 원뿔은 쌍대원뿔 범주의 초기 객체라서 보편적 꼭짓점에서 다른 꼭짓점으로 유일한 매개사상이 나갑니다. 두 이산 객체의 쌍대극한은 쌍대곱, 빈 도식의 쌍대극한은 초기 객체입니다.

Set의 밀어냄(pushout)은 A←B→C에서 A와 C의 서로소 합을 만들고 B에서 같은 출처로 지정한 값들을 식별한 몫입니다. 한 번 지정한 쌍만 표시하는 것이 아니라 반사·대칭·추이적인 동치관계가 생성됩니다. 아래에서는 서로소 합의 태그를 먼저 유지한 뒤 필요한 값만 합칩니다.

실험 3 · 밀어냄 동치류 만들기

A0,A1,C0,C1의 서로소 합에서 공통 B의 지정 쌍을 합칩니다.

평행한 두 함수 f,g:A→B의 쌍대등화자 q:B→Q는 q∘f=q∘g이며 이 식을 만족하는 다른 함수가 q를 통해 유일하게 나가도록 정의합니다. Set에서는 f(a)와 g(a)를 같게 만드는 동치관계로 B를 나눈 몫입니다.

7. 빈 도식과 연속성

빈 도식의 원뿔에는 꼭짓점만 남으므로 극한은 말단 객체입니다. 곱·등화자·당김은 서로 다른 인덱스 모양의 극한이며, 쌍대곱·쌍대등화자·밀어냄은 대응하는 쌍대극한입니다.

극한을 보존하는 함자를 연속적이라고 부릅니다. 모든 함자가 그런 것은 아닙니다. Hom(R,−)는 존재하는 극한을 보존하며, Hom(−,R)는 반변으로 쌍대극한을 극한으로 보냅니다. 예를 들어 R→(A×B)는 (R→A)×(R→B), (A+B)→R는 (A→R)×(B→R)에 대응합니다. 이 구조적 연속성을 물리 시간의 연속성과 혼동하지 않습니다.

전체 C# 프로그램

C# 12 / .NET 8, 외부 패키지 없는 전체 Program.cs입니다. examples/Ch12에서 dotnet run으로 실행합니다. 이 예제는 명시한 순수 값 모델을 구현합니다. C# 전체의 종료·순수성을 타입이 증명한다는 뜻은 아닙니다.

internal static class Program
{
    static void Main()
    {
        int[] domain = [-3, -2, -1, 0, 1, 2, 3];
        var equalizer = domain.Where(x => x * x == 1).ToArray();
        Console.WriteLine($"equalizer = {string.Join(",", equalizer)}");
        int[] f = [0, 1, 0], g = [0, 0, 1];
        var pairs = Enumerable.Range(0, 3).SelectMany(a => Enumerable.Range(0, 3).Where(c => f[a] == g[c]).Select(c => (a, c))).ToArray();
        Console.WriteLine($"pullback = {string.Join(",", pairs.Select(p => $"{p.a}:{p.c}"))}");
        var cone = new[]
        {
            (a: 0, c: 0),
            (a: 1, c: 2)
        };
        Console.WriteLine($"cone compatible = {cone.All(p => f[p.a] == g[p.c])}");
    }
}

기대 출력:

equalizer = -1,1
pullback = 0:0,0:1,1:2,2:0,2:1
cone compatible = True

핵심 요약

  • 도식은 함자, 원뿔은 상수 함자에서 도식으로 가는 자연변환입니다.
  • 극한은 원뿔 범주의 말단 객체이고 쌍대극한은 쌍대원뿔 범주의 초기 객체입니다.
  • Set의 등화자는 같은 값 부분, 당김은 같은 공통 결과를 가진 쌍, 밀어냄은 식별 몫입니다.

실습 2 · 밀어냄의 추이적 식별

A0=C0, A1=C0를 식별하면 세 값이 같은 동치류가 되는지 계산하세요.

기대 결과: classes = 2 / identified = True

힌트

서로소 합 원소를 0,1,2,3으로 두고 union-find를 씁니다.

해답 · 독립 실행 Program.cs
int[] parent = [0, 1, 2, 3];
int Find(int x) => parent[x] == x ? x : parent[x] = Find(parent[x]);
void Union(int a, int b)
{
    parent[Find(a)] = Find(b);
}

Union(0, 2);
Union(1, 2);
Console.WriteLine($"classes = {Enumerable.Range(0, 4).Select(Find).Distinct().Count()}");
Console.WriteLine($"identified = {Find(0) == Find(1) && Find(1) == Find(2)}");
