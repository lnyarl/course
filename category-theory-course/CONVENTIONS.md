# 프로그래머를 위한 범주론 · C# 작성 규칙

- 원문: Bartosz Milewski, *Category Theory for Programmers*, Igal Tabachnik 편집, 2023-01-30, 98b71ac. 사용자 제공 PDF를 기준으로 31장 번호·순서를 유지한다.
- 코스는 **원문 31장 전체**를 포함한다. 장별로 구현·검증을 완료한 뒤 공개 상태로 표시한다. 미제작 장은 `assets/common.js`의 `ready: false`로 표시하고 본문 링크를 만들지 않는다.
- 한국어 해설과 C# 12 / .NET 8 예제로 재구성한다. 웹 위젯은 동일한 규칙의 JavaScript 모형이며 C# 실행기라고 표시하지 않는다.
- 원문 정의를 확인하고 수식의 정의역·공역과 성립 조건을 적는다. C# 전체를 순수 전함수 범주로 취급하지 않는다. 함수의 동등성은 입력별 결과의 같음이며 delegate 참조 비교와 구분한다.
- 학습 흐름: 문제 상황, 개념과 법칙, C# 예제, 도식과 조작 실습, 핵심 요약, 확인 문제, 구현 과제.
- 상호작용 개수나 장별 재생 버튼을 할당량으로 만들지 않는다. 각 조작은 학습자가 어떤 개념을 비교·예측·확인하는지 설명할 수 있어야 한다. 단순한 내용은 정적 도식으로 전달한다. 해설 있는 퀴즈와 구현 실습은 유지한다.
- 재생 단계는 원소·연결·중간값·분기·문맥 중 하나가 실제로 달라져야 한다. 완성된 답을 모두 보여 놓고 색이나 불투명도만 순회하는 재생은 제거한다. 항목 나열은 격자·대응·집합·트리 등 의미가 드러나는 배치로 보여준다.
- 재생이 필요한 계산 과정은 사용자가 시작하고, 일시정지·이전·다음·초기화를 지원한다. 입력 변경·페이지 숨김 시 재생을 중지한다. 장마다 애니메이션을 넣을 의무는 없다.
- 도식은 입력·선택·단계 변경에 맞춰 갱신한다. 가능한 경우 화살표·연결·대응값을 직접 바꾸고 법칙의 성립과 반례를 비교하게 한다. 강조 색에는 단계명·기호·설명을 함께 표시한다.
- 시각화는 360px 화면·다크 테마·키보드 조작을 검증한다. 넓은 도식은 포커스 가능한 내부 스크롤 영역에 넣고 안내를 제공한다. `prefers-reduced-motion`에서는 이동 효과를 줄이거나 끄되 단계별 학습은 유지한다. 실제 브라우저에서 재생·정지·끝 단계·입력 오류·도식과 계산 결과의 일치를 확인한다.
- 유한 표본 실험을 일반 증명으로 설명하지 않는다. 지원하지 않는 고차 타입이나 가상 C# 문법을 실행 코드에 섞지 않는다.
- 실행할 전체 C# 프로그램은 `data-csharp="true"`로 표시한다. `examples/ChNN/Program.cs`와 동일하게 유지하고 SDK로 컴파일·실행한다. 조각 코드는 조각이라고 밝힌다.
- 모든 페이지는 빌드·CDN 없이 `file://`로 열려야 한다. CSS 변수와 순수 HTML/CSS/SVG/JS만 사용한다. 360px 화면, 다크 테마, 키보드 조작을 확인한다.
- 공유 UI는 `assets/common.js`의 `MM`을 사용한다. 장의 `body`에 `data-chapter="NN"`을 지정한다. 테마·방문 기록은 이 코스 전용 키로 저장한다.
- 위젯 스크립트는 `node --check`와 실제 브라우저로 검증하고, 계산 결과를 알려진 기대값 및 반례와 비교한다. 입력값은 검증하고 출력은 `textContent` 또는 `MM.esc`로 삽입한다.
- 장 시작 또는 끝에서 원문 인쇄 페이지와 PDF 실제 페이지를 구분한다. 이 판은 본문 인쇄 p.2가 PDF 20페이지다.
- 원문 및 각색 학습 콘텐츠는 CC BY-SA 4.0. 원저자, 편집자, 원문 URL, 판본, 변경 내용을 명시한다. 공통 푸터가 출처·라이선스를 표시한다.
- 새 장을 공개 상태로 바꿀 때 코스 목차, 루트 `index.html`, `README.md`의 실제 장 수를 함께 갱신한다. 커밋·게시·배포는 별도 요청이 있어야 한다.
