관계의 존재만으로는 이동 비용이나 근사 오차를 표현할 수 없습니다. Hom 집합을 모노이달 범주의 객체로 바꾸면 같은 합성 법칙을 순서·거리·선형 구조에서 해석할 수 있습니다.

1. Hom의 원소에서 Hom 객체로

기저 모노이달 범주 (V,⊗,I)를 먼저 고릅니다. V-풍성한 범주 C는 객체 x,y마다 V의 객체 C(x,y)를 지정하고, 합성 m:C(y,z)⊗C(x,y)→C(x,z)와 단위 j_x:I→C(x,x)를 V의 사상으로 가집니다. 합성과 단위는 결합자·단위원 동형을 포함한 가환도를 만족합니다.

V=Set, ⊗=×, I=한 원소 집합이면 보통의 국소적으로 작은 범주가 복원됩니다. 일반 V에서는 C(x,y)에 개별 원소가 있다고 가정할 수 없습니다. 풍성화는 크기 문제에만 쓰는 기법이 아니라 Hom에 추가 구조를 담는 방법이기도 합니다.

실험 1 · 거리의 합성 부등식

x→y→z를 거치는 비용과 직접 비용을 비교합니다. 대각 거리는 0으로 고정합니다.

2. 기저 모노이달 구조를 빠뜨리지 않기

⊗:V×V→V는 이변함자이고 결합자 (a⊗b)⊗c≅a⊗(b⊗c), 왼쪽·오른쪽 단위원 I⊗a≅a≅a⊗I가 있습니다. 이들은 오각형·삼각형 coherence를 만족해야 합니다. 대칭은 기본 정의에 필수가 아니며 필요하면 별도 조건을 둡니다.

모노이달 닫힘은 내부 Hom [b,c]에 대한 V(a⊗b,c)≅V(a,[b,c])를 말합니다. 카르테시안 닫힘은 ⊗가 곱인 특수 경우입니다. 단지 수치에 더하기를 정의했다는 이유만으로 풍성한 범주가 완성되는 것은 아닙니다. Hom 객체, 합성·단위 사상과 법칙까지 지정해야 합니다.

3. Bool 위의 풍성화는 전순서가 아닌 전위순서

V={false≤true}, ⊗=∧, I=true를 택합니다. C(x,y)는 x≤y라는 관계의 참·거짓입니다. 단위 사상 true→C(x,x)는 반사성을 요구하고, 합성 C(y,z)∧C(x,y)→C(x,z)는 추이성을 요구합니다.

반대칭성은 이 조건에서 나오지 않습니다. 서로 다른 x,y에 양방향 관계가 있어도 되므로 결과는 일반적으로 전위순서(preorder)입니다. 부분순서가 되려면 반대칭성이 추가되어야 합니다. 아래 Bool 위젯은 한 방향 두 간선이 있을 때 합성 간선이 반드시 필요한 이유를 보여 줍니다.

실험 2 · Bool 풍성화의 추이성

x≤y와 y≤z를 선택한 다음 x≤z의 필요 여부를 검사합니다. 반사 간선은 모두 포함합니다.

4. Lawvere 거리의 부등식 방향

V는 확장 비음수 실수 [0,∞]를 역순으로 봅니다. V의 사상 r→s가 있다는 뜻을 수치 부등식 r≥s로 정하고 ⊗=+, I=0으로 둡니다. 그러면 합성 사상은 d(y,z)+d(x,y)≥d(x,z), 즉 통상적인 삼각부등식입니다.

단위 0→d(x,x)는 0≥d(x,x)를 요구하므로 비음수 조건과 함께 d(x,x)=0입니다. 대칭 d(x,y)=d(y,x)나 서로 다른 점의 거리 양수는 기본 정의에서 요구하지 않습니다. 무한 거리도 허용됩니다. 기저 순서를 보통 ≤로 잘못 택하면 합성 부등식 방향이 뒤집혀 전혀 다른 조건이 됩니다.

5. 풍성한 함자와 C#의 유한 행렬

V-함자는 객체 함수 F와 V의 사상 C(x,y)→D(Fx,Fy)를 가지며 단위·합성과 호환됩니다. 거리 기저에서는 d_C(x,y)≥d_D(Fx,Fy)여야 하므로 거리를 늘리지 않는 비팽창 함수입니다. 세 번째 실험은 세 점의 거리 전체에 배율을 적용해 이 조건을 검사합니다.

C#에서는 유한한 거리 행렬과 Bool 관계를 데이터로 검증할 수 있습니다. 이는 모든 V와 모든 Hom 객체를 표현하는 일반 인터페이스가 아닙니다. 실수 반올림도 수학적 등식과 다르므로 이 장의 위젯과 실행 예제는 작은 정수 거리와 단순 유리 배율만 사용합니다. 삼각부등식 하나가 실패하는 즉시 풍성화 법칙이 성립하지 않습니다.

실험 3 · 비팽창 함자 검사

원래 거리 0,2,5의 직선 세 점을 같은 비율로 재배치합니다. 모든 점 쌍에서 새 거리≤원래 거리인지 검사합니다.

6. 실행 가능한 전체 C#

C# 12 / .NET 8의 BCL만 사용하는 전체 Program.cs입니다. examples/Ch28/Program.cs에 같은 프로그램이 있습니다. 웹 위젯은 같은 수학 규칙의 JavaScript 계산이며 C# 실행기가 아닙니다.

using System;
int[] points = [0, 2, 5];
bool triangle = true, nonexpanding = true;
foreach (int x in points)
    foreach (int y in points)
        foreach (int z in points)
            triangle &= Math.Abs(x - z) <= Math.Abs(x - y) + Math.Abs(y - z);
foreach (int x in points)
    foreach (int y in points)
        nonexpanding &= Math.Abs(2 * x - 2 * y) <= Math.Abs(x - y);
Console.WriteLine($"triangles = {triangle}");
Console.WriteLine($"scale 2 nonexpanding = {nonexpanding}");

기대 표준 출력:

triangles = True
scale 2 nonexpanding = False

7. 확인 문제

풍성화에서 먼저 정하는 것은?
Hom 객체, 합성, 단위의 의미가 기저에 의존합니다.
Bool 풍성 범주가 자동으로 갖는 것은?
반대칭성이나 전순서 조건은 별도입니다.
거리 기저에서 r→s의 수치 조건은?
역순을 써야 합성 사상이 일반 삼각부등식을 나타냅니다.
거리 풍성 함자는?
Hom 사상 조건은 원래 거리≥새 거리입니다.

8. 직접 구현하는 실습

실습 A · 추이 폐포

0→1,1→2와 반사 간선으로 시작해 Bool 합성을 닫고 관계 원소 수를 구하세요.

기대 결과:

relations = 6
힌트

Floyd–Warshall의 논리 버전을 사용합니다.

해답 · 별도 Program.cs로 실행하는 전체 프로그램
using System;
bool[,] r = new bool[3, 3];
for (int i = 0; i < 3; i++) r[i, i] = true;
r[0, 1] = true;
r[1, 2] = true;
for (int k = 0; k < 3; k++) for (int i = 0; i < 3; i++) for (int j = 0; j < 3; j++) r[i, j] |= r[i, k] && r[k, j];
int count = 0;
foreach (bool b in r) if (b) count++;
Console.WriteLine($"relations = {count}");

추가되는 것은 0→2입니다. 역방향 간선을 자동으로 추가하지 않습니다.

실습 B · 비대칭 거리

d(0,1)=1, d(1,0)=2, 대각은 0인 두 점이 Lawvere 거리인지 검사하세요.

기대 결과:

Lawvere metric = True
symmetric = False
힌트

세 점의 모든 선택은 2³=8개이며 같은 점을 여러 번 골라도 됩니다.

해답 · 별도 Program.cs로 실행하는 전체 프로그램
using System;
int[,] d = { { 0, 1 }, { 2, 0 } };
bool ok = true;
for (int x = 0; x < 2; x++) for (int y = 0; y < 2; y++) for (int z = 0; z < 2; z++) ok &= d[x, z] <= d[x, y] + d[y, z];
Console.WriteLine($"Lawvere metric = {ok}");
Console.WriteLine($"symmetric = {d[0, 1] == d[1, 0]}");

풍성화의 단위·합성 조건에 대칭성은 포함되어 있지 않습니다.

핵심 요약

Hom 객체의 기저를 바꾸어 같은 합성·단위 구조를 다른 문맥에서 해석합니다. Bool은 전위순서를, 역순 비음수 실수와 덧셈은 Lawvere 거리를 줍니다.
