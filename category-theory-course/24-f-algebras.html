1. 재귀와 한 층의 계산을 분리하기

구문 트리의 합계, 출력, 노드 수 계산은 트리의 모양을 따라 내려가는 부분이 같습니다. 달라지는 것은 자식들의 계산 결과를 받아 한 부모의 결과를 만드는 규칙입니다. 함자 F는 바로 이 한 층의 모양을 나타냅니다. 예를 들어 자연수의 모양 F X = 1 + X에는 Zero와 Succ(X) 두 경우가 있습니다.

F-대수는 자기함자 F:C→C, 운반 객체 A, 구조 사상 α:F A→A입니다. F 자체가 고정되었을 때 (A,α)라고 씁니다. F X=1+X인 Set의 예에서 A=자연수, α(Zero)=0, α(Succ(n))=n+1을 고릅니다. 같은 F에 A=문자열을 골라 괄호 표기를 만드는 다른 해석도 가능합니다.

실험 1 · 자연수 접기 단계

입력 트리를 확인한 뒤 Zero부터 안쪽 생성자를 값으로 바꿉니다. 마지막 단계에는 결과 값만 남습니다.

2. 대수 준동형과 초기성

두 F-대수 (A,α), (B,β) 사이 준동형 h:A→B는 h∘α = β∘Fh를 만족합니다. 왼쪽은 한 층을 먼저 해석한 뒤 결과를 옮기며, 오른쪽은 자식 결과를 먼저 옮긴 뒤 새 대수로 해석합니다. 이 조건이 있어야 h가 구조를 보존합니다.

초기 F-대수 (μF,in:F(μF)→μF)는 모든 (A,α)에 유일한 준동형 foldα:μF→A를 가집니다. 식 foldα∘in = α∘F(foldα)가 접기의 재귀 방정식입니다. μF가 존재한다는 보장은 임의의 자기함자에 자동으로 주어지지 않습니다. 다항 함자의 유한 생성 트리에서는 구조적 재귀가 이 함수를 정의하고, 트리 높이에 대한 귀납법이 유일성을 보입니다.

3. 고정점과 Lambek 보조정리

초기 대수의 구조 사상 in은 동형입니다. 따라서 F(μF) ≅ μF이며, 재귀 자료형을 함자의 고정점으로 부를 수 있습니다. 그러나 F X≅X인 객체라는 사실만으로 초기성이 따르지는 않습니다. 초기성은 모든 다른 대수로 가는 구조 보존 사상의 존재와 유일성까지 요구합니다.

자연수 예에서 유한한 Zero, Succ(Zero), Succ(Succ(Zero))…가 초기 대수의 원소입니다. 여기에 무한 Succ 사슬을 임의로 넣으면 유한 구조적 접기의 근거가 사라집니다. 위젯의 0~6 표본은 fold 방정식을 계산할 뿐 모든 트리와 모든 대수에 대한 유일성 증명 자체는 아닙니다.

실험 2 · 준동형 방정식 검사

h(n)=k·n, 원래 α는 +1, 새 β는 +k입니다. β를 잘못 +1로 선택하면 어떤 입력에서 방정식이 깨지는지 봅니다.

4. 카타모피즘을 두 해석으로 실행하기

카타모피즘(catamorphism)은 이 초기 대수에서 나가는 접기의 이름입니다. F X=1+X에 대한 길이 대수는 Zero를 0으로, Succ(a)를 a+1로 보냅니다. 별표 대수는 Zero를 빈 문자열로, Succ(s)를 "*"+s로 보냅니다. 구조는 같고 운반 타입과 한 층의 연산만 바뀝니다.

C#은 F처럼 타입 생성자를 받는 고차 타입 매개변수를 직접 지원하지 않습니다. 아래 Nat 전용 Fold<A>는 특정 F의 카타모피즘을 실제 코드로 표현합니다. Func<A,A>가 임의의 효과·예외·비종료를 만들 수도 있으므로 C# 타입 검사기가 초기성이나 순수성을 보증하는 것은 아닙니다. 작은 유한 입력과 순수한 해석을 사용합니다.

5. 코대수와 생성 방향

F-코대수는 γ:A→F A입니다. 입력 상태를 한 층 펼치며 다음 상태를 만듭니다. 끝 F-코대수가 존재하면 각 코대수에서 그 객체로 가는 유일한 unfold, 즉 아나모피즘을 얻습니다. 접기는 구조를 소비하고 펼치기는 구조를 생산합니다. 모든 unfold가 유한한 트리를 만든다고 가정하면 안 됩니다.

유한 리스트의 모양 F X=1+E×X에서 상태 n>0을 (n,n-1)로 펼치고 n=0에서 종료하면 [n,…,1]이 됩니다. 이것은 종료 조건을 갖춘 유한 예입니다. 생성 후 fold로 합계를 내는 합성은 하일로모피즘의 전형적인 모양입니다. F-대수만으로 결합법칙 같은 모노이드 방정식까지 얻지는 않습니다.

실험 3 · 펼치기 후 접기

상태 n을 [n,…,1]로 펼친 뒤 합칩니다. 원래 상태와 다음 상태, 합계 경로를 함께 표시합니다.

6. 실행 가능한 전체 C#

C# 12 / .NET 8의 BCL만 사용하는 전체 Program.cs입니다. examples/Ch24/Program.cs에 같은 프로그램이 있습니다. 웹 위젯은 같은 수학 규칙의 JavaScript 계산이며 C# 실행기가 아닙니다.

using System;
abstract record Nat;
sealed record Zero : Nat;
sealed record Succ(Nat Previous) : Nat;
static class Program
{
    static A Fold<A>(Nat n, A zero, Func<A, A> succ) => n switch
    {
        Zero => zero,
        Succ s => succ(Fold(s.Previous, zero, succ)),
        _ => throw new ArgumentException("unknown constructor")
    };
    static void Main()
    {
        Nat three = new Succ(new Succ(new Succ(new Zero())));
        Console.WriteLine($"value = {Fold(three, 0, x => x + 1)}");
        Console.WriteLine($"stars = {Fold(three, "", x => "*" + x)}");
    }
}

기대 표준 출력:

value = 3
stars = ***

7. 확인 문제

F-대수의 구조 사상은?
A는 운반 객체이고 F A의 한 층을 A의 값으로 해석합니다.
초기성이 추가하는 것은?
유일한 구조 보존 사상이 fold이며 단순한 고정점 방정식보다 강합니다.
F X=1+X만 지정하면 반드시 모노이드인가?
함자는 연산의 모양을 주지만 결합법칙 등은 추가 조건입니다.
코대수의 방향은?
코대수는 상태에서 한 층의 관찰과 다음 상태를 생성합니다.

8. 직접 구현하는 실습

실습 A · 두 배 해석 준동형

자연수 표본 0~5에서 h(n)=2n과 β(Succ(x))=x+2가 준동형 방정식을 만족하는지 검사하세요.

기대 결과:

hom samples = True
힌트

h(n+1)과 h(n)+2를 직접 비교합니다.

해답 · 별도 Program.cs로 실행하는 전체 프로그램
using System;
Console.WriteLine($"hom samples = {System.Linq.Enumerable.Range(0, 6).All(n => 2 * (n + 1) == 2 * n + 2)}");

모든 자연수에 대한 증명은 분배법칙 2(n+1)=2n+2로 합니다. 표본 검사는 구현 확인입니다.

실습 B · 종료하는 unfold와 합계

상태 4를 [4,3,2,1]로 펼치고 합계를 구하세요.

기대 결과:

4,3,2,1
sum = 10
힌트

0일 때 종료하며 각 반복은 상태를 하나 줄입니다.

해답 · 별도 Program.cs로 실행하는 전체 프로그램
using System;
using System.Collections.Generic;
using System.Linq;
var xs = new List<int>();
for (int n = 4; n > 0; n--) xs.Add(n);
Console.WriteLine(string.Join(",", xs));
Console.WriteLine($"sum = {xs.Sum()}");

이 생성기는 유한 상태 감소로 종료합니다. 임의의 코대수나 끝 코대수의 모든 관찰이 유한하다는 주장은 아닙니다.

핵심 요약

F는 재귀의 한 층, α는 그 층의 해석입니다. 초기 대수의 fold는 구조를 보존하는 유일한 소비 함수이며, 코대수는 반대 방향으로 한 층을 생성합니다.
