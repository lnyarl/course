1. 사상인 함수와 객체인 함수 타입

f:A→B는 사상입니다. 이제 A에서 B로 가는 함수들을 값으로 담는 함수 타입도 객체로 생각합니다. Set에서는 실제 함수들의 집합 B^A가 이 역할을 합니다. 일반 범주의 외부 Hom 집합이 있다고 그 범주 안에 해당 내부 객체가 자동으로 생기는 것은 아닙니다.

이 객체의 핵심 관찰은 함수 값을 입력에 적용하는 평가입니다. Eval:(A⇒B)×A→B는 (f,a)를 받아 f(a)를 돌려줍니다. 함수 객체는 단순히 “아무 함수 비슷한 것을 담는 상자”가 아니라 다음 보편적 성질로 선택됩니다.

2. 평가를 통한 보편적 성질

임의의 g:Z×A→B에 대해 h:Z→(A⇒B)가 유일하게 있어 g=Eval∘(h×id_A)를 만족해야 합니다. Z값 하나를 먼저 받아 A→B 함수를 고르고, 그 함수에 A값을 넣으면 원래 g와 같습니다. h가 g의 커링입니다.

Eval : B^A×A → B
g : Z×A → B ↔ curry(g) : Z → B^A
g(z,a)=Eval(curry(g)(z),a)

존재는 h(z)(a)=g(z,a)로 정의하면 되고, 유일성은 같은 평가 결과를 모든 a에 대해 내야 한다는 조건으로 얻습니다. 함수의 동등성은 델리게이트 참조가 아니라 모든 입력에서의 결과 동등성입니다.

실험 1 · 커링과 평가 따라가기

g(z,a)=z+2a를 두 표현으로 계산합니다.

3. C#의 커링과 부분 적용

C#의 Func<(A,B),C>와 Func<A,Func<B,C>>는 서로 다른 타입입니다. Curry와 Uncurry를 직접 정의해 변환합니다. 인수 두 개짜리 C# 델리게이트 Func<A,B,C>도 관련되지만 여기서는 수학적 곱을 명확히 보이도록 튜플 인수로 고정합니다.

커링은 함수의 표현을 바꾸는 것이고, 부분 적용은 커링된 함수에 첫 인수를 넣어 남은 함수를 얻는 일입니다. 순수 전함수 모델에서는 두 왕복이 항등이지만, 환경을 변경하는 캡처나 부작용·비종료를 끼우면 무엇을 관찰하는지 별도로 정해야 합니다.

4. 지수: 왜 인수 타입이 위에 놓이는가

A에 a개, B에 b개 원소가 있으면 각 입력마다 B의 값 하나를 고르므로 B^A의 원소는 b^a개입니다. Bool→Bool은 네 가지입니다. 함수값을 입력별 결과표로 바꾸면 “함수 타입도 데이터”라는 관점이 구체적으로 보입니다.

|B^A|=|B|^|A|
B^0≅1, B^1≅B, 1^A≅1

빈 정의역에는 빈 대응표 하나가 있으므로 함수 개수 문맥에서 0^0=1입니다. 비어 있지 않은 A에서 Empty로 가는 전함수는 없지만 Empty→Empty는 하나입니다. 이론적 함수 집합과 실제 유한 메모리 프로그램의 표현 능력을 동일시하지는 않습니다.

실험 2 · 함수를 대응표로 펼치기

빈 입력·빈 결과를 포함한 작은 유한 모델입니다.

5. 지수와 타입 대수

합 타입에서 나가는 함수는 각 분기의 처리 함수 두 개와 같습니다. 따라서 B^(A+C)≅B^A×B^C입니다. 곱에서 나가는 함수의 커링은 B^(A×C)≅(B^C)^A를 줍니다. 곱으로 들어가는 함수는 두 결과를 나란히 계산하므로 (B×C)^A≅B^A×C^A입니다.

이 법칙도 숫자 지수법칙만 따라 적는 대신 타입에 맞는 양방향 변환으로 정당화합니다. 아래 실험은 크기 2와 1의 입력 분기를 Bool 결과로 보내는 여덟 대응표를 둘로 나누고 다시 합칩니다.

실험 3 · 합에서 나가는 함수 나누기

입력 분기 크기 2와 1, 결과 Bool의 여덟 함수를 분할합니다.

6. 카르테시안 닫힌 범주

말단 객체와 이항 곱, 그리고 모든 A,B에 대한 지수 객체를 갖춘 범주를 카르테시안 닫힌 범주라고 합니다. Set은 대표적인 예입니다. 함수 타입의 보편적 정의에 곱이 들어가므로 단지 Hom 집합이 많다는 사실만으로 닫힘을 결론 내리지 않습니다.

프로그래밍에서 함수·튜플·단위 값의 조합이 자연스러운 이유를 이 구조로 설명할 수 있습니다. 다만 C# 전체를 곧바로 정확한 Set 또는 순수 전함수 범주라고 선언하지 않고, null·예외·비종료를 제외한 모델과 구현의 경계를 계속 유지합니다.

7. Curry–Howard 대응

타입을 명제, 값을 증거로 읽으면 곱은 논리곱, 합은 논리합, 함수 타입은 함의에 대응합니다. Unit은 참, Empty는 거짓에 대응합니다. A×B의 값을 만들려면 양쪽 증거가 필요하고, A→B의 값은 A의 증거를 B의 증거로 변환합니다.

이 대응이 아무 C# 함수나 논리 증명으로 인정한다는 뜻은 아닙니다. 예외를 던지거나 끝나지 않는 함수로 임의의 반환형을 선언할 수 있으므로 정상적으로 구성되고 종료하는 계산의 조건이 중요합니다. 이 장에서는 논리와 타입 대수의 연결을 소개하며 C# 컴파일 성공만으로 수학적 정리를 증명했다고 주장하지 않습니다.

전체 C# 프로그램

C# 12 / .NET 8, 외부 패키지 없는 전체 Program.cs입니다. examples/Ch09에서 dotnet run으로 실행합니다. 이 예제는 명시한 순수 값 모델을 구현합니다. C# 전체의 종료·순수성을 타입이 증명한다는 뜻은 아닙니다.

using System.Numerics;

internal static class Program
{
    static Func<A, Func<B, C>> Curry<A, B, C>(Func<(A, B), C> f) => a => b => f((a, b));
    static Func<(A, B), C> Uncurry<A, B, C>(Func<A, Func<B, C>> f) => pair => f(pair.Item1)(pair.Item2);
    static void Main()
    {
        Func<(int, int), int> calculate = p => p.Item1 + 2 * p.Item2;
        var curried = Curry(calculate);
        Console.WriteLine($"curried(3)(4) = {curried(3)(4)}");
        var roundtrip = Uncurry(curried);
        bool same = Enumerable.Range(-2, 5).All(a => Enumerable.Range(-2, 5).All(b => roundtrip((a, b)) == calculate((a, b))));
        Console.WriteLine($"sample roundtrip = {same}");
        Console.WriteLine($"Bool -> Bool = {BigInteger.Pow(2, 2)}");
    }
}

기대 출력:

curried(3)(4) = 11
sample roundtrip = True
Bool -> Bool = 4

실습 1 · Bool 함수 전부 만들기

네 가지 Bool→Bool 함수의 결과표를 출력하세요.

기대 결과: False,False / True,False / False,True / True,True

힌트

두 입력의 출력 비트를 독립적으로 고릅니다.

해답 · 독립 실행 Program.cs
for (int mask = 0; mask < 4; mask++)
{
    Func<bool, bool> f = b => (mask & (1 << (b ? 1 : 0))) != 0;
    Console.WriteLine($"{f(false)},{f(true)}");
}

실습 2 · Bool 인수 함수와 결과 쌍

Bool→Int와 (Int,Int)의 양방향 변환을 모두 검사하세요.

기대 결과: function = True / pair = True

힌트

false 결과와 true 결과를 순서대로 저장합니다.

해답 · 독립 실행 Program.cs
internal static class Program
{
    static (int, int) Table(Func<bool, int> f) => (f(false), f(true));
    static Func<bool, int> From((int, int) p) => b => b ? p.Item2 : p.Item1;
    static void Main()
    {
        Func<bool, int> f = b => b ? 7 : 3;
        var pair = (3, 7);
        Console.WriteLine($"function = {new[] { false, true }.All(b => From(Table(f))(b) == f(b))}");
        Console.WriteLine($"pair = {Table(From(pair)) == pair}");
    }
}
