요네다 매장

객체의 내부 표현 대신 모든 관찰 가능한 사상을 모으면 원래 사상까지 복원됩니다. 요네다 매장의 핵심은 객체 수가 아니라 Hom 집합에서의 전단사입니다.

1. 문제에서 출발하기

같은 결과를 내는 API 두 개가 있다고 해서 구조가 같다고 할 수 있을까요? 테스트 하나가 같으면 한 관찰에서 구분되지 않을 뿐입니다. 요네다 매장은 객체가 참여하는 모든 사상과 그 합성 관계를 함께 보존하는 방법을 제시합니다.

고정한 A를 Hom(A,−)로 옮기면 이제 객체는 집합값 함자가 됩니다. A를 바꾸면 함자 사이 자연변환이 생깁니다. 이 변환이 어떤 원래 사상에서 왔는지 항등사상을 통해 되찾을 수 있습니다.

2. 정의와 타입

C가 국소적으로 작다고 합시다. 공변 Hom을 쓰면 Y:Cᵒᵖ→[C,Set], Y(A)=Hom(A,−)입니다. 원래 f:B→A는 Y(f):Hom(A,−)⇒Hom(B,−)가 되며 성분은 h:A→X를 h∘f:B→X로 보냅니다.

요네다 보조정리에 F=Hom(B,−)를 대입하면 Nat(Hom(A,−),Hom(B,−))≅Hom(B,A)를 얻습니다. 이 전단사가 모든 객체 쌍에 성립하므로 Y는 완충실합니다. 충실은 Hom별 단사, 완전은 Hom별 전사입니다. 객체 전체에 대한 전단사는 요구하지 않습니다.

Y(f)_X(h)=h∘f
decode(τ)=τ_A(id_A):B→A
Nat(Hom(A,−),Hom(B,−)) ≅ Hom(B,A)

3. 계산에서 일반 논증으로

f:B→A와 관찰 h:A→X를 선택하면 결과는 h(f(b))입니다. h=id_A를 선택하면 f(b)가 그대로 드러나므로 서로 다른 f,g를 같은 자연변환으로 보낼 수 없습니다. 반대로 자연변환 τ가 있으면 15장의 논증으로 τ_X(h)=h∘τ_A(id_A)입니다. 빠진 자연변환도 없습니다. 이것이 충실성과 완전성의 두 부분입니다.

예를 들어 B={false,true}, A={0,1}이면 f는 네 개입니다. 각 f가 모든 관찰 h에 대한 전처리 변환을 하나 만듭니다. 이 예제에서 f(false)=0,f(true)=1이고 h(n)=n+10이면 관찰 결과는 [10,11]입니다. h=id일 때 [0,1]을 얻어 f의 표를 복원합니다.

반대 방향 표기를 택하면 y:C→[Cᵒᵖ,Set], y(A)=Hom(−,A)이고 f:A→B는 h↦f∘h를 만듭니다. 이 강의는 원문의 공변 Hom 버전을 먼저 사용합니다. 두 표기를 섞어 화살표를 뒤집지 마세요.

4. 직접 조작하는 세 실험

1. 관찰 전처리와 원래 사상 복원

Bool 두 입력에서 f(false)=n, f(true)=n+1입니다. 관찰 h와 항등 관찰을 차례로 적용해 보세요. 항등 관찰의 복원은 현재 h의 출력에서 역산하지 않고, 같은 Y(f) 가족에서 별도 id_A 관찰로 따로 계산합니다.

2. 충실성의 구별 관찰

f와 g가 한 좌표에서 다릅니다. 상수 관찰은 차이를 숨기고 항등 관찰은 드러냅니다.

3. 유한 Hom 전단사 세기

B의 원소 수 n, A의 원소 수 m에 대해 B→A 함수 표 수 mⁿ을 구합니다. 각 표는 자연 전처리 변환 하나에 대응합니다.

5. 실행 가능한 C#

아래는 C# 12 / .NET 8 전체 프로그램입니다. BCL만 사용하며 examples/Ch16에서 실행할 수 있습니다. JavaScript 실험은 이 계산을 시각화한 별도 모형입니다.

Func<bool, int> f = b => b ? 1 : 0;
Func<int, string> h = a => $"v{a + 10}";
var transformed = Lift(f, h);
Console.WriteLine($"{transformed(false)},{transformed(true)}");
var recovered = Lift(f, (int a) => a);
Console.WriteLine($"{recovered(false)},{recovered(true)}");
static Func<B, X> Lift<A, B, X>(Func<B, A> f, Func<A, X> h)
    => b => h(f(b));

기대 표준 출력:

v10,v11
0,1

6. 모형의 경계

집합값 함자 범주의 모든 객체가 Hom(A,−)인 것은 아닙니다. 완충실 매장은 원래 객체 쌍 사이 사상 구조를 손실 없이 보존하지만 본질적 전사를 자동으로 주지 않습니다. 두 객체의 Hom 관찰 함자가 자연동형이면 완충실성으로 그 동형과 역을 원래 범주로 되돌려 두 객체의 동형을 얻습니다. 동일한 C# 타입이나 메모리 주소를 뜻하지 않습니다.

C# Lift는 f를 이미 인자로 받은 방향을 구현합니다. 임의 자연변환을 인자로 받아 모든 X에 대해 검사하는 범용 라이브러리가 아닙니다. 유한 표 테스트는 정리의 일부 사례이며 자연성·모든 객체·모든 사상이라는 가정을 대체하지 않습니다.

7. 확인 문제

Nat(Hom(A,−),Hom(B,−))에 대응하는 사상은?
공변 Hom으로 만든 매장은 반변입니다.
완충실은 무엇의 전단사인가요?
객체에 대한 전사성을 요구하지 않습니다.
원래 f를 복원하는 관찰은?
Y(f)(id_A)=f입니다.
상수 관찰에서 f와 g가 같으면?
모든 관찰과의 일관된 관계를 알아야 합니다.

8. 구현 실습

실습 A · 네 함수의 복원

Bool→Bool의 네 함수를 표로 열거하고 항등 관찰로 복원하세요.

기대 출력:

False,False
False,True
True,False
True,True
힌트

두 입력의 출력을 독립적으로 고릅니다.

해답 · 별도 Program.cs 전체
foreach (bool a in new[] { false, true })
foreach (bool b in new[] { false, true })
{
    Func<bool, bool> f = x => x ? b : a;
    Func<bool, bool> observation = x => x;
    Console.WriteLine($"{observation(f(false))},{observation(f(true))}");
}

네 표가 서로 다르므로 이 유한 예제의 충실성을 직접 확인할 수 있습니다.

실습 B · 합성 방향

f(n)=n+1, g(n)=2n에 대해 관찰을 전처리할 때 h∘f∘g와 (h∘f)∘g를 비교하세요.

기대 출력:

6
6
힌트

h(n)=n−3을 사용하세요.

해답 · 별도 Program.cs 전체
Func<int,int> f = x => x + 1, g = x => 2 * x, h = x => x - 3;
Func<int,int> fg = x => f(g(x));
Func<int,int> hf = x => h(f(x));
Console.WriteLine(h(fg(4)));
Console.WriteLine(hf(g(4)));

함수 합성 결합법칙이 Hom 함자의 합성 보존을 보장합니다.

9. 핵심 정리

  • 공변 Hom(A,−) 매장은 Cᵒᵖ에서 함자 범주로 갑니다.
  • 완충실성은 Hom별 전단사이며 객체별 전단사가 아닙니다.
  • 항등 관찰은 사상을 복원하고 자연성은 모든 성분을 강제합니다.
  • 모든 관찰 함자가 자연동형이면 원래 객체들도 동형입니다.
