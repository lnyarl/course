대수적 인터페이스의 메서드 서명만으로는 법칙이 정해지지 않습니다. 로비어 이론은 변수 선택·복제·삭제와 연산의 방정식을 유한 곱 범주에 함께 기록합니다.

1. 연산의 개수보다 방정식이 중요하다

모노이드에는 이항 연산 m:A×A→A와 영항 연산 e:1→A가 있습니다. 영항이라는 말은 인수가 없다는 뜻이며 공역 값이 없다는 뜻이 아닙니다. 결합법칙과 좌우 단위 법칙을 모든 값에 대해 요구합니다. 군은 여기에 역원 연산 A→A와 방정식을 더합니다.

이 언어는 유한 개 인수의 연산과 전칭 등식을 다룹니다. 0이 아닌 경우에만 역원이 있다는 체의 보통 공리는 조건을 포함하므로 같은 단일 종류의 등식 이론에 그대로 넣을 수 없습니다. 연산의 서명과 그 연산 사이의 등식을 구분하는 것이 출발점입니다.

실험 1 · 자유 모노이드 항의 평가

x,y의 단어는 괄호를 지운 모노이드 항입니다. 빈 단어 ε도 허용하고 대입 후 문자 순서를 보존합니다.

2. 유한 곱으로 모든 인수 개수를 표현하기

로비어 이론 L은 작은 유한 곱 범주이며 객체들이 하나의 지정 객체 1의 거듭제곱 0,1,2,…로 주어집니다. 여기서 숫자 0은 1⁰인 말단 객체이고, 숫자 1은 이론의 생성 객체입니다. 구조 함자 J:FinSet_skelᵒᵖ→L은 객체에서 항등이며 유한 곱을 보존합니다.

L의 n→1 사상은 n변수 항(연산)이고 n→m 사상은 m개의 n변수 항의 튜플입니다. 사영, 대각선, 말단으로 가는 사상이 변수의 선택·복제·삭제를 표현합니다. FinSet의 함수 방향을 뒤집으면 주입이 사영이 되며, 이 골격이 모든 이론에서 공통된 변수 조작을 제공합니다.

3. 사상의 같음으로 방정식을 기록하기

모노이드 이론에서 m∘(m×id)=m∘(id×m):3→1은 결합법칙입니다. 영항 사상 e:0→1을 사용한 m∘(e×id)=id, m∘(id×e)=id는 단위 객체와의 표준 동형을 생략한 단위 법칙입니다. 괄호 모양이 달라도 L에서 같은 사상으로 취급됩니다.

자유 모노이드의 n변수 항은 변수 알파벳의 유한 단어로 정규화할 수 있습니다. 빈 단어는 e이고 연결은 m입니다. 모노이드에는 교환법칙이 없으므로 xy와 yx는 일반적으로 다릅니다. 첫 실험은 변수에 구체적 문자열을 대입하고 괄호 제거와 순서 보존을 보여 줍니다.

실험 2 · 유한 모델의 방정식 전수 검사

운반 집합 {0,1,2}, 단위 후보 0에서 결합법칙 27개와 좌우 단위 6개를 모두 계산합니다.

4. 모델은 유한 곱 보존 함자

Set 값 모델은 유한 곱 보존 함자 M:L→Set입니다. 운반 집합 A=M(1), M(n)≅Aⁿ이고 각 사상을 실제 연산 함수로 보냅니다. 범주에서 같은 사상은 같은 함수로 가므로 이론의 방정식이 모델에서 성립합니다. 임의의 함자는 이 의미를 충분히 보존하지 않습니다.

모델 사이 자연변환은 대수 준동형입니다. 곱과의 호환 때문에 모든 성분은 1 성분 h:A→B로 결정되며, 자연성은 h가 모든 연산을 보존한다는 뜻입니다. 두 번째 실험은 {0,1,2}의 덧셈 mod 3과 뺄셈 mod 3을 비교해 같은 이항 함수 타입이 결합법칙·단위 법칙을 보장하지 않음을 확인합니다.

5. 항의 합성은 동시 치환

s:n→m은 m개의 n변수 항이고 t:m→1은 m변수 항입니다. 합성 t∘s:n→1은 t의 각 변수를 s의 해당 항으로 동시에 치환합니다. 세 번째 위젯은 x,y의 단어에 각 대입 단어를 치환하며 중복과 빈 단어까지 처리합니다.

Set에서 로비어 이론은 finitary 모나드와 대응합니다. finitary는 필터된 쌍대극한을 보존한다는 조건이며 모든 모나드에 아무 조건 없이 대응한다는 말이 아닙니다. 유한 인수의 등식 이론과 잘 맞는 범위입니다. C# 예제는 모노이드 항의 유한 문자열 모델이며, 컴파일러가 전체 이론의 모든 방정식을 검사해 주는 것은 아닙니다.

실험 3 · 항의 동시 치환

x,y의 단어에서 x와 y를 다른 단어로 동시에 바꿉니다. 새 문자열을 다시 재귀 치환하지 않습니다.

6. 실행 가능한 전체 C#

C# 12 / .NET 8의 BCL만 사용하는 전체 Program.cs입니다. examples/Ch30/Program.cs에 같은 프로그램이 있습니다. 웹 위젯은 같은 수학 규칙의 JavaScript 계산이며 C# 실행기가 아닙니다.

using System;
using System.Linq;
static string Evaluate(string term, string x, string y) => string.Concat(term.Select(c => c == 'x' ? x : y));
Console.WriteLine($"xyx = {Evaluate("xyx", "A", "B")}");
Console.WriteLine($"empty = [{Evaluate("", "A", "B")}]");
string substitute = Evaluate("xyx", "xy", "yx");
Console.WriteLine($"substitution = {substitute}");
Console.WriteLine($"associative = {("A" + "B") + "C" == "A" + ("B" + "C")}");

기대 표준 출력:

xyx = ABA
empty = []
substitution = xyyxxy
associative = True

7. 확인 문제

이론에서 0 객체는?
Set 모델은 이것을 한 원소 집합 A⁰로 보냅니다.
Set 값 모델에 필요한 보존 조건은?
n변수 객체를 Aⁿ로 해석해야 하기 때문입니다.
모노이드 이론에서 xy와 yx는?
교환법칙은 모노이드 정의에 포함되지 않습니다.
Set에서 로비어 이론과 대응하는 모나드는?
유한 인수 등식 연산이라는 범위가 finitary 조건과 대응합니다.

8. 직접 구현하는 실습

실습 A · 치환과 평가의 합성

t=xy, x↦yx, y↦xx의 동시 치환 결과를 A,B로 평가하고, 먼저 각 대입 항을 평가한 결과와 비교하세요.

기대 결과:

BAAA
composition = True
힌트

동시 치환은 새로 삽입한 x를 또 치환하지 않습니다.

해답 · 별도 Program.cs로 실행하는 전체 프로그램
using System;
using System.Linq;
static string E(string t, string x, string y) => string.Concat(t.Select(c => c == 'x' ? x : y));
string left = E(E("xy", "yx", "xx"), "A", "B");
string right = E("xy", E("yx", "A", "B"), E("xx", "A", "B"));
Console.WriteLine(left);
Console.WriteLine($"composition = {left == right}");

함자 모델은 항의 합성을 함수 합성으로 보존합니다.

실습 B · 반례를 찾는 모델 검사

뺄셈 mod 3의 결합법칙 첫 반례를 사전식 순서로 찾으세요.

기대 결과:

counterexample = 0,0,1
힌트

음수를 피하도록 (a-b+3)%3을 사용합니다.

해답 · 별도 Program.cs로 실행하는 전체 프로그램
using System;
static int Op(int a, int b) => (a - b + 3) % 3;
bool done = false;
for (int a = 0; a < 3 && !done; a++)
    for (int b = 0; b < 3 && !done; b++)
        for (int c = 0; c < 3 && !done; c++)
            if (Op(Op(a, b), c) != Op(a, Op(b, c)))
            {
                Console.WriteLine($"counterexample = {a},{b},{c}");
                done = true;
            }

한 반례만으로 이 연산이 모노이드 모델이 아니라는 결론이 충분합니다. 모든 표본 통과는 이 유한 운반 집합에 대해서만 완전한 검사입니다.

핵심 요약

로비어 이론은 유한 곱과 사상의 등식으로 연산·변수·법칙을 기록합니다. 모델은 유한 곱 보존 함자이며 항의 합성은 동시 치환입니다.
