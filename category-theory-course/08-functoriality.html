1. 자료형 구조에서 Map을 얻기

7장의 Map은 타입 인수 하나를 바꾸었습니다. 곱 (A,B)나 Either<A,B>에는 바꿀 수 있는 자리가 둘입니다. 각 자리의 타입을 독립적으로 바꾸는 두 함수를 받으면 전체 구조의 사상 작용을 구성할 수 있습니다. 원문은 이를 곱·합으로 만든 자료형 전체로 확장합니다.

상수 타입 Const<C,A>에서 A는 값에 쓰이지 않으므로 Map은 C를 유지합니다. Identity<A>는 A를 한 겹 감싸므로 Map은 안의 A를 바꿉니다. 이 작은 함자들과 곱·합·합성을 조합하면 복합 자료형의 함자 작용을 체계적으로 만들 수 있습니다.

2. 이변함자와 두 좌표

이변함자 F:C×D→E는 객체 쌍과 사상 쌍을 옮깁니다. f:A→A′, g:B→B′가 있으면 Bimap(f,g):F(A,B)→F(A′,B′)입니다. 항등 쌍을 보존하고 좌표별 합성도 보존해야 합니다.

Bimap(id,id)=id
Bimap(f₂∘f₁,g₂∘g₁)=Bimap(f₂,g₂)∘Bimap(f₁,g₁)

곱에서는 각 성분에 각 함수를 적용합니다. 합에서는 실제 태그에 맞는 함수 하나만 적용합니다. 타입 인수 둘이 있다고 언제나 이변함자인 것은 아닙니다. 어떤 자리가 함수 입력으로 쓰이면 다음 절의 반변성이 필요할 수 있습니다.

3. Writer와 고정된 인수

Writer<A>=(A,Log)에서 Log를 고정하면 Map은 A에만 함수를 적용하고 로그를 그대로 둡니다. 이는 4장의 두 Writer 함수를 합칠 때 로그를 이어 붙이는 연산과 다릅니다. 함자의 사상 작용과 클레이슬리 합성은 서로 다른 타입 시그니처를 가집니다.

곱의 한 인수를 고정해 한 변수의 함자를 얻는 방식은 일반적입니다. 반대로 어떤 타입 인수가 아예 사용되지 않는 상수 함자도 정당합니다. 그래서 타입 변수의 개수만 세기보다 실제 값 구조와 화살표를 그려야 합니다.

4. 반변: Predicate로 함수를 거꾸로 옮기기

Predicate<A>=A→Bool이라고 합시다. f:A→B가 있고 B를 검사하는 p:B→Bool이 있다면 p∘f는 A를 검사합니다. 따라서 사상 f는 Predicate<B>→Predicate<A>로 옮겨집니다. 입력 함수의 방향과 타입 생성자가 옮기는 방향이 반대입니다.

Contramap(f,p)=p∘f
Contra(g∘f)=Contra(f)∘Contra(g)

실제 실행은 A값→f→B값→p→Bool 순서입니다. “반대”란 값을 시간을 거슬러 실행한다는 뜻이 아니라 Predicate 타입 사이의 사상 방향을 말합니다. 반변 함자는 보통 함자 Cᵒᵖ→D로 표현할 수 있습니다.

실험 2 · 입력 전처리로 검사 재사용

길이 검사를 문자열 검사로 바꿉니다.

5. 프로함자: 입력은 반변, 출력은 공변

함수 타입 P(A,B)=A→B는 첫 인수에서 반변, 둘째에서 공변입니다. 기존 h:A→B 앞에 pre:A′→A를 붙이고 뒤에 post:B→B′를 붙이면 A′→B′ 함수를 얻습니다. 이것이 Dimap입니다.

Dimap(pre,post,h)=post∘h∘pre
P:Cᵒᵖ×D→Set

입력을 받는 자리는 원하는 새 타입에서 기존 타입으로 변환해야 합니다. 출력 자리는 기존 결과에서 새 결과로 변환합니다. 양쪽에 같은 방향의 “Map 두 번”을 붙이면 타입이 안 맞는 이유가 여기 있습니다. 원문은 이 구조를 일반 범주의 Hom 프로함자로 연결합니다.

실험 3 · 함수의 Dimap

문자열 길이→제곱→offset 더하기를 분리합니다.

6. Hom의 함자성과 언어의 분산

국소적으로 작은 범주 C에서 Hom(A,B)는 사상들의 집합입니다. 첫 자리를 고정하면 후합성으로 공변 함자 Hom(A,−), 둘째를 고정하면 전합성으로 반변 함자 Hom(−,B)를 얻습니다. 둘을 합친 Hom:Cᵒᵖ×C→Set이 대표적인 프로함자입니다.

C#의 Func<in A,out B>와 분산 어노테이션은 관련된 입력·출력 방향을 반영하지만, 컴파일러의 타입 대입 가능성만으로 임의의 사용자 구현이 함자 법칙을 만족한다고 증명하지는 않습니다. 이 장에서는 구체적인 순수 함수와 식으로 법칙을 설명합니다.

7. 방향을 먼저 적는 구현 습관

고차 함수 이름을 외우기 전에 원래 함수와 새 함수의 정의역·공역을 적으세요. Bimap은 두 좌표를 같은 방향으로, Contramap은 입력 쪽을 반대 방향으로, Dimap은 입력과 출력을 서로 다르게 처리합니다.

예제의 문자열은 null을 제외하고 정수는 표시한 작은 범위에서 계산합니다. 일반 C# 함수의 예외·변이·평가 시점까지 자동으로 순수 함수 범주의 법칙에 넣지 않습니다. 유한 실험은 방향 실수를 찾고 정의를 이해하기 위한 것이며 임의 범주의 정리 자체를 실행으로 증명한 것은 아닙니다.

전체 C# 프로그램

C# 12 / .NET 8, 외부 패키지 없는 전체 Program.cs입니다. examples/Ch08에서 dotnet run으로 실행합니다. 이 예제는 명시한 순수 값 모델을 구현합니다. C# 전체의 종료·순수성을 타입이 증명한다는 뜻은 아닙니다.

internal static class Program
{
    static (C, D) Bimap<A, B, C, D>((A, B) pair, Func<A, C> f, Func<B, D> g) => (f(pair.Item1), g(pair.Item2));
    static Func<A, bool> Contra<A, B>(Func<A, B> f, Func<B, bool> p) => a => p(f(a));
    static Func<X, Y> Dimap<X, A, B, Y>(Func<X, A> pre, Func<B, Y> post, Func<A, B> f) => x => post(f(pre(x)));
    static void Main()
    {
        var pair = Bimap((2, "abc"), n => n + 1, s => s.Length);
        Console.WriteLine($"bimap = ({pair.Item1},{pair.Item2})");
        Func<string, int> length = s => s.Length;
        Func<int, bool> large = n => n > 2;
        Console.WriteLine($"predicate(abcd) = {Contra(length, large)("abcd")}");
        Func<int, int> twice = n => n * 2;
        Func<int, string> label = n => $"v={n}";
        Console.WriteLine($"dimap(abcd) = {Dimap(length, label, twice)("abcd")}");
    }
}

기대 출력:

bimap = (3,3)
predicate(abcd) = True
dimap(abcd) = v=8

핵심 요약

  • 이변함자는 두 공변 좌표를 독립적으로 옮깁니다.
  • 반변성은 타입 사이 사상의 방향을 뒤집습니다.
  • 함수의 Dimap은 입력 전처리와 출력 후처리입니다.

직접 구현하는 실습

실습 1 · 반변 합성의 순서

문자열 길이 f와 두 배 g, n>6 검사를 사용해 반변 합성 법칙을 확인하세요.

기대 결과: same = True

힌트

검사 p 앞에 g를 붙인 뒤 f를 붙입니다.

해답 · 독립 실행 Program.cs
Func<string, int> f = s => s.Length;
Func<int, int> g = n => n * 2;
Func<int, bool> p = n => n > 6;
Func<string, bool> left = s => p(g(f(s)));
Func<int, bool> pg = n => p(g(n));
Func<string, bool> right = s => pg(f(s));
Console.WriteLine($"same = {new[] { "", "ab", "abcd" }.All(s => left(s) == right(s))}");

string→길이→제곱→문자열 접두사 순서로 함수를 적응시키세요.

기대 결과: #9

힌트

Dimap은 기존 제곱 함수를 고치지 않습니다.

해답 · 독립 실행 Program.cs
Func<int, int> square = n => n * n;
Func<string, int> pre = s => s.Length;
Func<int, string> post = n => $"#{n}";
Func<string, string> adapted = s => post(square(pre(s)));
Console.WriteLine(adapted("abc"));
