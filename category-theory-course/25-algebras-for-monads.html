1. 효과를 해석하는 함수에 법칙을 더하기

모나드 (T,η,μ)가 범주 C 위에 주어졌다고 합시다. T-대수는 운반 객체 A와 a:T A→A입니다. 단순한 F-대수와 달리 T의 두 자연변환과 호환되는 두 방정식을 요구합니다. 단위를 평가해 원래 값으로 돌아오고, 이중 문맥을 해석하는 두 방법이 같아야 합니다.

첫 법칙은 a∘η_A=id_A입니다. 둘째는 a∘μ_A=a∘T a이며 두 경로 모두 T(T A)→A입니다. 왼쪽은 문맥을 먼저 합치고, 오른쪽은 내부 문맥들을 먼저 평가합니다. T a:T(T A)→T A의 정의역·공역을 확인하면 식의 각 단계가 명확해집니다.

실험 1 · 중첩 리스트를 해석하는 두 경로

선택한 대수로 [[1,2],[],[3]] 또는 다른 중첩 리스트를 계산합니다.

2. 리스트 모나드의 대수와 모노이드

리스트 모나드는 η(x)=[x], μ=Concat입니다. 정수 덧셈의 대수 a(xs)=Sum(xs)는 [x]를 x로 보내고, 중첩 리스트를 펴서 합치든 각 리스트의 합을 합치든 결과가 같습니다. 공백 리스트를 0으로 해석하는 것도 중요합니다.

Set에서 리스트 모나드의 대수는 모노이드와 대응합니다. 대수에서 e=a([]), x⋆y=a([x,y])를 복원하면 모노이드 법칙을 얻으며, 모노이드에서 리스트 fold를 만들면 두 대수 법칙을 얻습니다. 길이를 정수로 반환하는 함수 Length:List(Int)→Int는 운반 타입이 같아도 [7]을 1로 보내므로 단위 법칙부터 실패합니다.

3. 아일렌베르크–무어 범주

T-대수 사이 사상 h:(A,a)→(B,b)는 C의 사상 h:A→B로서 h∘a=b∘T h를 만족합니다. 대수들과 이 준동형들은 아일렌베르크–무어 범주 C^T를 만듭니다. 단순히 T A→A 타입을 갖는 모든 함수의 범주가 아닙니다.

망각 함자 U:C^T→C는 구조를 잊고 A를 반환합니다. 자유 함자 F:C→C^T는 X를 (T X,μ_X)로 보냅니다. F⊣U이고 U F=T입니다. 수반으로부터 얻는 모나드는 원래 모나드이며, 클레이슬리 범주에서 얻는 또 다른 수반과 구분해야 합니다. 한 모나드를 유도하는 수반이 하나뿐인 것은 아닙니다.

실험 2 · 대수 준동형 후보

덧셈 모노이드의 리스트 대수 사이에서 h(n)=k·n+b를 검사합니다. 공백 리스트가 b의 영향을 드러냅니다.

4. 코모나드의 코대수

코모나드 (W,ε,δ)에 대해 코대수 c:A→W A는 ε_A∘c=id_A, δ_A∘c=W c∘c를 만족합니다. 모든 화살표를 뒤집은 모양이므로 평가 함수와 생성 함수의 방향을 섞지 않아야 합니다.

Store S A=(S→A,S) 코모나드에서 c:A→Store S A를 view:A→S, set:A×S→A로 읽으면 렌즈 법칙이 나타납니다. get-put: set(a,view(a))=a, put-get: view(set(a,s))=s, put-put: set(set(a,s),t)=set(a,t)입니다. Store 코모나드 코대수의 두 식을 성분으로 풀면 이 세 법칙이 됩니다.

5. 법칙과 C# 구현의 경계

아래 프로그램은 BigInteger 리스트 합계로 정수 오버플로를 피합니다. ListSum을 재귀적 효과 해석의 구체적인 한 예로 사용하며 HKT를 지원하는 보편적인 T-대수 인터페이스라고 부르지 않습니다. C# 제네릭 타입만으로 대수 법칙이나 모든 자연성을 강제할 수 없습니다.

위젯은 선택한 중첩 리스트 및 유한한 준동형 후보를 계산합니다. 법칙은 모든 입력에 대한 명제입니다. 단위만 검사해 합격했다고 결론 내리거나, 비어 있지 않은 리스트만 검사해서 공백 리스트와 관련된 조건을 빠뜨리면 안 됩니다. 렌즈 실험도 선택한 필드 갱신의 구체적 계산입니다.

실험 3 · 필드 렌즈의 세 법칙

문서 (이름,점수)에서 점수 렌즈를 비교합니다. 잘못된 setter는 요청한 점수에 1을 더합니다.

6. 실행 가능한 전체 C#

C# 12 / .NET 8의 BCL만 사용하는 전체 Program.cs입니다. examples/Ch25/Program.cs에 같은 프로그램이 있습니다. 웹 위젯은 같은 수학 규칙의 JavaScript 계산이며 C# 실행기가 아닙니다.

using System;
using System.Linq;
using System.Numerics;
static class Program
{
    static BigInteger Algebra(BigInteger[] xs) => xs.Aggregate(BigInteger.Zero, (a, b) => a + b);
    static void Main()
    {
        BigInteger[][] nested = [[1, 2], [], [3]];
        BigInteger left = Algebra(nested.SelectMany(xs => xs).ToArray());
        BigInteger right = Algebra(nested.Select(Algebra).ToArray());
        Console.WriteLine($"flatten then sum = {left}");
        Console.WriteLine($"sum then sum = {right}");
        Console.WriteLine($"unit(7) = {Algebra([7])}");
        Console.WriteLine($"length unit(7) = {new[] { 7 }.Length}");
    }
}

기대 표준 출력:

flatten then sum = 6
sum then sum = 6
unit(7) = 7
length unit(7) = 1

7. 확인 문제

T-대수가 F-대수에 더하는 것은?
aη=id와 aμ=aTa는 모나드의 생성·중첩 구조를 일관되게 해석합니다.
Length:List(Int)→Int의 문제는?
타입은 맞지만 타입만으로 법칙이 보장되지 않습니다.
자유 T-대수는?
구조 사상은 T(T X)→T X이어야 합니다.
정상 렌즈의 put-put은?
같은 위치에 연속으로 쓸 때 마지막 쓰기가 앞선 쓰기를 덮어씁니다.

8. 직접 구현하는 실습

실습 A · 곱셈 대수

리스트 곱셈의 공백 값을 1로 두고 [[],[2,3]]의 두 평가 경로를 구현하세요.

기대 결과:

flat = 6
nested = 6
힌트

각 내부 공백 리스트는 1이며 SelectMany는 공백 부분을 제거합니다.

해답 · 별도 Program.cs로 실행하는 전체 프로그램
using System;
using System.Linq;
static int Product(int[] xs) => xs.Aggregate(1, (a, b) => a * b);
int[][] x = [[], [2, 3]];
Console.WriteLine($"flat = {Product(x.SelectMany(a => a).ToArray())}");
Console.WriteLine($"nested = {Product(x.Select(Product).ToArray())}");

공백 값을 0으로 바꾸면 [[2]] 같은 단위 표본에서도 문제가 생깁니다. 모노이드 단위는 곱셈에서 1입니다.

실습 B · 점수 렌즈

불변 튜플의 Score 필드만 바꾸는 Set을 만들고 세 법칙을 검사하세요.

기대 결과:

get-put = True
put-get = True
put-put = True
힌트

with 대신 새 튜플 (기존 이름,새 점수)을 반환해도 됩니다.

해답 · 별도 Program.cs로 실행하는 전체 프로그램
using System;
static (string Name, int Score) Set((string Name, int Score) a, int s) => (a.Name, s);
var a = (Name: "Kim", Score: 3);
Console.WriteLine($"get-put = {Set(a, a.Score) == a}");
Console.WriteLine($"put-get = {Set(a, 8).Score == 8}");
Console.WriteLine($"put-put = {Set(Set(a, 5), 8) == Set(a, 8)}");

모든 이름·점수에서 첫 성분을 보존하고 둘째 성분을 교체한다는 정의로 일반 법칙도 증명할 수 있습니다.

핵심 요약

T-대수는 모나드의 단위와 중첩 제거를 존중하는 해석입니다. 리스트 대수는 모노이드, Store 코대수는 정상 렌즈와 연결되며 각각 별도의 법칙이 필요합니다.
