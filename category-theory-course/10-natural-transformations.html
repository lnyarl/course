1. 함자 사이의 화살표

F,G:C→D가 두 함자라면 같은 객체 A를 F(A),G(A)로 각각 옮깁니다. 자연변환 α:F⇒G는 모든 A마다 D의 사상 α_A:F(A)→G(A)를 고른 가족입니다. A는 C의 객체이고 α_A는 D의 사상입니다. 하나의 값 변환과 전체 타입에 걸친 가족을 구별해야 합니다.

아무 성분 가족이나 허용하면 F와 G의 사상 작용을 무시하게 됩니다. 따라서 f:A→B마다 두 경로가 같은 자연성 조건을 요구합니다. 이 식이 자연변환의 핵심이며 아래의 모든 실험에서 확인할 대상입니다.

G(f)∘α_A = α_B∘F(f)
두 경로 모두 F(A)→G(B)

2. 리스트의 첫 값은 자연스럽게 옮겨진다

Head:List<A>→Option<A>는 빈 리스트면 None, 아니면 첫 원소를 Some으로 돌려줍니다. 모든 원소에 f를 적용한 뒤 Head를 구하면 처음 값에 f가 적용됩니다. 먼저 Head를 구해 Option의 Map으로 f를 적용해도 같습니다. 빈 리스트에서는 양쪽 모두 None입니다.

이는 첫 원소를 고르는 기준이 A의 값 자체를 검사하지 않기 때문에 가능합니다. 반대로 “최댓값”은 타입의 순서 구조에 의존합니다. int에서라도 f를 부호 반전으로 고르면 최대를 고른 뒤 반전한 값과 반전한 뒤 최대를 고른 값이 다릅니다.

3. 다형성과 자연성의 조건

원문은 충분한 매개변수적 다형성 아래 ∀A.F(A)→G(A) 형태의 순수한 함수가 자연성 정리를 준다고 설명합니다. 하나의 정의가 값의 구체적인 타입을 들여다보지 않고 작동한다는 제약이 중요합니다. 단순히 제네릭 메서드 문법이 있다는 뜻은 아닙니다.

C#은 typeof·리플렉션·런타임 타입 검사·예외·변이 같은 관찰을 허용합니다. 따라서 C# 제네릭 함수를 선언했다고 자동으로 자연성이 증명되지는 않습니다. 이 교재에서는 성분과 사각형을 실제로 적고, 일반 논증에 필요한 순수성·균일성 조건을 명시합니다.

반변 함자 사이에도 Cᵒᵖ를 출발 범주로 보면 자연변환을 정의할 수 있습니다. 예를 들어 A→Bool 검사의 결과를 T/F 문자열로 바꾸는 변환은 입력 전처리와 교환합니다. 반면 A→A는 같은 A가 입력·출력에 동시에 나타나 일반적인 Map이나 Contramap을 그대로 만들 수 없습니다. 이런 혼합 위치를 다루는 더 일반적인 dinaturality는 엔드 장에서 이어집니다.

4. 자연동형과 한쪽 역변환

자연변환의 모든 성분이 동형이면 자연동형입니다. 역 성분들의 가족도 자연성으로 연결됩니다. Option을 길이 0 또는 1의 리스트로 바꾸고 Head로 되돌리면 Option에서는 항등이지만, 임의 리스트에서는 나머지 원소가 사라집니다.

따라서 양쪽 변환이 자연적이라는 사실만으로 자연동형이 되는 것은 아닙니다. 두 합성이 각각 전체 정의역에서 항등이어야 합니다. 리스트를 길이 0·1로 제한한 다른 함자를 정하면 이야기가 달라질 수 있지만, 원래 List 전체와 Option이 동형이라는 주장은 아닙니다.

5. Reader의 평가도 자연변환

R을 고정한 Reader<R,A>에서 환경 r₀ 하나를 고르면 α_A(reader)=reader(r₀)는 Reader<R,−>⇒Identity 자연변환입니다. Reader에 Map(f)를 적용한 후 평가하면 f(reader(r₀)), 먼저 평가한 후 f를 적용해도 같은 식입니다.

자연변환을 “컨테이너의 포장만 바꾸기”라고 생각하는 비유는 유용하지만 전부는 아닙니다. Reader는 함수이고, Const 함자로 가는 길이 계산은 형태 정보를 결과로 만들 수도 있습니다. 일반 정의는 객체마다 정한 성분과 자연성 사각형입니다.

6. 함자 범주와 수직·수평 합성

고정한 C,D 사이의 함자들을 객체, 자연변환을 사상으로 두면 함자 범주 [C,D]를 얻습니다. α:F⇒G와 β:G⇒H의 수직 합성은 (β·α)_A=β_A∘α_A입니다. 항등변환은 각 F(A)의 항등사상입니다. 결합법칙은 성분 사상의 결합법칙으로부터 옵니다.

함자도 합성할 수 있으므로 자연변환을 옆으로 합치는 수평 합성도 있습니다. α:F⇒F′, β:G⇒G′에 대해 (β*α)_A=β_(F′A)∘G(α_A)=G′(α_A)∘β_(FA)입니다. 두 표현의 같음은 β의 자연성입니다. 수직·수평 합성은 서로 호환되는 교환 법칙을 만족합니다.

7. Cat와 2범주의 첫 모습

작은 범주를 객체, 함자를 1차 사상, 자연변환을 2차 사상으로 보면 Cat는 2범주의 예입니다. 객체를 옮기는 것, 그 옮김을 서로 비교하는 것, 비교를 두 방향으로 합치는 것이 한 구조 안에 놓입니다. 크기 문제를 피하려면 다루는 범주들의 범위를 적절히 고정해야 합니다.

원문은 함자 범주를 함수 타입과 연결하기도 합니다. 함자 범주 [C,D]는 Cat에서 지수 객체 역할을 하며, 평가 함자는 함자와 C의 객체를 받아 D의 객체를 줍니다. 이 장의 코드는 이 일반 고차 구조를 C#의 지원되지 않는 고차 타입 문법으로 흉내 내지 않고 구체적인 자연변환을 실행합니다.

전체 C# 프로그램

C# 12 / .NET 8, 외부 패키지 없는 전체 Program.cs입니다. examples/Ch10에서 dotnet run으로 실행합니다. 이 예제는 명시한 순수 값 모델을 구현합니다. C# 전체의 종료·순수성을 타입이 증명한다는 뜻은 아닙니다.

readonly record struct Option<T>(bool HasValue, T Value);
internal static class Program
{
    static Option<B> Map<A, B>(Option<A> x, Func<A, B> f) => x.HasValue ? new(true, f(x.Value)) : new(false, default !);
    static Option<A> Head<A>(IReadOnlyList<A> x) => x.Count == 0 ? new(false, default !) : new(true, x[0]);
    static A[] Pack<A>(Option<A> x) => x.HasValue ? [x.Value] : [];
    static void Main()
    {
        int[] xs = [1, 3];
        Func<int, int> negate = n => -n;
        var left = Map(Head(xs), negate);
        var right = Head(xs.Select(negate).ToArray());
        Console.WriteLine($"head natural = {left == right}");
        Console.WriteLine($"empty natural = {Map(Head(Array.Empty<int>()), negate) == Head(Array.Empty<int>())}");
        Console.WriteLine($"max natural = {negate(xs.Max()) == xs.Select(negate).Max()}");
        var some = new Option<int>(true, 3);
        Console.WriteLine($"option roundtrip = {Head(Pack(some)) == some}");
    }
}

기대 출력:

head natural = True
empty natural = True
max natural = False
option roundtrip = True

핵심 요약

  • 자연변환은 모든 객체에서의 성분과 모든 사상에서의 자연성 조건입니다.
  • C#의 제네릭 문법만으로 매개변수성이나 자연성이 증명되지는 않습니다.
  • 자연동형은 두 방향의 역성까지 필요하며 자연변환은 두 방향으로 합성됩니다.

자연성 사각형의 두 경로는?
Gf∘α_A와 α_B∘Ff를 비교합니다.

[1,3]에서 -3과 -1이 다릅니다.
Option→List→Option만 항등이면?

(β·α)_A=β_A∘α_A입니다.

실습 1 · 타입이 바뀌는 자연성

Some(3)에 int→string 변환을 적용하는 두 경로를 비교하세요.

힌트

먼저 리스트로 포장하거나 먼저 내부 값을 변환합니다.

해답 · 독립 실행 Program.cs
var source = new Option<int>(true, 3);
Func<int, string> f = n => $"v{n}";
string[] left = source.HasValue ? [f(source.Value)] : [];
var mapped = source.HasValue ? new Option<string>(true, f(source.Value)) : new Option<string>(false, "");
string[] right = mapped.HasValue ? [mapped.Value] : [];
Console.WriteLine($"natural = {left.SequenceEqual(right)}");

실습 2 · 양쪽 왕복은 다른 요구

Head와 Pack으로 Option과 List 양쪽 왕복을 검사하세요.

기대 결과: option = True / list = False

힌트

List에서는 두 원소를 넣어 보세요.

해답 · 독립 실행 Program.cs
static Option<T> Head<T>(T[] x) => x.Length == 0 ? new(false, default !) : new(true, x[0]);
static T[] Pack<T>(Option<T> x) => x.HasValue ? [x.Value] : [];
var some = new Option<int>(true, 1);
int[] xs = [1, 2];
Console.WriteLine($"option = {Head(Pack(some)) == some}");
Console.WriteLine($"list = {Pack(Head(xs)).SequenceEqual(xs)}");
