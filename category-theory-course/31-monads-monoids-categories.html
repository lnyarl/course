1. 사상 사이에도 사상이 있다

Cat의 0셀은 범주, 1셀은 함자, 2셀은 자연변환입니다. 고정한 A,B 사이의 1셀과 2셀은 Hom 범주 Cat(A,B)를 이룹니다. 2셀의 세로 합성은 같은 Hom 범주 안의 합성이며, 가로 합성은 인접한 1셀들을 따라 일어납니다.

엄격한 2범주는 1셀 합성의 결합·단위가 등식이고, 쌍범주(bicategory)는 이들이 가역적인 2셀인 결합자와 단위원 동형까지 성립합니다. 오각형·삼각형 coherence 및 2셀 합성과의 호환이 필요합니다. 보통 범주에 자연변환을 아무렇게나 덧붙였다는 설명으로는 충분하지 않습니다.

실험 1 · Span 합성의 당김

객체 A,B와 항등, f:A→B를 사용합니다. g:B→A를 추가하면 두 객체의 유일 사상 groupoid를 얻습니다. 합성 가능한 쌍을 전부 계산합니다.

2. endo-1셀의 모노이달 범주

0셀 A를 고정하면 B(A,A)는 모노이달 범주입니다. 객체는 A→A인 1셀, 사상은 그 사이의 2셀이고 텐서는 1셀 합성, 단위는 항등 1셀 I_A입니다. 따라서 이 Hom 범주 안의 모노이드 객체를 정의할 수 있습니다.

쌍범주의 모나드는 endo-1셀 T:A→A와 2셀 η:I_A⇒T, μ:T∘T⇒T입니다. 엄격한 경우 μ∘(μ⋆id_T)=μ∘(id_T⋆μ), μ∘(η⋆id_T)=id_T=μ∘(id_T⋆η)입니다. ⋆는 2셀의 가로 합성입니다. 일반 쌍범주에서는 정의역의 괄호와 단위를 맞추는 결합자·단위원 동형을 포함해 이 식을 읽어야 합니다.

3. Cat에서 복원하는 익숙한 모나드

Cat(A,A)의 객체는 자기함자이며 텐서는 함자 합성입니다. 여기서 η와 μ는 자연변환이므로 η_X:X→T X, μ_X:T(T X)→T X의 가족을 얻습니다. 따라서 기존 모나드가 쌍범주 모나드의 특수 경우로 복원됩니다.

리스트에서 η는 singleton, μ는 flatten입니다. 세 번째 실험은 중첩 문맥을 합치는 두 경로를 보여 줍니다. 리스트 원소 수준 계산으로 모든 자연성이나 모든 모나드의 coherence를 증명했다고 주장하지 않습니다. 모노이드는 Set의 곱 텐서에서, 모나드는 Cat의 endo-Hom에서 같은 모노이드 정의를 사용합니다.

실험 2 · 한 객체인 경우의 모노이드 법칙

화살표는 {0,1,2}이고 0을 항등 후보로 둡니다. 합성을 바꾸면 Span 모나드의 법칙이 성립하는지 계산합니다.

4. Span의 1셀 합성은 당김이다

Span(Set)의 0셀은 집합, A→B인 1셀은 span A←S→B입니다. 2셀은 두 끝을 보존하는 꼭짓점 함수입니다. A←S→B와 B←T→C를 합성하면 꼭짓점은 S×_B T={(s,t) | 오른쪽(s)=왼쪽(t)}입니다.

세 span을 합치는 두 괄호 방식은 ((s,t),u)와 (s,(t,u))라는 다른 쌍 구조를 만듭니다. 표준 재괄호 동형으로 연결되므로 Span은 자연스럽게 쌍범주입니다. 당김을 무시하고 S×T의 모든 쌍을 포함하면 중간 끝점이 맞지 않는 경로까지 합성되어 잘못된 구조가 됩니다.

5. Span의 모나드는 작은 범주다

0셀 Ob와 endo-span Ob←Ar→Ob를 고릅니다. 두 다리는 dom,cod입니다. η는 항등 span에서 이 span으로 가는 2셀이므로 각 객체 o에 dom(η(o))=o=cod(η(o))인 항등 화살표를 고릅니다. μ는 Ar×_Ob Ar→Ar인 꼭짓점 함수이므로 합성 가능한 두 화살표를 하나로 합칩니다.

2셀의 끝점 보존 조건은 합성의 시작과 끝을 보존하고, 모나드 단위·결합법칙은 바로 범주의 항등·결합법칙이 됩니다. Ob와 Ar가 집합이므로 작은 범주입니다. Ob가 한 원소이면 Ar 위에 모든 쌍의 합성이 가능한 모노이드를 복원합니다. 이것은 보통 범주 안의 자기함자를 고르는 것과 다른 층위입니다. C#에서는 두 객체의 유한 범주를 화살표 표로 구현해 확인합니다.

실험 3 · 2셀 μ의 결합법칙

3중 리스트에서 μ∘Tμ와 μ∘μT의 중간 문맥과 최종 결과를 계산합니다.

6. 실행 가능한 전체 C#

C# 12 / .NET 8의 BCL만 사용하는 전체 Program.cs입니다. examples/Ch31/Program.cs에 같은 프로그램이 있습니다. 웹 위젯은 같은 수학 규칙의 JavaScript 계산이며 C# 실행기가 아닙니다.

using System;
using System.Linq;
readonly record struct Arrow(string Name, int Dom, int Cod);
static class Program
{
    static void Main()
    {
        Arrow[] arrows = [new("idA", 0, 0), new("f", 0, 1), new("idB", 1, 1)];
        var pairs = from f in arrows from g in arrows where f.Cod == g.Dom select (f, g);
        Console.WriteLine($"pullback pairs = {pairs.Count()}");
        foreach (var (f, g) in pairs)
        {
            Arrow composite = arrows.Single(h => h.Dom == f.Dom && h.Cod == g.Cod);
            Console.WriteLine($"{g.Name} after {f.Name} = {composite.Name}");
        }
    }
}

기대 표준 출력:

pullback pairs = 4
idA after idA = idA
f after idA = f
idB after f = f
idB after idB = idB

7. 확인 문제

쌍범주 모나드의 η와 μ는?
T는 endo-1셀이고 η:I⇒T, μ:T∘T⇒T는 2셀입니다.
Span 합성에서 필요한 것은?
cod(f)=dom(g)인 쌍만 합성 가능합니다.
Span(Set)의 모나드가 주는 것은?
집합 Ob,Ar와 dom,cod,η,μ가 범주 구조를 정의합니다.
Ob가 한 원소이면 무엇을 복원하는가?
모든 두 화살표가 합성 가능하고 항등·결합법칙이 모노이드 법칙입니다.

8. 직접 구현하는 실습

실습 A · 끝점이 맞지 않는 쌍

세 화살표 idA,f,idB의 전체 9쌍에서 합성 가능한 쌍만 고르세요.

기대 결과:

composable = 4, rejected = 5
힌트

첫 화살표의 cod와 둘째 화살표의 dom을 비교합니다.

해답 · 별도 Program.cs로 실행하는 전체 프로그램
using System;
(int Dom, int Cod)[] a = [(0, 0), (0, 1), (1, 1)];
int good = 0, bad = 0;
foreach (var f in a) foreach (var g in a) if (f.Cod == g.Dom) good++; else bad++;
Console.WriteLine($"composable = {good}, rejected = {bad}");

곱 전체와 당김을 혼동하면 합성 불가능한 다섯 쌍을 잘못 포함합니다.

실습 B · 리스트 모나드의 결합법칙

3중 리스트 [[[1],[2,3]],[[4]]]에 두 중첩 제거 경로를 구현하세요.

기대 결과:

1,2,3,4
associative = True
힌트

내부 flatten을 Map한 뒤 flatten하거나 바깥 두 층을 먼저 flatten합니다.

해답 · 별도 Program.cs로 실행하는 전체 프로그램
using System;
using System.Linq;
int[][][] x = [[[1], [2, 3]], [[4]]];
int[] left = x.Select(group => group.SelectMany(xs => xs).ToArray()).SelectMany(xs => xs).ToArray();
int[] right = x.SelectMany(group => group).SelectMany(xs => xs).ToArray();
Console.WriteLine(string.Join(",", left));
Console.WriteLine($"associative = {left.SequenceEqual(right)}");

두 경로가 원소 순서를 같게 유지합니다. 이는 특정 입력의 계산 증거이며 일반 증명은 각 원소의 위치와 순서를 추적해 합니다.

핵심 요약

endo-1셀의 Hom 범주에서 모노이드를 취하면 쌍범주 모나드입니다. Cat에서는 보통 모나드, Span(Set)에서는 작은 범주, 한 객체 범주에서는 모노이드가 드러납니다.
