코스 목록

리눅스 커널 심화

기존 커널 지도에서 프로세스 제어, RT 지연, BPF 계측, 장치 수명, KVM, 파일 시스템 저장 경로로 내려갑니다. 소스·API 계약과 현재 환경의 관측을 분리하고 실제 실행하지 않은 값은 예상으로 표시합니다.

기존 코스 목차

  1. 시그널·pidfd와 로컬 IPC

    6장의 자식 생성·종료를 장기 실행 작업 감시로 연결합니다. 숫자 PID를 저장하는 방식, 시그널로 요청하는 방식, 파일 디스크립터로 대상을 참조하는 방식의 차이를 봅니다.

  2. PREEMPT_RT와 지연의 구성 요소

    11장에서 spinlock과 mutex의 문맥을 구분했습니다. RT 구성에서는 같은 락 이름의 구현과 IRQ의 실행 주체가 달라질 수 있어 지연을 분해하는 기준도 달라집니다.

  3. BPF의 검증·연결·이식성

    25장에서 BPF map 집계를 소개했습니다. 프로그램이 안전하게 로드됐다는 사실, 원하는 hook에 연결됐다는 사실, 수집한 지표가 질문에 맞는다는 사실을 이제 세 단계로 나눕니다.

  4. 드라이버 DMA와 제거 시 자원 회수

    24장의 miscdevice는 하드웨어 요청을 단순화했습니다. 실제 장치에서는 probe에서 얻은 MMIO·IRQ·DMA와 remove에서 끝내야 하는 비동기 참조를 함께 관리합니다.

  5. KVM VM·vCPU와 호스트 실행 경계

    23장에서 VM은 별도 게스트 커널을 실행한다고 배웠습니다. 이제 /dev/kvm의 디스크립터와 KVM_RUN의 복귀 이유를 통해 게스트 진행과 호스트 스케줄링을 연결합니다.

  6. VFS 객체에서 ext4 저널까지

    17장의 fd·열린 파일·inode 관계를 실제 파일 시스템의 저장 경로로 이어갑니다. 이름과 열린 참조의 수명, 캐시 데이터와 저널 transaction을 같은 객체라고 읽지 않습니다.
