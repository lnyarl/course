무엇을 배우나요?

기능 이름을 외우는 대신 실행 주체, 공유 자원, 대기 조건을 추적합니다. 마지막에는 느린 서버의 관측 증거를 보고 다음 조사 지점을 고릅니다.

어떻게 읽나요?

도식의 다음 단계를 예측하고 입력 조건을 바꿔 보세요. 설명을 읽은 뒤 Linux VM에서 관측합니다. 장당 45–90분은 읽기·개념 실험의 계획치이며, 소스 탐색과 실제 실습은 별도입니다.

움직이는 구조로 먼저 살펴보기

부모·자식의 페이지 공유, malloc 뒤의 첫 접근, 패킷 수신 경로를 단계별로 따라가세요. 각 장의 본문 도식은 확대할 수 있고, 시뮬레이터는 조건을 바꿔 결과를 비교할 수 있습니다.
