TCP/IP 전문가 과정

패킷이 비트로 바뀌어 전선을 지나고, 라우터를 거쳐, 다시 애플리케이션 데이터로 되돌아오기까지. 도식과 애니메이션, 직접 조작하는 시뮬레이터로 TCP/IP를 설명할 수 있는 수준까지 끌어올립니다.

학습 지도

왼쪽은 네트워크 계층 모델, 오른쪽은 각 계층을 다루는 장입니다. 개론(Part 1)은 아래에서 위로 한 번 올라가고, 심화(Part 2)는 전송 계층(TCP)을 깊게 판 뒤 다시 네트워크·보안·도구로 넓힙니다.

Part 1 · 개론

네트워크를 처음 체계적으로 배우거나, 아는 것을 정리하려는 분을 위한 과정. 각 계층의 역할과 핵심 프로토콜을 애니메이션으로 봅니다.

Part 2 · 심화

"왜 그렇게 설계되었는가"에 답하는 과정. TCP 내부 알고리즘, 라우팅 프로토콜, 보안, 실제 패킷 분석까지 다룹니다. 전문가라면 이 내용을 백지에 그릴 수 있어야 합니다.

활용 방법

📐 도식 · 애니메이션

각 애니메이션은 다음 ▶ 버튼으로 단계별 진행이 가능하고, 자동 재생도 지원합니다. 헤더 도식은 필드를 클릭하면 설명이 나타납니다.

🧪 시뮬레이터

서브넷 계산기, 슬라이딩 윈도우, 혼잡 제어(cwnd) 그래프, Dijkstra, NAT 테이블, 패킷 디코더 등은 값을 직접 바꿔가며 실험할 수 있습니다.

✅ 퀴즈와 진행률

장 끝의 퀴즈로 이해도를 점검하고, 완료로 표시를 눌러 진행률을 기록하세요. 진행률은 브라우저(localStorage)에 저장됩니다.

💻 실습

각 장의 터미널 예시는 macOS/Linux에서 바로 실행할 수 있습니다. tcpdump, ss, ip, dig 등 실제 도구로 눈으로 본 것을 손으로 확인하세요.
