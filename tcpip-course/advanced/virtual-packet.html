가상 링크와 오버레이 MTU

선수 장 · 3장 IP와 단편화

컨테이너의 작은 요청은 통하지만 큰 응답은 멈춥니다. 물리 링크 MTU에서 캡슐화에 드는 비용을 떼어 놓고 계산합니다.

패킷이 지나는 계층

컨테이너의 프레임은 veth 쌍을 거쳐 호스트 브리지에 들어갈 수 있습니다. VXLAN 구간에서는 안쪽 이더넷 프레임이 외부 UDP/IP로 다시 감싸집니다.

안쪽 TCP의 주소와 터널 종단의 외부 IP는 역할이 다릅니다. 컨테이너 포트, 터널 장치, 물리 인터페이스 세 곳에서 어느 계층의 주소와 길이인지 표시해야 반환 경로를 확인할 수 있습니다.

캡슐화를 고려한 크기 산정

외부 IP MTU가 1500이고 외부 IPv4 20, UDP 8, VXLAN 8, 내부 이더넷 14바이트를 가정하면 내부 IP MTU는 1450입니다. IPv6 외부 헤더이거나 옵션이 붙으면 계산이 달라집니다.

성공한 작은 연결 확인은 큰 데이터의 도달을 보장하지 않습니다. 서로 다른 크기를 같은 경로에서 비교하고, MSS와 IP MTU를 혼동하지 않은 상태에서 PMTU 피드백을 확인합니다.

실습과 예상 관찰

외부 IP MTU 1500을 고정하고 외부 IPv4 헤더를 20바이트, IPv6 헤더를 40바이트로 바꿔 계산하세요.

외부 IPv4, VLAN과 옵션 없음

외부 36바이트와 내부 이더넷 14바이트를 빼면 내부 IP MTU는 1450입니다.

외부 IPv6, 확장 헤더 없음

외부 헤더가 20바이트 늘어 같은 조건에서 내부 IP MTU는 1430입니다.
