코스 목록

Windows 커널 심화

NT의 객체·I/O·보안 경계를 네트워크, 장치 수명, 로컬 IPC, Registry, 성능 trace, KMDF 요청 설계로 확장합니다. 실험은 기존 도구의 읽기 전용 관찰과 명시적인 상태·시간선 비교를 사용합니다.

기존 코스 목차

  1. Windows 네트워크 경로와 버퍼 소유권

    11장에서 요청이 드라이버 스택을 지나 완료되는 흐름을 봤습니다. 네트워크에서는 소켓 요청·프로토콜 처리·NIC 버퍼의 완료 경계가 한 번의 send 성공과 일치하지 않을 수 있습니다.

  2. PnP·전원 전이와 대기 요청 수명

    14장의 최소 KMDF 장치가 읽기에 응답한다고 끝은 아닙니다. 장치가 멈추거나 전원 상태를 바꾸는 동안 큐에 남은 요청을 누가 책임지는지 정해야 합니다.

  3. 로컬 IPC와 요청자 보안 문맥

    10장의 이름 있는 객체와 핸들을 로컬 서비스 요청으로 연결합니다. 서비스가 파일을 대신 열 때 자신의 계정으로 열 것인지 요청자의 권한으로 열 것인지가 핵심 계약입니다.

  4. Registry 하이브와 캐시·영속성

    3장에서 부팅 중 SYSTEM 하이브를 읽었습니다. 여기서는 Registry 키를 열고 값을 바꾸는 API와 하이브 파일에 변경이 남는 시점을 구분합니다.

  5. WPR·WPA로 실행과 대기 분리하기

    15장의 크래시 분석은 멈춘 시점의 상태를 읽었습니다. 성능 분석은 요청 시간선에서 CPU 실행과 실행 준비·I/O 대기를 나눠야 합니다.

  6. KMDF 요청 취소·완료 캡스톤

    14장의 요청 완료 규칙을 timer·work item·사용자 취소가 만나는 상황으로 확장합니다. 완료를 두 번 하지 않는 것과 사용 중 상태를 먼저 해제하지 않는 것을 함께 지켜야 합니다.
