이 코스를 공부하는 법

1. 그림을 먼저

각 챕터의 도식은 클릭(🔍 explore)하거나 단계별로 재생(▶ stepper)할 수 있습니다. 글보다 그림을 먼저 따라가며 큰 흐름을 잡으세요.

2. 직접 조작

시뮬레이터에서 값을 바꿔 보며 "왜 이렇게 되는가"를 예측한 뒤 확인하세요. 예측이 틀린 지점이 진짜 학습 지점입니다.

3. 디버거로 검증

모든 챕터에 WinDbg 실습이 있습니다. 가상 머신에 커널 디버깅 환경을 만들고(15·17장) 구조체와 함수를 직접 확인하세요.

선수 지식

C 언어(포인터, 구조체, 비트 연산), 운영체제 기초(프로세스, 가상 메모리, 인터럽트 개념), x86-64 어셈블리 읽기 정도면 충분합니다. 어셈블리가 낯설다면 01·02장을 진행하며 필요한 만큼 익혀도 됩니다.

권장 학습 경로

01 → 17 순서대로. Part I·II로 실행 모델을, Part III로 메모리를, Part IV로 객체·I/O·보안을 익힌 뒤 Part V에서 실전 기술을 종합합니다. 약 6~10주(주 5~8시간) 분량입니다.

01 → 02 → 04 → 06 → 07 → 08 → 10 → 11 → 14 → 12 → 15. IRQL과 동기화(06·07), IRP(11)가 드라이버 품질의 핵심입니다. 14장을 마치면 Driver Verifier를 켠 채로 직접 드라이버를 작성해 보세요.

01 → 04 → 05 → 06 → 07 → 08 → 09 → 11 → 15. 덤프 분석은 결국 "스레드가 무엇을 기다리는가, 메모리가 왜 이 상태인가"를 읽는 일입니다. 15장의 워크스루를 반복하세요.

01 → 02 → 03 → 04 → 08 → 09 → 10 → 13 → 16. 보안 모델(13)과 커널 보호 메커니즘(16)은 메모리·객체 관리자에 대한 이해 위에서만 제대로 보입니다.
