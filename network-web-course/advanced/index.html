코스 목록

웹 네트워크 심화

이름과 신원 검증에서 시작해 메시지와 스트림의 경계, 타임아웃과 복구까지 따라갑니다.

기존 코스 목차

  1. DNSSEC 검증과 장애 진단

    권한 서버가 주소를 반환하지만 검증 리졸버만 실패하는 상황을 신뢰 사슬과 응답 서명으로 나눠 봅니다.

  2. HTTP 본문 경계를 확인하기

    한 번 받은 바이트 묶음이 HTTP 요청 하나라는 가정을 버리고, 앞단과 업스트림이 하나의 본문을 어떻게 완료하는지 봅니다.

  3. 인증서 회전과 mTLS 신원

    종료 지점 A와 B 중 한 곳만 새 인증서를 사용합니다. 성공한 연결 한 건으로는 회전 완료를 판정할 수 없습니다.

  4. HTTP/2와 HTTP/3의 흐름 제어

    다중화 연결에서 일부 스트림만 멈추거나 전체 DATA가 멈추는 시점을 별도 전송 예산으로 설명합니다.

  5. 느린 소비자와 스트리밍 재연결

    배포 뒤 연결은 다시 열렸지만 일부 이벤트가 빠졌습니다. 연결 복구와 커서에 따른 데이터 복구를 따로 설계합니다.

  6. 타임아웃 예산과 과부하 전파

    게이트웨이의 504가 늘고 앱 대기열도 길어졌습니다. 한 요청이 실제 내부 시도 몇 건을 만드는지 계산합니다.
