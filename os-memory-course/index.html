현대 운영체제 메모리 관리
개론부터 커널 내부까지

주소 변환의 원리에서 출발해 Linux 커널의 할당자, 회수, NUMA, 가상화, 보안까지. 도식·애니메이션·시뮬레이터로 직접 만져 보며 전문가 수준의 감각을 기르는 16개 챕터 코스입니다.

이 코스를 공부하는 방법
  • 각 챕터의 ▶ 위젯은 설명을 읽기 전에 먼저 만져 봐도 좋습니다. 예측해 보고 → 실행하고 → 왜 그런지 본문에서 확인하세요.
  • 보라색 심화 박스는 처음엔 건너뛰고, 두 번째 읽을 때 펼치세요.
  • 챕터 끝 확인 문제를 다 맞히지 못하면 다음 챕터로 넘어가지 마세요. 16장에 종합 문제 20개가 있습니다.
  • Linux 머신이 있다면 본문에 나오는 /proc 명령을 직접 실행해 보는 것이 가장 빠른 길입니다.
