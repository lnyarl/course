코스 목록

운영체제 메모리 관리 심화

주소 변환을 이해한 뒤 접근 순서·장치 주소·페이지 이동·관측 경계를 다룹니다. 여섯 단원은 기존 장의 원리를 실제 API와 반증 가능한 실험으로 연결하며, 교육용 계산과 직접 측정할 결과를 구분합니다.

기존 코스 목차

  1. 캐시 지연과 메모리 대역폭

    1장에서 메모리 지연의 자릿수를 배웠습니다. 같은 크기의 배열을 읽는데도 순차 합산과 연결 목록 탐색의 시간이 다른 이유를 요청 의존성과 전송량으로 나눕니다.

  2. 메모리 게시 순서와 객체 수명

    13장의 캐시 일관성은 한 주소의 값을 조율합니다. 이제 data와 ready 두 주소 사이의 게시 순서, 그리고 게시된 객체를 언제 해제할 수 있는지 따로 다룹니다.

  3. DMA 주소와 페이지 고정의 비용

    9장에서 연속 페이지와 GFP 계약을 봤습니다. 장치가 사용하는 버퍼는 CPU가 읽는 포인터와 주소·소유권·회수 조건이 다릅니다.

  4. 사용자 공간에서 해결하는 페이지 폴트

    6장에서는 커널이 PTE를 채워 명령을 재개했습니다. userfaultfd는 등록된 범위의 일부 fault 처리를 사용자 공간의 별도 관리 스레드로 넘길 수 있게 합니다.

  5. NUMA 이동과 계층형 메모리 정책

    13장에서 원격 NUMA 접근을 봤습니다. 더 빠른 메모리와 더 큰 메모리 사이에서 페이지를 움직일 때는 접근 지연 절약과 복사 비용을 함께 계산해야 합니다.

  6. 메모리 장애를 증거로 좁히는 캡스톤

    16장의 도구 목록을 하나의 조사 절차로 묶습니다. free가 적고 응답이 느리다는 보고에서 출발해 사용량·회수 대기·소유 범위를 각각 확인합니다.
