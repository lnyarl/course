코스 목록

Node.js 심화

런타임 메모리·워커·모듈·진단을 실제 소유권과 종료 경계로 연결합니다. 모든 실험은 자신의 로컬 프로그램과 정상 입력을 사용하며 자료의 관측과 원인 해석을 분리합니다.

기존 코스 목차

  1. Buffer·바이너리 파서·메모리 소유권

    작은 subarray만 보관했는데 큰 Buffer가 계속 살아 있을 수 있습니다. GC 지표에서 본 backing store를 네트워크 파서의 바이트 수명으로 연결합니다.

  2. 공유 메모리 워커 파이프라인

    공유 Buffer를 쓰면 복사 비용은 줄일 수 있지만 누가 어느 슬롯을 읽고 쓰는지 결정해야 합니다. Atomics 연산 하나를 아는 것에서 bounded 전달 프로토콜로 확장합니다.

  3. 패키지 호환성과 런타임 업그레이드

    앱 소스의 import가 같아도 exports 조건이나 네이티브 바이너리 때문에 업그레이드 결과가 달라질 수 있습니다. 모듈 해석에서 소비자 환경별 검증 행렬로 이동합니다.

  4. 네이티브 종료와 사후 분석 자료

    힙 스냅샷의 JS 객체가 작다고 네이티브 쪽 메모리나 프로세스 종료를 설명할 수 있는 것은 아닙니다. 핸들·callback 수명에서 어떤 진단 자료가 필요한지 연결합니다.

  5. 느린 의존성과 종료를 포함한 서비스 실험

    외부 의존성이 느려진 순간 서버도 종료된다면 timeout·재시도·drain이 서로 영향을 줍니다. 개별 복원력 패턴을 하나의 요청 수명에 적용합니다.

  6. 실제 자료로 푸는 장애 분석

    상황실에서 정답 도구를 골랐다면 이제 자신이 만든 로컬 작업의 원시 자료로 같은 판단을 해 봅니다. 그래프와 설명을 실제 파일의 어느 위치에서 확인했는지 남깁니다.
