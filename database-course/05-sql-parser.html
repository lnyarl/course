SQL 파서

SQL 문자열을 토큰으로 나누고 문법에 따라 AST를 만듭니다. 현재 읽는 토큰과 재귀 호출 스택, 완성되는 부분 트리를 한 단계씩 따라갑니다.

학습 목표

  • 따옴표 안의 문자열과 SQL 키워드를 구분합니다.
  • 토큰이 가리키는 UTF-8 바이트 범위를 원문과 연결합니다.
  • 재귀 하강으로 NOT → AND → OR 우선순위를 구현합니다.
  • 구문 오류와 카탈로그·타입 오류를 구분하고 입력 전체를 검사합니다.

1. 파싱은 실행 전의 구조화다

4장은 insert|people|1|Roy|NULL 같은 실습 명령을 직접 API로 보냈습니다. 이번 장은 INSERT INTO people VALUES (1, 'Roy', NULL)을 구조화합니다. 결과는 실행 결과가 아니라 AST, 즉 문장의 의미 있는 구조를 표현한 트리입니다.

SELECT unknown FROM absent는 이 문법에 맞으므로 파싱에 성공합니다. absent 테이블과 unknown 열이 있는지는 카탈로그를 조회하는 다음 단계에서 판단합니다. INSERT 열 개수 불일치, 중복 열 이름, 기본키 제약도 이 장의 파서가 판단하지 않습니다.

참조 구현은 데이터베이스 파일을 열거나 행을 쓰지 않습니다. PostgreSQL 파서 단계 설명도 구문 분석과 카탈로그를 사용하는 의미 분석을 구분합니다.

2. 토큰과 원문의 위치를 연결하기

공백으로만 split하면 'Roy Choi'를 둘로 나누고 age>=20을 구분하지 못합니다. 렉서는 현재 바이트를 보고 단어·정수·문자열·기호를 읽습니다. >=, <=, <>, !=처럼 두 글자 연산자는 한 글자보다 먼저 확인합니다.

키워드와 이름은 Word 토큰으로 읽은 뒤 소문자로 맞춥니다. 문자열의 내용은 보존합니다. 작은따옴표를 문자열에 넣으려면 두 번 씁니다. 'O''Reilly'는 값 O'Reilly인 Text 토큰 하나입니다. 백슬래시는 특별한 이스케이프로 해석하지 않습니다. -- 주석은 줄 끝까지 건너뛰지만 문자열 안의 --는 그대로 남습니다.

토큰은 [start, end) 범위를 갖습니다. 기준은 0부터 시작하는 UTF-8 바이트 오프셋입니다. 따옴표를 포함한 '한글'은 8바이트입니다. 문자 수나 브라우저 문자열 인덱스와 혼동하지 마세요. EOF는 원문 끝의 길이 0인 토큰입니다.

SQL을 한 토큰씩 읽기
분석 후 이전·다음·재생으로 읽는 위치를 옮기세요. 토큰 버튼을 누르면 해당 위치로 이동합니다. 문자열·CREATE·잘못된 SQL 예제를 골라 차이를 확인하세요.


왜 음수는 숫자 토큰 하나로 읽나요?
이 문법에는 산술 연산이 없습니다. -가 바로 숫자 앞에 붙었을 때 부호 있는 정수 토큰으로 읽습니다. 덕분에 i64 최솟값 -9223372036854775808도 직접 표현합니다. - 1, +1, 소수는 지원하지 않습니다. 산술식을 추가할 때는 단항 부호와 뺄셈을 구분하도록 렉서와 문법을 함께 바꿔야 합니다.


3. 이번 장의 SQL 문법


CREATE TABLE, INSERT 한 행, SELECT를 지원합니다. SELECT에는 열 목록 또는 *, WHERE, ORDER BY, LIMIT를 둘 수 있습니다. 식별자는 4장의 규칙에 맞춰 영문자로 시작하고 영숫자·밑줄만 사용하며 최대 32바이트입니다. 큰따옴표 식별자·별칭·JOIN·함수·산술식·여러 행 VALUES·블록 주석은 지원하지 않습니다.


statement = (create | insert | select) [";"] EOF
create    = CREATE TABLE name "(" column {"," column} ")"
column    = name (INT | TEXT) [NOT NULL]
insert    = INSERT INTO name ["(" names ")"] VALUES "(" literals ")"
select    = SELECT ("*" | names) FROM name [WHERE expr]
            [ORDER BY sort {"," sort}] [LIMIT nonnegative_int]
sort      = name [ASC | DESC]
expr      = and_expr {OR and_expr}
and_expr  = not_expr {AND not_expr}
not_expr  = NOT not_expr | "(" expr ")" | predicate
predicate = operand (compare operand | IS [NOT] NULL)
operand   = name | literal
compare   = "=" | "!=" | "<>" | "<" | "<=" | ">" | ">="
names     = name {"," name}
literals  = literal {"," literal}
literal   = signed_i64 | single_quoted_text | NULL


CREATE의 타입은 INT와 TEXT입니다. NOT NULL을 생략하면 NULL 허용으로 AST에 기록합니다. INSERT에서 열 목록을 생략하면 columns는 None입니다. SELECT에서는 None을 *에 사용합니다. 같은 None이라도 문장 타입에 따라 의미가 다릅니다. LIMIT는 0 이상 i64 정수이며 0도 허용합니다.


세미콜론 뒤의 입력도 검사합니다마지막 세미콜론은 하나까지 생략하거나 붙일 수 있습니다. 그 뒤에는 주석·공백을 제외하고 EOF가 와야 합니다. SELECT * FROM people; DROP TABLE people;을 첫 문장만 읽고 성공으로 처리하지 않습니다. 문장 배치는 다음 문법을 추가할 때 별도로 설계할 일입니다.


4. 재귀 하강과 부분 AST


문법마다 함수를 둡니다. 낮은 우선순위의 OR 함수는 AND 함수를 호출하고, AND는 NOT·조건 함수를 호출합니다. 아래 함수가 먼저 조건을 완성한 뒤 호출자에게 돌려줍니다. 이 방식으로 a=1 OR b=2 AND c=3은 OR(a=1, AND(b=2, c=3))이 됩니다.



토큰 소비 → 호출 스택 → AST 생성
위 SQL의 실제 파서 추적입니다. 문법 진입, 토큰 소비, 노드 생성, 반환을 순서대로 재생합니다. 도식은 그 시점에 완성한 마지막 부분 트리이며 전체 문장 AST는 마지막에 나타납니다. 기본 트리 목록에서 노드를 펼치고 선택해 전체 값을 확인하세요. 도식 보기에서는 전체 맞춤·확대·이동을 사용할 수 있습니다.

표현식은 Compare, IsNull, Not, And, Or로 표현합니다. 비교의 양쪽은 열 또는 리터럴입니다. 값 NULL과 문자열 "NULL"은 서로 다른 리터럴입니다. 원문에 age = NULL을 쓰는 것은 문법적으로 허용하지만 그 결과를 참으로 판단하지는 않습니다. NULL을 포함한 비교와 WHERE 평가 규칙은 실행기에서 다룹니다.


5. 괄호가 바꾸는 트리를 예측하기


AND가 OR보다 먼저 묶이는 이유를 함수 호출과 트리로 함께 확인하세요. 괄호는 파싱 순서를 바꿉니다. NOT은 AND보다 먼저 묶고, IS NOT NULL의 NOT은 해당 조건 안에 negated 표시로 저장합니다. 식 앞의 NOT 노드와 구분합니다.


루트 연산자와 결과 예측
A는 a=1, B는 b=2, C는 c=3 조건의 참/거짓입니다. A=true, B=false, C=false 상태에서 괄호를 켜고 끄세요. SQL을 실제 테이블에 실행하는 실습은 아닙니다.


6. 기대한 토큰이 없으면 그 자리에서 실패한다


WHERE age >= ;에서 비교 연산자 다음에는 피연산자가 필요합니다. 파서는 세미콜론이 있는 byte 위치와 함께 오류를 반환합니다. 문자열의 끝 따옴표가 없으면 렉서가 문자열 시작 위치를 반환합니다. EOF에 도착해 필요한 토큰이 없으면 원문의 바이트 길이가 오류 위치입니다.


참조 구현은 입력을 최대 16384 UTF-8 바이트, EOF를 제외한 토큰 1024개, 괄호·NOT 재귀 깊이 32, 표현식 노드 128개로 제한합니다. 긴 OR/AND 사슬도 노드 수를 검사합니다. 이 제한은 학습용 도구가 과도한 메모리나 재귀를 사용하지 않게 하는 범위입니다. 완전한 SQL 서버의 한계나 성능 측정치가 아닙니다.


오류를 고쳐 가며 추적하세요예제를 ‘구문 오류’로 바꾸고 ‘오류 단계 보기’를 누르세요. 비교 오른쪽에 20을 넣고 다시 분석하면 EOF까지 진행합니다. 세미콜론 뒤에 다른 문장을 붙이면 다시 거부합니다. 오류 입력에서 완성 AST나 실행 결과를 만들어 내지 않습니다.

접힌 참조 구현: sql.rs
sql.rs 저장. 소형 수동 렉서와 재귀 하강 파서입니다. 외부 파서 라이브러리나 데이터베이스 접근은 없습니다.
use std::{
    fmt,
    io::{self, Read},
};
const MAX_BYTES: usize = 16384;
const MAX_TOKENS: usize = 1024;
const MAX_DEPTH: usize = 32;
const MAX_NODES: usize = 128;
const RESERVED: &[&str] = &[
    "create", "table", "int", "text", "not", "null", "insert", "into", "values", "select", "from",
    "where", "and", "or", "is", "order", "by", "asc", "desc", "limit", "join", "on", "as",
    "update", "delete", "drop", "primary", "key", "true", "false",
];
#[derive(Debug, Clone, PartialEq)]
struct Error {
    pos: usize,
    message: String,
}
impl fmt::Display for Error {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "ERROR byte={}: {}", self.pos, self.message)
    }
}
impl std::error::Error for Error {}
type Result<T> = std::result::Result<T, Error>;
fn error(pos: usize, message: &str) -> Error {
    Error {
        pos,
        message: message.into(),
    }
}
#[derive(Debug, Clone, PartialEq)]
enum Kind {
    Word(String),
    Int(i64),
    Text(String),
    Sym(String),
    Eof,
}
#[derive(Debug, Clone, PartialEq)]
struct Token {
    kind: Kind,
    start: usize,
    end: usize,
}
fn lex(sql: &str) -> Result<Vec<Token>> {
    if sql.len() > MAX_BYTES {
        return Err(error(MAX_BYTES, "SQL exceeds 16384 UTF-8 bytes"));
    }
    let b = sql.as_bytes();
    let mut i = 0;
    let mut tokens = vec![];
    while i < b.len() {
        if b[i].is_ascii_whitespace() {
            i += 1;
            continue;
        }
        if b[i..].starts_with(b"--") {
            while i < b.len() && b[i] != b'\n' {
                i += 1;
            }
            continue;
        }
        let start = i;
        let kind = if b[i].is_ascii_alphabetic() || b[i] == b'_' {
            i += 1;
            while i < b.len() && (b[i].is_ascii_alphanumeric() || b[i] == b'_') {
                i += 1;
            }
            Kind::Word(sql[start..i].to_ascii_lowercase())
        } else if b[i].is_ascii_digit()
            || (b[i] == b'-' && b.get(i + 1).is_some_and(u8::is_ascii_digit))
        {
            i += 1;
            while i < b.len() && b[i].is_ascii_digit() {
                i += 1;
            }
            Kind::Int(
                sql[start..i]
                    .parse()
                    .map_err(|_| error(start, "integer is outside i64"))?,
            )
        } else if b[i] == b'\'' {
            i += 1;
            let mut text = String::new();
            let mut closed = false;
            while i < b.len() {
                if b[i] == b'\'' {
                    if b.get(i + 1) == Some(&b'\'') {
                        text.push('\'');
                        i += 2;
                        continue;
                    }
                    i += 1;
                    closed = true;
                    break;
                }
                let ch = sql[i..].chars().next().unwrap();
                text.push(ch);
                i += ch.len_utf8();
            }
            if !closed {
                return Err(error(start, "unterminated string"));
            }
            Kind::Text(text)
        } else {
            let two = b.get(i..i + 2);
            if two.is_some_and(|s| [b"<=".as_slice(), b">=", b"<>", b"!="].contains(&s)) {
                i += 2;
                Kind::Sym(sql[start..i].into())
            } else if b"(),;*=<>".contains(&b[i]) {
                i += 1;
                Kind::Sym(sql[start..i].into())
            } else {
                return Err(error(start, "unsupported character"));
            }
        };
        tokens.push(Token {
            kind,
            start,
            end: i,
        });
        if tokens.len() > MAX_TOKENS {
            return Err(error(start, "more than 1024 tokens"));
        }
    }
    tokens.push(Token {
        kind: Kind::Eof,
        start: i,
        end: i,
    });
    Ok(tokens)
}

    Not(Box<Expr>),
    And(Box<Expr>, Box<Expr>),
    Or(Box<Expr>, Box<Expr>),
}
#[derive(Debug, Clone, PartialEq)]
struct Column {
    name: String,
    data_type: String,
    nullable: bool,
}
#[derive(Debug, Clone, PartialEq)]
struct Order {
    column: String,
    descending: bool,
}
#[derive(Debug, Clone, PartialEq)]
enum Statement {
    Create {
        table: String,
        columns: Vec<Column>,
    },
    Insert {
        table: String,
        columns: Option<Vec<String>>,
        values: Vec<Literal>,
    },
    Select {
        table: String,
        columns: Option<Vec<String>>,
        filter: Option<Expr>,
        order: Vec<Order>,
        limit: Option<i64>,
    },
}
struct Parser {
    tokens: Vec<Token>,
    at: usize,
    nodes: usize,
}
impl Parser {
    fn current(&self) -> &Token {
        &self.tokens[self.at]
    }
    fn fail<T>(&self, message: &str) -> Result<T> {
        Err(error(self.current().start, message))
    }
    fn word(&mut self, s: &str) -> bool {
        if matches!(&self.current().kind,Kind::Word(w) if w==s) {
            self.at += 1;
            true
        } else {
            false
        }
    }
    fn sym(&mut self, s: &str) -> bool {
        if matches!(&self.current().kind,Kind::Sym(w) if w==s) {
            self.at += 1;
            true
        } else {
            false
        }
    }
    fn expect_word(&mut self, s: &str) -> Result<()> {
        if self.word(s) {
            Ok(())
        } else {
            self.fail(&format!("expected {s}"))
        }
    }
    fn expect_sym(&mut self, s: &str) -> Result<()> {
        if self.sym(s) {
            Ok(())
        } else {
            self.fail(&format!("expected {s}"))
        }
    }
    fn name(&mut self) -> Result<String> {
        if let Kind::Word(s) = &self.current().kind {
            if s.len() <= 32
                && s.as_bytes()[0].is_ascii_alphabetic()
                && !RESERVED.contains(&s.as_str())
            {
                let name = s.clone();
                self.at += 1;
                return Ok(name);
            }
        }
        self.fail("expected identifier (letter first, at most 32 bytes; no reserved word)")
    }
    fn names(&mut self) -> Result<Vec<String>> {
        let mut out = vec![self.name()?];
        while self.sym(",") {
            out.push(self.name()?);
        }
        Ok(out)
    }
    fn literal(&mut self) -> Result<Literal> {
        let value = match &self.current().kind {
            Kind::Int(n) => Literal::Int(*n),
            Kind::Text(s) => Literal::Text(s.clone()),
            Kind::Word(s) if s == "null" => Literal::Null,
            _ => return self.fail("expected integer, string or NULL"),
        };
        self.at += 1;
        Ok(value)
    }
    fn operand(&mut self) -> Result<Operand> {
        if matches!(&self.current().kind, Kind::Int(_) | Kind::Text(_))
            || matches!(&self.current().kind,Kind::Word(s) if s=="null")
        {
            Ok(Operand::Value(self.literal()?))
        } else {
            Ok(Operand::Column(self.name()?))
        }
    }
    fn node(&mut self, e: Expr) -> Result<Expr> {
        self.nodes += 1;
        if self.nodes > MAX_NODES {
            self.fail("more than 128 expression nodes")
        } else {
            Ok(e)
        }
    }
    fn expr(&mut self, depth: usize) -> Result<Expr> {
        let mut e = self.and(depth)?;
        while self.word("or") {
            let right = self.and(depth)?;
            e = self.node(Expr::Or(Box::new(e), Box::new(right)))?;
        }
        Ok(e)
    }
    fn and(&mut self, depth: usize) -> Result<Expr> {
        let mut e = self.not(depth)?;
        while self.word("and") {
            let right = self.not(depth)?;
            e = self.node(Expr::And(Box::new(e), Box::new(right)))?;
        }
        Ok(e)
    }
    fn not(&mut self, depth: usize) -> Result<Expr> {
        if depth > MAX_DEPTH {
            return self.fail("expression nesting exceeds 32");
        }
        if self.word("not") {
            let child = self.not(depth + 1)?;
            return self.node(Expr::Not(Box::new(child)));
        }
        if self.sym("(") {
            let child = self.expr(depth + 1)?;
            self.expect_sym(")")?;
            return Ok(child);
        }
        let left = self.operand()?;
        if self.word("is") {
            let negated = self.word("not");
            self.expect_word("null")?;
            return self.node(Expr::IsNull {
                value: left,
                negated,
            });
        }
        let op = match &self.current().kind {
            Kind::Sym(s) => match s.as_str() {
                "=" => Compare::Eq,
                "<>" | "!=" => Compare::Ne,
                "<" => Compare::Lt,
                "<=" => Compare::Le,
                ">" => Compare::Gt,
                ">=" => Compare::Ge,
                _ => return self.fail("expected comparison or IS [NOT] NULL"),
            },
            _ => return self.fail("expected comparison or IS [NOT] NULL"),
        };
        self.at += 1;
        let right = self.operand()?;
        self.node(Expr::Compare { left, op, right })
    }
    fn statement(&mut self) -> Result<Statement> {
        let stmt = if self.word("create") {
            self.expect_word("table")?;
            let table = self.name()?;
            self.expect_sym("(")?;
            let mut columns = vec![];
            loop {
                let name = self.name()?;
                let data_type = if self.word("int") {
                    "int"
                } else if self.word("text") {
                    "text"
                } else {
                    return self.fail("expected INT or TEXT");
                }
                .into();
                let nullable = if self.word("not") {
                    self.expect_word("null")?;
                    false
                } else {
                    true
                };
                columns.push(Column {
                    name,
                    data_type,
                    nullable,
                });
                if !self.sym(",") {
                    break;
                }
            }
            self.expect_sym(")")?;
            Statement::Create { table, columns }
        } else if self.word("insert") {
            self.expect_word("into")?;
            let table = self.name()?;
            let columns = if self.sym("(") {
                let c = self.names()?;
                self.expect_sym(")")?;
                Some(c)
            } else {
                None
            };
            self.expect_word("values")?;
            self.expect_sym("(")?;
            let mut values = vec![self.literal()?];
            while self.sym(",") {
                values.push(self.literal()?);
            }
            self.expect_sym(")")?;
            Statement::Insert {
                table,
                columns,
                values,
            }
        } else if self.word("select") {
            let columns = if self.sym("*") {
                None
            } else {
                Some(self.names()?)
            };
            self.expect_word("from")?;
            let table = self.name()?;
            let filter = if self.word("where") {
                Some(self.expr(0)?)
            } else {
                None
            };
            let mut order = vec![];
            if self.word("order") {
                self.expect_word("by")?;
                loop {
                    let column = self.name()?;
                    let descending = if self.word("desc") {
                        true
                    } else {
                        self.word("asc");
                        false
                    };
                    order.push(Order { column, descending });
                    if !self.sym(",") {
                        break;
                    }
                }
            }
            let limit = if self.word("limit") {
                let Kind::Int(n) = self.current().kind else {
                    return self.fail("expected nonnegative LIMIT");
                };
                if n < 0 {
                    return self.fail("expected nonnegative LIMIT");
                }
                self.at += 1;
                Some(n)
            } else {
                None
            };
            Statement::Select {
                table,
                columns,
                filter,
                order,
                limit,
            }
        } else {
            return self.fail("expected CREATE, INSERT or SELECT");
        };
        self.sym(";");
        if self.current().kind != Kind::Eof {
            return self.fail("expected end of input (one statement only)");
        }
        Ok(stmt)
    }
}
fn parse(sql: &str) -> Result<Statement> {
    Parser {
        tokens: lex(sql)?,
        at: 0,
        nodes: 0,
    }
    .statement()
}
// Stable JSON output for comparing the browser parser with this Rust parser.
fn quote(s: &str) -> String {
    let mut out = String::from("\"");
    for c in s.chars() {
        match c {
            '"' => out.push_str("\\\""),
            '\\' => out.push_str("\\\\"),
            '\n' => out.push_str("\\n"),
            '\r' => out.push_str("\\r"),
            '\t' => out.push_str("\\t"),
            c if c < ' ' => out.push_str(&format!("\\u{:04x}", c as u32)),
            _ => out.push(c),
        }
    }
    out.push('"');
    out
}
fn array(items: impl IntoIterator<Item = String>) -> String {
    format!("[{}]", items.into_iter().collect::<Vec<_>>().join(","))
}
impl Literal {
    fn json(&self) -> String {
        match self {
            Self::Int(n) => format!("{{\"type\":\"int\",\"value\":{}}}", quote(&n.to_string())),
            Self::Text(s) => format!("{{\"type\":\"text\",\"value\":{}}}", quote(s)),
            Self::Null => "{\"type\":\"null\"}".into(),
        }
    }
}
impl Operand {
    fn json(&self) -> String {
        match self {
            Self::Column(s) => format!("{{\"type\":\"column\",\"name\":{}}}", quote(s)),
            Self::Value(v) => v.json(),
        }
    }
}
impl Expr {
    fn json(&self) -> String {
        match self {
            Self::Compare { left, op, right } => format!(
                "{{\"type\":\"compare\",\"op\":{},\"left\":{},\"right\":{}}}",
                quote(match op {
                    Compare::Eq => "=",
                    Compare::Ne => "!=",
                    Compare::Lt => "<",
                    Compare::Le => "<=",
                    Compare::Gt => ">",
                    Compare::Ge => ">=",
                }),
                left.json(),
                right.json()
            ),
            Self::IsNull { value, negated } => format!(
                "{{\"type\":\"is_null\",\"negated\":{negated},\"value\":{}}}",
                value.json()
            ),
            Self::Not(child) => format!("{{\"type\":\"not\",\"value\":{}}}", child.json()),
            Self::And(a, b) | Self::Or(a, b) => format!(
                "{{\"type\":{},\"left\":{},\"right\":{}}}",
                quote(if matches!(self, Self::And(..)) {
                    "and"
                } else {
                    "or"
                }),
                a.json(),
                b.json()
            ),
        }
    }
}
impl Statement {
    fn json(&self) -> String {
        match self {
            Self::Create { table, columns } => format!(
                "{{\"type\":\"create\",\"table\":{},\"columns\":{}}}",
                quote(table),
                array(columns.iter().map(|c| format!(
                    "{{\"name\":{},\"data_type\":{},\"nullable\":{}}}",
                    quote(&c.name),
                    quote(&c.data_type),
                    c.nullable
                )))
            ),
            Self::Insert {
                table,
                columns,
                values,
            } => format!(
                "{{\"type\":\"insert\",\"table\":{},\"columns\":{},\"values\":{}}}",
                quote(table),
                columns
                    .as_ref()
                    .map(|cols| array(cols.iter().map(|s| quote(s))))
                    .unwrap_or_else(|| "null".into()),
                array(values.iter().map(Literal::json))
            ),
            Self::Select {
                table,
                columns,
                filter,
                order,
                limit,
            } => format!(
                "{{\"type\":\"select\",\"table\":{},\"columns\":{},\"filter\":{},\"order\":{},\"limit\":{}}}",
                quote(table),
                columns
                    .as_ref()
                    .map(|cols| array(cols.iter().map(|s| quote(s))))
                    .unwrap_or_else(|| "null".into()),
                filter
                    .as_ref()
                    .map(Expr::json)
                    .unwrap_or_else(|| "null".into()),
                array(order.iter().map(|o| format!(
                    "{{\"column\":{},\"descending\":{}}}",
                    quote(&o.column),
                    o.descending
                ))),
                limit
                    .map(|n| quote(&n.to_string()))
                    .unwrap_or_else(|| "null".into())
            ),
        }
    }
}
fn tokens_json(tokens: &[Token]) -> String {
    array(tokens.iter().map(|t| {
        let (kind, value) = match &t.kind {
            Kind::Word(s) => ("word", quote(s)),
            Kind::Int(n) => ("int", quote(&n.to_string())),
            Kind::Text(s) => ("text", quote(s)),
            Kind::Sym(s) => ("symbol", quote(s)),
            Kind::Eof => ("eof", "null".into()),
        };
        format!(
            "{{\"kind\":{},\"value\":{},\"start\":{},\"end\":{}}}",
            quote(kind),
            value,
            t.start,
            t.end
        )
    }))
}
fn main() {
    let args: Vec<_> = std::env::args().skip(1).collect();
    if !args.is_empty() && args != ["--tokens"] {
        eprintln!("usage: sql [--tokens] < input.sql");
        std::process::exit(2);
    }
    let mut bytes = Vec::new();
    if let Err(e) = io::stdin()
        .take((MAX_BYTES + 1) as u64)
        .read_to_end(&mut bytes)
    {
        eprintln!("input error: {e}");
        std::process::exit(2);
    }
    if bytes.len() > MAX_BYTES {
        eprintln!("{}", error(MAX_BYTES, "SQL exceeds 16384 UTF-8 bytes"));
        std::process::exit(2);
    }
    let sql = match String::from_utf8(bytes) {
        Ok(sql) => sql,
        Err(e) => {
            eprintln!("input error: {e}");
            std::process::exit(2);
        }
    };
    let result = if args.is_empty() {
        parse(&sql).map(|s| s.json())
    } else {
        lex(&sql).map(|t| tokens_json(&t))
    };
    match result {
        Ok(json) => println!("{json}"),
        Err(e) => {
            eprintln!("{e}");
            std::process::exit(2);
        }
    }
}

  • NOT, AND, OR, 괄호로 만든 AST 구조가 기대와 같습니다.

  • 카탈로그에 없는 이름도 구문이 맞으면 AST를 생성합니다.


핵심 요약
  • 토큰의 값과 원문 UTF-8 바이트 범위를 함께 보관합니다.

  • AST 생성 성공과 이름·타입 확인, 실제 실행은 다른 단계입니다.
  • 입력 전체를 EOF까지 확인해야 합니다.
