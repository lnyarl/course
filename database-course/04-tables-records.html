테이블과 레코드

정수 키·값 저장소에 열의 이름과 타입을 붙입니다. 문자열과 NULL을 바이트로 저장하고, B+트리의 RID를 따라 실제 행을 읽는 테이블 계층을 만듭니다.

학습 목표

  • 스키마로 행의 타입과 NOT NULL을 검사합니다.
  • NULL 비트맵과 문자열의 오프셋·바이트 길이를 인코딩합니다.
  • 힙 페이지에 여러 행을 넣고 RID로 다시 읽습니다.
  • 카탈로그·힙·기본키 색인을 저장하고 재시작 후 조회합니다.

1. 행의 바이트를 해석할 스키마

3장의 B+트리는 i64 키와 i64 값만 저장했습니다. 이번에는 값 자리에 실제 행의 위치인 RID를 넣습니다. 이름이나 나이 같은 데이터는 별도의 힙 페이지에 저장합니다. B+트리는 기본키로 위치를 찾고, 테이블 계층은 스키마에 따라 행을 해석합니다.

스키마는 열의 이름·타입·NULL 허용 여부를 순서대로 정의합니다. 예제 테이블 people(id:int, name:text?, age:int?)에서 물음표는 NULL 허용입니다. 첫 열은 NULL을 허용하지 않는 정수 기본키로 고정합니다. 같은 기본키를 다시 insert하면 갱신하지 않고 오류를 반환합니다.

열타입제약
idi64NOT NULL, 기본키, 중복 거부
nameUTF-8 문자열NULL 허용
agei64NULL 허용

행마다 열 이름과 타입을 반복 저장하지 않습니다. 카탈로그에 있는 스키마가 각 셀의 해석 방법을 정합니다. 행에 저장한 열 개수도 스키마와 맞아야 합니다. 이 장은 타입을 Int와 Text로 제한하고 열 변경은 지원하지 않습니다.

이전 장의 코드는 그대로 재사용합니다2장의 페이지·버퍼 풀 위에 힙 어댑터를 추가하고, 3장의 B+트리를 기본키 색인으로 감쌉니다. 새 데이터는 디렉터리의 tables.pages와 테이블별 people.idx에 저장합니다. 이전 장의 실습 파일을 덮어쓰지 마세요.

2. NULL과 빈 값은 다른 바이트다

NULL을 숫자 0이나 빈 문자열로 표현하면 실제 값과 구분할 수 없습니다. 이 코스는 열마다 한 비트를 두고 1이면 NULL로 정합니다. 열 i의 비트는 bitmap[i / 8] & (1 << (i % 8))로 확인합니다. 비트 0부터 열 순서대로 사용하며 남는 상위 비트는 0입니다.

세 열이면 비트맵은 한 바이트입니다. (1, "Roy", NULL)은 age가 세 번째 열이므로 00000100입니다. (1, "", 0)은 NULL이 하나도 없어 00000000입니다. 빈 문자열의 길이는 0이지만 NULL 비트는 0입니다.

행의 시작에는 열 개수 u16을 두고, 비트맵 다음에 열마다 8바이트 셀을 둡니다. 정수는 셀에 직접 쓰고, 문자열은 offset:u32 + length:u32로 표현합니다. NULL인 열의 셀은 8바이트 모두 0으로 둡니다. 따라서 이 형식에서는 NULL도 고정 셀 공간을 차지합니다.

3. 문자열 길이는 UTF-8 바이트로 센다

문자열의 본문은 고정 셀 뒤에 열 순서대로 붙입니다. 첫 문자열의 offset은 2 + ceil(열 수 / 8) + 8 × 열 수입니다. 이 예제에서는 27입니다. 길이는 글자 수가 아니라 UTF-8 바이트 수입니다. Roy는 3바이트, 한글은 6바이트입니다.

모든 다중 바이트 정수는 little-endian입니다. 레코드 길이는 페이지 슬롯이 이미 저장하므로 행 앞에 전체 길이를 반복하지 않습니다. 각 문자열이 이전 본문의 끝에서 시작하는지, 범위를 넘지 않는지, UTF-8이 맞는지도 디코딩할 때 검사합니다. 끝에 남는 바이트도 거부합니다.

행을 바이트로 바꾸기
스키마는 id:int, name:text?, age:int?입니다. 이름을 지우는 것과 NULL을 체크하는 것을 비교하세요. 정수는 i64 전체 범위를 받습니다.
열 수
0..2NULL 비트
2..3id 셀
3..11name 셀
11..19age 셀
19..27


왜 문자열 셀에도 8바이트를 주나요?
모든 셀의 폭을 같게 두면 i번째 셀의 위치를 바로 계산할 수 있습니다. 타입과 NULL 개수에 따라 뒤의 셀 위치가 달라지지 않습니다. 공간 효율은 낮습니다. 문자열 오프셋만 저장하거나 NULL 셀을 생략하는 형식은 더 작지만 디코더가 복잡해집니다. 실제 제품의 행 형식과 이 학습용 형식은 다릅니다.



  
행 인코딩을 한 단계씩 실행하기
바로 위 id·name·age 입력을 바꾸고 ‘현재 입력 가져오기’를 누르세요. NULL 비트 → 정수 셀 → 문자열 셀 → UTF-8 본문 순서로 행을 조립합니다. 이전 단계로 돌아가면 그때까지 쓴 바이트만 보입니다.

4. 힙 페이지와 RID


힙은 행을 기본키 순서로 정렬하지 않고 빈 공간에 넣는 저장 방식입니다. 여기서는 테이블마다 연결된 페이지 목록을 사용하고 마지막 페이지에만 삽입합니다. 앞 페이지의 빈 공간을 다시 탐색하지 않습니다. 페이지가 부족하면 새 페이지를 할당하고 마지막 페이지의 next를 바꿉니다.


2장의 페이지 헤더·슬롯 디렉터리는 그대로 사용합니다. 슬롯 0은 다음 페이지 번호 u64이며 실제 행은 슬롯 1부터 넣습니다. 따라서 RID는 (page_id, slot_id)입니다. 페이지가 바뀌어도 같은 슬롯 번호를 재사용할 수 있으므로 두 번호가 모두 필요합니다.


빈 힙 페이지가 쓰는 공간은 헤더 8 + 슬롯 0 디렉터리 4 + next 8 = 20바이트입니다. 행 하나를 추가할 때는 행 바이트 외에 슬롯 디렉터리 4바이트가 필요합니다. 한 페이지에 담을 수 있는 최대 행은 4096 − 20 − 4 = 4072바이트입니다. 더 큰 행을 위한 overflow 페이지는 구현하지 않습니다.


현재 행을 힙 페이지에 넣기
위에서 만든 바이트를 복사해 저장합니다. id를 바꿔 여러 번 넣으세요. 중복 기본키는 거부합니다. 페이지는 실제 4096바이트로 계산하며 디렉터리 4바이트도 포함합니다. 화면 예제는 30행까지입니다.


행의 바이트 오프셋이 아니라 슬롯 번호를 RID에 사용합니다. 나중에 페이지 내부에서 행을 옮기더라도 슬롯이 가리키는 오프셋만 바꾸면 됩니다. 이 장은 삽입과 조회만 제공하므로 삭제·슬롯 재사용·행 갱신에 따른 RID 수명 문제는 다루지 않습니다.


5. B+트리는 기본키에서 RID를 찾는다


3장의 B+트리 값은 i64입니다. 이를 바꾸지 않고 양수 범위에 RID를 패킹합니다. rid = (page_id << 16) | slot_id이며 읽을 때는 page = rid >> 16, slot = rid & 65535로 나눕니다. p1의 slot1은 정수 65537입니다.


부호 비트를 사용하지 않으므로 page_id는 최대 2^47 − 1입니다. 페이지 0과 슬롯 0은 데이터 행 RID에서 거부합니다. 숫자 범위를 검사한 뒤에만 패킹합니다. 같은 기본키를 넣기 전에는 색인에서 중복을 검사하고, 색인 조회로 읽은 행의 첫 열이 요청한 키와 같은지도 확인합니다.




6. 재시작 후에도 스키마를 찾는 카탈로그


카탈로그는 테이블 이름, 열 정의, 저장 위치를 기록하는 메타데이터입니다. 이 예제는 page 0의 슬롯 0에 카탈로그 전체를 한 레코드로 넣습니다. 크기가 4084바이트를 넘으면 테이블 생성을 거부합니다. 테이블은 최대 32개, 테이블당 열은 1~16개입니다. 공간이 먼저 부족해질 수도 있습니다.


순서카탈로그 레코드 형식
헤더magic TB04: 4바이트 + 테이블 수: u16 LE
테이블 이름길이: u8 + ASCII 이름 바이트
열 목록열 수: u8. 각 열은 이름 길이 u8 + 이름 + 타입 u8 + NULL 허용 u8
힙 위치first_page_id: u64 LE + last_page_id: u64 LE
다음 테이블테이블 수만큼 반복


타입 번호는 Int=1, Text=2이며 NULL 허용 값은 0 또는 1입니다. 이름은 영문자로 시작하고 영숫자·밑줄만 허용하며 최대 32바이트입니다. 색인 파일명은 테이블 이름에 .idx를 붙여 정합니다. 재시작 때 카탈로그를 읽어 테이블별 색인을 열며, 색인 파일이 없거나 비어 있으면 오류로 끝냅니다.


카탈로그 → 기본키 색인 → 행 읽기
앞의 힙 시뮬레이터에 삽입한 행을 조회합니다. 카탈로그 바이트를 먼저 읽어 스키마를 복원하세요. B+트리 검색 단계는 여기서는 키→RID 매핑으로 축약했습니다. 전체 트리 과정은 3장에서 확인할 수 있습니다.
저장된 카탈로그 바이트
모의 재열기는 해석한 스키마만 지웁니다. 메모리의 카탈로그 바이트·행·키 매핑은 유지하며 실제 파일 I/O는 하지 않습니다. 실제 프로세스 재시작은 아래 Rust 검사로 확인합니다.


실제 DB에서는 카탈로그도 일반 테이블로 관리할 수 있습니다. 여기서는 카탈로그를 읽어야 테이블을 열 수 있는 시작 과정을 단순하게 만들기 위해 단일 페이지를 사용했습니다. PostgreSQL의 카탈로그는 테이블과 열 같은 스키마 메타데이터를 저장합니다. PostgreSQL 시스템 카탈로그와 비교해 보세요.



  
조회가 지나가는 위치를 따라가기
위 인코딩 애니메이션에서 가져온 행 하나를 p1의 slot1에 저장했다고 가정합니다. 기본키를 맞추면 카탈로그 → 색인 → 슬롯 → 행으로 이동하고, 없는 키이면 색인 단계에서 종료합니다. 실제 파일 I/O와 B+트리 탐색은 생략한 경로 모형입니다.

처음 실행할 때는 새 디렉터리 이름을 사용하세요. RID 출력은 메모리 삽입 성공입니다. .flush, .exit, 정상 EOF에서 힙과 색인을 동기화합니다. 명령 오류나 I/O 오류로 종료하면 자동 flush하지 않습니다.

mod heap {
    include!("../ch02/pages.rs");
    pub struct Heap(Pool);
    impl Heap {
        pub fn open(path: &Path) -> io::Result<Self> {
            Ok(Self(Pool::new(Disk::open(path)?, 3)?))
        }
        pub fn len(&self) -> u64 {
            self.0.disk.pages
        }
        pub fn allocate(&mut self, metadata: &[u8]) -> io::Result<u64> {
            let id = self.0.disk.allocate()?;
            self.replace(id, metadata)?;
            Ok(id)
        }
        pub fn replace(&mut self, id: u64, metadata: &[u8]) -> io::Result<()> {
            let mut p = Page::new();
            p.insert(metadata)?;
            let f = self.0.fetch(id)?;
            let frame = self.0.frames[f].as_mut().unwrap();
            frame.page = p;
            frame.dirty = true;
            self.0.unpin(f)
        }
        pub fn read(&mut self, id: u64, slot: u16) -> io::Result<Vec<u8>> {
            let f = self.0.fetch(id)?;
            let result = self
                .0
                .get(f, slot)
                .and_then(|b| b.map(<[u8]>::to_vec).ok_or_else(|| invalid("missing slot")));
            self.0.unpin(f)?;
            result
        }
        pub fn append(&mut self, id: u64, bytes: &[u8]) -> io::Result<Option<u16>> {
            let f = self.0.fetch(id)?;
            let free = self.0.frames[f].as_ref().unwrap().page.free();
            let result = if bytes.len() + 4 > free {
                Ok(None)
            } else {
                self.0.insert(f, bytes).map(Some)
            };
            self.0.unpin(f)?;
            result
        }
        pub fn count(&mut self, id: u64) -> io::Result<usize> {
            let f = self.0.fetch(id)?;
            let n = self.0.frames[f].as_ref().unwrap().page.count();
            self.0.unpin(f)?;
            Ok(n)
        }
        pub fn next(&mut self, id: u64) -> io::Result<u64> {
            let b = self.read(id, 0)?;
            if b.len() != 8 {
                return Err(invalid("bad heap header"));
            }
            let next = u64::from_le_bytes(b.try_into().unwrap());
            if next >= self.len() && next != 0 {
                return Err(invalid("bad next page"));
            }
            Ok(next)
        }
        pub fn link(&mut self, id: u64, next: u64) -> io::Result<()> {
            self.next(id)?;
            let f = self.0.fetch(id)?;
            let frame = self.0.frames[f].as_mut().unwrap();
            let start = frame.page.u16(8);
            frame.page.0[start..start + 8].copy_from_slice(&next.to_le_bytes());
            frame.dirty = true;
            self.0.unpin(f)
        }
        pub fn flush(&mut self) -> io::Result<()> {
            self.0.flush()
        }
    }
}
const MAX_ROW: usize = 4072;
fn bad(message: &str) -> io::Error {
    io::Error::new(io::ErrorKind::InvalidData, message)
}
#[derive(Debug, Clone, PartialEq)]
enum Kind {
    Int,
    Text,
}
#[derive(Debug, Clone, PartialEq)]
struct Column {
    name: String,
    kind: Kind,
    nullable: bool,
}
#[derive(Debug, Clone, PartialEq)]
enum Value {
    Int(i64),
    Text(String),
    Null,
}
type Row = Vec<Value>;
fn identifier(s: &str) -> bool {
    !s.is_empty()
        && s.len() <= 32
        && s.as_bytes()[0].is_ascii_alphabetic()
        && s.bytes().all(|b| b.is_ascii_alphanumeric() || b == b'_')
}
fn validate_schema(schema: &[Column]) -> io::Result<()> {
    if schema.is_empty() || schema.len() > 16 || schema[0].kind != Kind::Int || schema[0].nullable {
        return Err(bad("first column must be non-null int; 1..16 columns"));
    }
    let mut names = HashSet::new();
    for c in schema {
        if !identifier(&c.name) || !names.insert(&c.name) {
            return Err(bad("bad or duplicate column name"));
        }
    }
    Ok(())
}
fn encode(schema: &[Column], row: &[Value]) -> io::Result<Vec<u8>> {
    if row.len() != schema.len() {
        return Err(bad("column count mismatch"));
    }
    let bitmap = schema.len().div_ceil(8);
    let fixed = 2 + bitmap + 8 * schema.len();
    let mut b = vec![0; fixed];
    b[..2].copy_from_slice(&(schema.len() as u16).to_le_bytes());
    for (i, (c, v)) in schema.iter().zip(row).enumerate() {
        let at = 2 + bitmap + i * 8;
        match (&c.kind, v) {
            (_, Value::Null) if c.nullable => b[2 + i / 8] |= 1 << (i % 8),
            (Kind::Int, Value::Int(n)) => b[at..at + 8].copy_from_slice(&n.to_le_bytes()),
            (Kind::Text, Value::Text(s)) => {
                if b.len() + s.len() > MAX_ROW {
                    return Err(bad("row too large"));
                }
                let offset = b.len() as u32;
                b[at..at + 4].copy_from_slice(&offset.to_le_bytes());
                b[at + 4..at + 8].copy_from_slice(&(s.len() as u32).to_le_bytes());
                b.extend_from_slice(s.as_bytes());
            }
            _ => return Err(bad("type or NOT NULL constraint")),
        }
    }
    if b.len() > MAX_ROW {
        return Err(bad("row too large"));
    }
    Ok(b)
}
fn decode(schema: &[Column], b: &[u8]) -> io::Result<Row> {
    let n = schema.len();
    let bitmap = n.div_ceil(8);
    let fixed = 2 + bitmap + 8 * n;
    if b.len() < fixed || b.len() > MAX_ROW || u16::from_le_bytes([b[0], b[1]]) as usize != n {
        return Err(bad("bad row size"));
    }
    if n % 8 != 0 && b[2 + bitmap - 1] >> (n % 8) != 0 {
        return Err(bad("unused NULL bits"));
    }
    let mut row = vec![];
    let mut end = fixed;
    for (i, c) in schema.iter().enumerate() {
        let at = 2 + bitmap + 8 * i;
        let cell = &b[at..at + 8];
        if b[2 + i / 8] & (1 << (i % 8)) != 0 {
            if !c.nullable || cell.iter().any(|&v| v != 0) {
                return Err(bad("bad NULL field"));
            }
            row.push(Value::Null);
            continue;
        }
        row.push(match c.kind {
            Kind::Int => Value::Int(i64::from_le_bytes(cell.try_into().unwrap())),
            Kind::Text => {
                let start = u32::from_le_bytes(cell[..4].try_into().unwrap()) as usize;
                let len = u32::from_le_bytes(cell[4..].try_into().unwrap()) as usize;
                let limit = start.checked_add(len).ok_or_else(|| bad("text overflow"))?;
                if start != end || limit > b.len() {
                    return Err(bad("bad text range"));
                }
                let s = std::str::from_utf8(&b[start..limit]).map_err(|_| bad("bad UTF-8"))?;
                end = limit;
                Value::Text(s.to_owned())
            }
        });
    }
    if end != b.len() {
        return Err(bad("trailing row bytes"));
    }
    Ok(row)
}
#[derive(Debug, Clone, PartialEq)]
struct Table {
    name: String,
    schema: Vec<Column>,
    first: u64,
    last: u64,
}
fn catalog(tables: &[Table]) -> io::Result<Vec<u8>> {
    if tables.len() > 32 {
        return Err(bad("at most 32 tables"));
    }
    let mut b = b"TB04".to_vec();
    b.extend_from_slice(&(tables.len() as u16).to_le_bytes());
    for t in tables {
        if !identifier(&t.name) {
            return Err(bad("bad table name"));
        }
        validate_schema(&t.schema)?;
        b.push(t.name.len() as u8);
        b.extend_from_slice(t.name.as_bytes());
        b.push(t.schema.len() as u8);
        for c in &t.schema {
            b.push(c.name.len() as u8);
            b.extend_from_slice(c.name.as_bytes());
            b.push(if c.kind == Kind::Int { 1 } else { 2 });
            b.push(c.nullable as u8);
        }
        b.extend_from_slice(&t.first.to_le_bytes());
        b.extend_from_slice(&t.last.to_le_bytes());
    }
    if b.len() > 4084 {
        return Err(bad("catalog page full"));
    }
    Ok(b)
}
struct Reader<'a> {
    bytes: &'a [u8],
    at: usize,
}
impl<'a> Reader<'a> {
    fn take(&mut self, n: usize) -> io::Result<&'a [u8]> {
        let end = self
            .at
            .checked_add(n)
            .ok_or_else(|| bad("catalog overflow"))?;
        let out = self
            .bytes
            .get(self.at..end)
            .ok_or_else(|| bad("truncated catalog"))?;
        self.at = end;
        Ok(out)
    }
    fn byte(&mut self) -> io::Result<u8> {
        Ok(self.take(1)?[0])
    }
    fn name(&mut self) -> io::Result<String> {
        let len = self.byte()? as usize;
        Ok(std::str::from_utf8(self.take(len)?)
            .map_err(|_| bad("bad name"))?
            .to_owned())
    }
    fn id(&mut self) -> io::Result<u64> {
        Ok(u64::from_le_bytes(self.take(8)?.try_into().unwrap()))
    }
}
fn read_catalog(b: &[u8], pages: u64) -> io::Result<Vec<Table>> {
    let mut r = Reader { bytes: b, at: 0 };
    if r.take(4)? != b"TB04" {
        return Err(bad("bad catalog magic"));
    }
    let n = u16::from_le_bytes(r.take(2)?.try_into().unwrap());
    if n > 32 {
        return Err(bad("too many tables"));
    }
    let mut tables = vec![];
    let mut names = HashSet::new();
    for _ in 0..n {
        let name = r.name()?;
        if !identifier(&name) || !names.insert(name.clone()) {
            return Err(bad("bad table name"));
        }
        let count = r.byte()?;
        if !(1..=16).contains(&count) {
            return Err(bad("bad column count"));
        }
        let mut schema = vec![];
        for _ in 0..count {
            let name = r.name()?;
            let kind = match r.byte()? {
                1 => Kind::Int,
                2 => Kind::Text,
                _ => return Err(bad("bad type")),
            };
            let nullable = match r.byte()? {
                0 => false,
                1 => true,
                _ => return Err(bad("bad nullability")),
            };
            schema.push(Column {
                name,
                kind,
                nullable,
            });
        }
        validate_schema(&schema)?;
        let first = r.id()?;
        let last = r.id()?;
        if first == 0 || last == 0 || first >= pages || last >= pages {
            return Err(bad("bad heap page id"));
        }
        tables.push(Table {
            name,
            schema,
            first,
            last,
        });
    }
    if r.at != b.len() {
        return Err(bad("trailing catalog bytes"));
    }
    Ok(tables)
}
fn pack(page: u64, slot: u16) -> io::Result<i64> {
    if page == 0 || page > (i64::MAX as u64 >> 16) || slot == 0 {
        return Err(bad("RID overflow or reserved slot"));
    }
    Ok(((page << 16) | slot as u64) as i64)
}
fn unpack(rid: i64) -> io::Result<(u64, u16)> {
    if rid < 0 {
        return Err(bad("negative RID"));
    }
    let page = rid as u64 >> 16;
    let slot = rid as u16;
    pack(page, slot)?;
    Ok((page, slot))
}
struct Db {
    dir: PathBuf,
    heap: heap::Heap,
    tables: Vec<Table>,
    indexes: HashMap<String, index::Index>,
}
impl Db {
    fn open(dir: &Path) -> io::Result<Self> {
        std::fs::create_dir_all(dir)?;
        let mut heap = heap::Heap::open(&dir.join("tables.pages"))?;
        if heap.len() == 0 {
            heap.allocate(&catalog(&[])?)?;
            heap.flush()?;
        }
        let tables = read_catalog(&heap.read(0, 0)?, heap.len())?;
        let mut indexes = HashMap::new();
        for t in &tables {
            let path = dir.join(format!("{}.idx", t.name));
            if !path.exists() || path.metadata()?.len() == 0 {
                return Err(bad("missing or empty index file"));
            }
            indexes.insert(t.name.clone(), index::Index::open(&path)?);
        }
        Ok(Self {
            dir: dir.to_owned(),
            heap,
            tables,
            indexes,
        })
    }
    fn table(&self, name: &str) -> io::Result<usize> {
        self.tables
            .iter()
            .position(|t| t.name == name)
            .ok_or_else(|| bad("unknown table"))
    }
    fn create(&mut self, name: &str, schema: Vec<Column>) -> io::Result<()> {
        if !identifier(name) || self.tables.iter().any(|t| t.name == name) {
            return Err(bad("bad or duplicate table name"));
        }
        validate_schema(&schema)?;
        let mut tables = self.tables.clone();
        tables.push(Table {
            name: name.to_owned(),
            schema,
            first: 1,
            last: 1,
        });
        catalog(&tables)?;
        let path = self.dir.join(format!("{name}.idx"));
        if path.exists() {
            return Err(bad("index file already exists"));
        }
        let id = self.heap.allocate(&0u64.to_le_bytes())?;
        let t = tables.last_mut().unwrap();
        t.first = id;
        t.last = id;
        let idx = index::Index::open(&path)?;
        self.heap.replace(0, &catalog(&tables)?)?;
        self.tables = tables;
        self.indexes.insert(name.to_owned(), idx);
        Ok(())
    }
    fn insert(&mut self, name: &str, row: Row) -> io::Result<(u64, u16)> {
        let i = self.table(name)?;
        let bytes = encode(&self.tables[i].schema, &row)?;
        let Value::Int(key) = row[0] else {
            return Err(bad("int primary key required"));
        };
        if self.indexes.get_mut(name).unwrap().get(key)?.is_some() {
            return Err(bad("duplicate primary key"));
        }
        let mut page = self.tables[i].last;
        let slot = match self.heap.append(page, &bytes)? {
            Some(slot) => slot,
            None => {
                let new = self.heap.allocate(&0u64.to_le_bytes())?;
                let slot = self
                    .heap
                    .append(new, &bytes)?
                    .ok_or_else(|| bad("row does not fit"))?;
                self.heap.link(page, new)?;
                self.tables[i].last = new;
                self.heap.replace(0, &catalog(&self.tables)?)?;
                page = new;
                slot
            }
        };
        self.indexes
            .get_mut(name)
            .unwrap()
            .set(key, pack(page, slot)?)?;
        Ok((page, slot))
    }
    fn get(&mut self, name: &str, key: i64) -> io::Result<Option<Row>> {
        let i = self.table(name)?;
        let Some(rid) = self.indexes.get_mut(name).unwrap().get(key)? else {
            return Ok(None);
        };
        let (page, slot) = unpack(rid)?;
        let row = decode(&self.tables[i].schema, &self.heap.read(page, slot)?)?;
        if row.first() != Some(&Value::Int(key)) {
            return Err(bad("index key and heap row disagree"));
        }
        Ok(Some(row))
    }
    fn scan(&mut self, name: &str) -> io::Result<Vec<Row>> {
        let i = self.table(name)?;
        let t = self.tables[i].clone();
        let mut page = t.first;
        let mut seen = HashSet::new();
        let mut rows = vec![];
        loop {
            if !seen.insert(page) {
                return Err(bad("cycle in heap chain"));
            }
            for slot in 1..self.heap.count(page)? {
                rows.push(decode(&t.schema, &self.heap.read(page, slot as u16)?)?);
            }
            let next = self.heap.next(page)?;
            if next == 0 {
                if page != t.last {
                    return Err(bad("bad last page"));
                }
                return Ok(rows);
            }
            page = next;
        }
    }
    fn flush(&mut self) -> io::Result<()> {
        self.heap.flush()?;
        for idx in self.indexes.values_mut() {
            idx.flush()?;
        }
        Ok(())
    }
}
fn parse_schema(fields: &[&str]) -> io::Result<Vec<Column>> {
    let mut schema = vec![];
    for f in fields {
        let (name, ty) = f
            .split_once(':')
            .ok_or_else(|| bad("column syntax: name:int or name:text?"))?;
        let nullable = ty.ends_with('?');
        let ty = ty.strip_suffix('?').unwrap_or(ty);
        let kind = match ty {
            "int" => Kind::Int,
            "text" => Kind::Text,
            _ => return Err(bad("unknown type")),
        };
        schema.push(Column {
            name: name.to_owned(),
            kind,
            nullable,
        });
    }
    validate_schema(&schema)?;
    Ok(schema)
}
fn display(row: &[Value]) -> String {
    row.iter()
        .map(|v| match v {
            Value::Int(n) => n.to_string(),
            Value::Text(s) => s.clone(),
            Value::Null => "NULL".into(),
        })
        .collect::<Vec<_>>()
        .join("|")
}
fn main() -> io::Result<()> {
    let dir = std::env::args()
        .nth(1)
        .ok_or_else(|| bad("usage: tables DIRECTORY"))?;
    let mut db = Db::open(Path::new(&dir))?;
    for line in io::stdin().lock().lines() {
        let line = line?;
        let parts: Vec<_> = line.split('|').collect();
        match parts.as_slice() {
            ["create", name, fields @ ..] => {
                db.create(name, parse_schema(fields)?)?;
                println!("CREATED");
            }
            ["insert", name, fields @ ..] => {
                let i = db.table(name)?;
                if fields.len() != db.tables[i].schema.len() {
                    return Err(bad("column count mismatch"));
                }
                let mut row = vec![];
                for (s, c) in fields.iter().zip(&db.tables[i].schema) {
                    row.push(if *s == "NULL" {
                        Value::Null
                    } else {
                        match c.kind {
                            Kind::Int => Value::Int(s.parse().map_err(|_| bad("expected i64"))?),
                            Kind::Text => Value::Text((*s).to_owned()),
                        }
                    });
                }
                let (page, slot) = db.insert(name, row)?;
                println!("RID {page}:{slot}");
            }
            ["get", name, key] => {
                let key = key.parse().map_err(|_| bad("expected i64"))?;
                println!(
                    "{}",
                    db.get(name, key)?
                        .map(|r| display(&r))
                        .unwrap_or_else(|| "(nil)".into())
                );
            }
            ["scan", name] => {
                for row in db.scan(name)? {
                    println!("{}", display(&row));
                }
            }
            [".flush"] => {
                db.flush()?;
                println!("FLUSHED");
            }
            [".exit"] => break,
            [""] => {}
            _ => {
                return Err(bad(
                    "commands: create|TABLE|COL:TYPE...; insert|TABLE|VALUE...; get|TABLE|KEY; scan|TABLE; .flush; .exit",
                ));
            }
        }
    }
    db.flush()
}

이 문자열의 한글 음절은 각각 UTF-8 3바이트입니다.

실제 행은 힙에 저장하고 색인은 페이지·슬롯 위치를 저장합니다.
새 힙 페이지의 최대 행 크기가 4072인 이유는?
헤더 8 + next 8 + slot 0과 새 행의 디렉터리 8 = 24바이트입니다.


실습 과제
  1. NULL과 빈 문자열을 비교하세요. name이 NULL인 행, 빈 문자열인 행, "한글"인 행을 각각 인코딩하세요. 첫 두 행은 길이가 같아도 비트맵과 셀 내용이 달라야 합니다. "한글"의 payload 길이는 6이어야 합니다.
  2. 페이지 경계와 재시작을 검사하세요. 3열 스키마에서 이름 길이를 4045 ASCII 바이트로 만들면 행 길이는 4072입니다. 그 행 하나가 빈 페이지에 들어가고 다음 행은 새 페이지로 가야 합니다. flush 후 재시작해 두 행의 기본키 조회와 scan이 같아야 합니다.
  3. 카탈로그를 여러 페이지로 확장하세요. 현재의 4084바이트 제한을 넘는 테이블 정의를 만들고 먼저 거부를 확인하세요. 그다음 카탈로그 페이지 연결을 추가하고, 첫 페이지를 어디서 찾을지 정하세요. 모든 테이블 정의를 재시작 후 복원하는 검사까지 작성하세요.
