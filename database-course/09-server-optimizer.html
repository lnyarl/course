1. SQL 엔진에 네트워크 경계를 붙이기

서버는 SQL을 새로 해석하지 않습니다. 5장의 파서, 6장의 바인딩·연산자, 4장의 테이블과 3장의 기본키 색인을 재사용합니다. 7장은 파일 사본의 변경을 WAL로 커밋하고 8장은 세션별 사본과 전역 revision을 관리합니다. 이 장은 그 위에 메시지 인코더와 접근 경로 선택을 추가합니다.

호환 범위를 먼저 고정합니다PostgreSQL 제품 서버의 전체 구현이 아닙니다. 프로토콜 3.0의 simple Query, UTF-8·텍스트 결과, BEGIN/COMMIT/ROLLBACK과 기존 SQL 부분집합만 지원합니다. TLS·암호 인증·prepared statement·extended query·COPY·CancelRequest·psql의 역슬래시 메타 명령은 지원하지 않습니다. 수치 IP의 loopback 주소만 바인딩합니다.

2. 길이가 있는 메시지

TCP는 메시지가 아니라 바이트 스트림입니다. 한 번의 read가 헤더 전체나 한 쿼리 전체를 반환한다고 가정하면 안 됩니다. read_exact로 길이를 먼저 읽고, 범위를 검사한 뒤 본문만 할당합니다. 여기서는 길이 필드 4바이트를 포함하여 4~65536바이트만 허용합니다. 정수는 디스크 페이지의 little endian과 달리 네트워크의 big endian입니다.

메시지순서중요한 경계
Startuplength:u32 → protocol:u32 → key/value NUL 쌍 → NULtype byte 없음, protocol=196608
Query'Q':u8 → length:u32 → UTF8 SQL → NULlength는 type을 제외, 한 SQL 문장
DataRow'D' → length → 열 수:u16 → 각 셀 길이:i32 + bytesNULL 길이=-1, 빈 문자열=0
ReadyForQuery'Z' → 00 00 00 05 → 'I' 또는 'T' 또는 'E'명령이 끝난 세션 상태

연결 시작 시 SSLRequest에는 한 바이트 N으로 답하고, AuthenticationOk·ParameterStatus·ReadyForQuery를 보냅니다. 조회는 RowDescription → DataRow들 → CommandComplete → ReadyForQuery 순서입니다. 열 타입은 실제 스키마에서 가져옵니다. 0행 조회에서도 id의 OID=20(INT8), TEXT의 OID=25를 알 수 있습니다.

// ReadyForQuery I의 실제 6바이트
// type        length=5 (길이필드 4 + 상태 1)       status
// 0x5a        0x00 0x00 0x00 0x05                 0x49
frame(&mut out, b'Z', b"I");
// DataRow 셀: NULL=-1=ff ff ff ff; 빈 TEXT=00 00 00 00
// 한글 2자는 UTF-8 6바이트입니다. 문자열 문자 수를 길이로 쓰지 않습니다.
실험 1 · SQL이 패킷 바이트가 되는 과정

오프라인 인코딩 모델입니다. people의 6장 기본 데이터 5행에 SELECT를 실행하며 실제 소켓은 아래 Rust 서버로 확인합니다. RowDescription 단계는 필드 설명만 표시합니다.



오류 응답은 'E' 메시지 안에 severity·SQLSTATE·message를 넣습니다. ReadyForQuery의 상태 E와 ErrorResponse의 type E는 위치가 다릅니다. 잘못된 UTF-8, NUL 경계, 큰 프레임은 실행 전에 거부합니다. 공유 실행기는 결과를 모으는 중 보수적인 8MiB 바이트 예산과 10000행 상한을 검사합니다. 서버도 전송 결과를 8MiB로 제한하고, libpq 텍스트 형식으로 표현할 수 없는 NUL 포함 TEXT는 응답을 보내기 전에 거부합니다.

3. 같은 결과, 다른 접근 경로
6장에서는 모든 SELECT가 SeqScan이었습니다. 이제 WHERE id = 3처럼 기본키의 정수 상수 비교가 반드시 참이어야 하는 조건을 찾습니다. id = 3 AND age IS NULL은 id=3 한 행을 찾고 남은 조건을 검사해도 됩니다. id = 3 OR age IS NULL에서 id=3만 찾으면 다른 행이 사라지므로 허용하지 않습니다. NOT 안에서도 추출하지 않습니다.



비용 모델은 의도적으로 작습니다. DB 전체 힙 데이터 페이지 수 × 8을 추정 행 수와 Seq 비용으로 쓰고 기본키 조회 비용은 3으로 둡니다. 안전한 equality가 있고 Seq 비용 > 3일 때 실제 B+트리 get을 선택합니다. 테이블별 통계나 분포 추정은 없으므로 정확한 성능 예측이 아닙니다. 순차·색인 경로 모두 전체 바인딩을 통과하고 같은 Filter·Sort·Limit·Project를 거칩니다.


실험 2 · 후보를 고르고 결과 동등성 확인
실행 전에 선택 경로와 scan_rows를 예상하세요. 페이지 입력은 추정치만 바꾸며, 조회 데이터는 people 5행으로 고정됩니다. 브라우저의 색인 경로는 키로 고른 메모리 후보이며 Rust는 3장의 실제 B+트리를 조회합니다.


EXPLAIN SELECT ...은 선택 경로·모델 비용·이유를 반환합니다. EXPLAIN ANALYZE SELECT ...은 실제 실행 후 통계도 반환합니다. 이 구현의 scan_rows는 source가 반환한 논리 행 수입니다. 거래 스냅샷의 전체 파일 복사 비용은 빠져 있으므로 “1행 조회 = 물리 I/O 1회” 또는 “전체 쿼리가 N배 빨라짐”으로 읽으면 안 됩니다. EXPLAIN은 SELECT만 받습니다.


4. 연결과 트랜잭션은 수명이 다르다
각 연결은 현재 txid 하나를 가집니다. BEGIN이면 8장의 private snapshot을 만들고 T, 오류가 나면 E, ROLLBACK이나 정상 COMMIT 뒤에는 I입니다. 거래 밖의 SQL은 autocommit입니다. 응답 바이트를 만드는 과정도 성공한 뒤 커밋하므로 응답 상한이나 NUL 오류로 거부된 쓰기가 먼저 공개되지 않습니다.
쓰기 커밋은 7장의 durable WAL 순서를 따릅니다. 커밋 후 네트워크가 끊기면 클라이언트는 성공 여부를 모를 수 있습니다. 연결의 Drop은 남은 사본을 버리지만 이미 durable commit된 변경은 되돌리지 않습니다. 같은 INSERT를 무조건 재시도하면 중복 키를 만날 수 있습니다.


실험 3 · 두 연결을 교차 실행하기
8장의 전체 DB snapshot + 전역 revision OCC를 재현하는 결정적 모델입니다. 이 위젯은 명시적 거래만 조작합니다. A/B가 다른 키를 써도 사이에 쓰기 커밋이 있으면 뒤의 쓰기 커밋은 충돌합니다.

네트워크 서버는 최대 16연결, 30초 read/write timeout, 관리자는 최대 32활성 거래로 제한합니다. 소켓 대기 중 Mutex를 풀어 느린 연결이 다른 연결의 SQL 실행을 막지 않게 합니다. 명령 실행 자체는 직렬화되며 병렬 쿼리 실행기는 아닙니다. DB 디렉터리는 7장의 프로세스 잠금으로 보호되므로 같은 경로를 별도 CLI로 동시에 열지 않습니다.

힌트 · SQL과 프로토콜 사이에 typed Reply를 둡니다
JSON을 다시 파싱하지 말고 열의 이름·타입과 SqlCell::Int/Text/Null을 전달하세요. 행이 0개인 경우에도 스키마는 남아 있어야 합니다. BEGIN/COMMIT/ROLLBACK은 세션 계층이 맡고 나머지 SQL은 기존 파서가 문장 전체를 검사합니다. 프레임 오류와 SQL 오류의 연결 종료 정책도 구분하세요.
힌트 · index 경로도 lazy source입니다
PointScan의 첫 next에서 Store.lookup을 호출하고 그 뒤에는 None을 반환합니다. LIMIT 0은 source를 한 번도 호출하지 않습니다. 바인딩은 source를 만들기 전에 끝내므로 없는 열을 포함한 LIMIT 0은 오류입니다. 조건이 AND로 연결되면 필수 equality 하나를 골라도 나머지 Filter가 모순 조건을 제거합니다.

//! PostgreSQL v3 simple-query teaching server. Loopback only; no authentication/TLS.
use std::{
    io::{self, Read, Write},
    net::{TcpListener, TcpStream},
    path::Path,
    sync::{
        Arc, Mutex,
        atomic::{AtomicUsize, Ordering},
    },
    time::Duration,
};
#[allow(dead_code)]
#[path = "../ch08/transactions.rs"]
mod transactions;
use transactions::{
    Transactions,
    wal::engine::{self, AccessMode, SqlCell, SqlReply, SqlType},
};
const MAX_MESSAGE: usize = 65536;
const MAX_REPLY: usize = 8 * 1024 * 1024;
fn bad(s: &str) -> io::Error {
    io::Error::new(io::ErrorKind::InvalidInput, s)
}
fn frame(out: &mut Vec<u8>, kind: u8, payload: &[u8]) {
    out.push(kind);
    out.extend_from_slice(&((payload.len() + 4) as u32).to_be_bytes());
    out.extend_from_slice(payload);
}
fn cstr(out: &mut Vec<u8>, s: &str) {
    out.extend_from_slice(s.as_bytes());
    out.push(0);
}
fn error(out: &mut Vec<u8>, message: &str) {
    let code = if message.starts_with("serialization conflict:") {
        "40001"
    } else if message.starts_with("database requires recovery") {
        "40003"
    } else if message == "transaction is failed; ROLLBACK required" {
        "25P02"
    } else {
        "42601"
    };
    let mut p = vec![b'S'];
    cstr(&mut p, "ERROR");
    p.push(b'C');
    cstr(&mut p, code);
    p.push(b'M');
    cstr(&mut p, &message.replace('\0', "?"));
    p.push(0);
    frame(out, b'E', &p);
}
fn encode(reply: &SqlReply) -> io::Result<Vec<u8>> {
    let mut out = Vec::new();
    if !reply.columns.is_empty() {
        let mut p = Vec::new();
        p.extend_from_slice(&(reply.columns.len() as u16).to_be_bytes());
        for c in &reply.columns {
            if c.name.contains('\0') {
                return Err(bad("NUL in column name"));
            }
            cstr(&mut p, &c.name);
            p.extend_from_slice(&0u32.to_be_bytes());
            p.extend_from_slice(&0u16.to_be_bytes());
            p.extend_from_slice(&(if c.kind == SqlType::Int { 20u32 } else { 25 }).to_be_bytes());
            p.extend_from_slice(&(if c.kind == SqlType::Int { 8i16 } else { -1 }).to_be_bytes());
            p.extend_from_slice(&(-1i32).to_be_bytes());
            p.extend_from_slice(&0u16.to_be_bytes());
        }
        frame(&mut out, b'T', &p);
        for row in &reply.rows {
            let mut p = Vec::new();
            p.extend_from_slice(&(row.len() as u16).to_be_bytes());
            for c in row {
                let s = match c {
                    SqlCell::Null => {
                        p.extend_from_slice(&(-1i32).to_be_bytes());
                        continue;
                    }
                    SqlCell::Int(v) => v.to_string(),
                    SqlCell::Text(v) => v.clone(),
                };
                if s.contains('\0') {
                    return Err(bad("NUL text cannot be sent through libpq text format"));
                }
                p.extend_from_slice(&(s.len() as u32).to_be_bytes());
                p.extend_from_slice(s.as_bytes());
            }
            frame(&mut out, b'D', &p);
            if out.len() > MAX_REPLY {
                return Err(bad("result exceeds 8 MiB wire limit"));
            }
        }
    }
    let mut p = Vec::new();
    cstr(&mut p, &reply.tag);
    frame(&mut out, b'C', &p);
    Ok(out)
}
fn command(tag: &str) -> SqlReply {
    SqlReply {
        columns: vec![],
        rows: vec![],
        tag: tag.into(),
        json: format!("{{\"command\":\"{tag}\"}}"),
    }
}
fn words_prefix<'a>(s: &'a str, keyword: &str) -> Option<&'a str> {
    let s = s.trim_start();
    if s.len() >= keyword.len()
        && s.get(..keyword.len())
            .is_some_and(|head| head.eq_ignore_ascii_case(keyword))
        && s[keyword.len()..].starts_with(char::is_whitespace)
    {
        Some(s[keyword.len()..].trim_start())
    } else {
        None
    }
}
fn query(manager: &mut Transactions, tx: &mut Option<u64>, sql: &str) -> io::Result<Vec<u8>> {
    let control = sql
        .trim()
        .strip_suffix(';')
        .unwrap_or(sql.trim())
        .trim()
        .to_ascii_uppercase();
    let result = (|| {
        match control.as_str() {
            "BEGIN" => {
                if tx.is_some() {
                    return Err(bad("transaction already active"));
                }
                *tx = Some(manager.begin()?);
                return encode(&command("BEGIN"));
            }
            "COMMIT" => {
                if let Some(id) = *tx {
                    manager.commit(id)?;
                    *tx = None;
                }
                return encode(&command("COMMIT"));
            }
            "ROLLBACK" => {
                if let Some(id) = tx.take() {
                    manager.rollback(id)?;
                }
                return encode(&command("ROLLBACK"));
            }
            "" => {
                let mut out = vec![];
                frame(&mut out, b'I', &[]);
                return Ok(out);
            }
            _ => {}
        }
        let (inner, explain, analyze) = if let Some(rest) = words_prefix(sql, "EXPLAIN") {
            if let Some(rest) = words_prefix(rest, "ANALYZE") {
                (rest, true, true)
            } else {
                (rest, true, false)
            }
        } else {
            (sql, false, false)
        };
        // Snapshot::query_with validates the complete inner statement before the callback.
        let runner = |path: &Path, statement: &str| {
            let reply = if explain {
                engine::explain(path, statement, analyze)?
            } else {
                engine::run_optimized(path, statement)?
            };
            encode(&reply)
        };
        if let Some(id) = *tx {
            manager.query_with(id, inner, runner)
        } else {
            manager.autocommit_with(inner, runner)
        }
    })();
    if result.is_err() {
        if let Some(id) = *tx {
            let _ = manager.mark_failed(id);
        }
    }
    result
}
fn read_length(stream: &mut TcpStream) -> io::Result<usize> {
    let mut b = [0; 4];
    stream.read_exact(&mut b)?;
    let n = u32::from_be_bytes(b) as usize;
    if !(4..=MAX_MESSAGE).contains(&n) {
        return Err(bad("message length outside 4..65536"));
    }
    Ok(n - 4)
}
fn startup(stream: &mut TcpStream) -> io::Result<()> {
    for _ in 0..3 {
        let len = read_length(stream)?;
        let mut p = vec![0; len];
        stream.read_exact(&mut p)?;
        if p.len() < 4 {
            return Err(bad("short startup"));
        }
        let code = u32::from_be_bytes(p[..4].try_into().unwrap());
        if code == 80877103 || code == 80877104 {
            if p.len() != 4 {
                return Err(bad("invalid negotiation"));
            }
            stream.write_all(b"N")?;
            continue;
        }
        if code != 196608 {
            return Err(bad("only PostgreSQL protocol 3.0 supported"));
        }
        if p.last() != Some(&0) {
            return Err(bad("unterminated startup"));
        }
        let fields = p[4..].split(|b| *b == 0).collect::<Vec<_>>();
        if fields.len() < 2 || !fields[fields.len() - 2].is_empty() || (fields.len() - 2) % 2 != 0 {
            return Err(bad("invalid startup key/value pairs"));
        }
        for pair in fields[..fields.len() - 2].chunks(2) {
            let key = std::str::from_utf8(pair[0]).map_err(|_| bad("startup UTF-8"))?;
            let value = std::str::from_utf8(pair[1]).map_err(|_| bad("startup UTF-8"))?;
            if key == "client_encoding"
                && !value.eq_ignore_ascii_case("UTF8")
                && !value.eq_ignore_ascii_case("UTF-8")
            {
                return Err(bad("UTF8 client encoding required"));
            }
        }
        let mut out = vec![];
        frame(&mut out, b'R', &0u32.to_be_bytes());
        for (k, v) in [
            ("server_version", "16.0"),
            ("client_encoding", "UTF8"),
            ("server_encoding", "UTF8"),
            ("standard_conforming_strings", "on"),
            ("integer_datetimes", "on"),
        ] {
            let mut p = vec![];
            cstr(&mut p, k);
            cstr(&mut p, v);
            frame(&mut out, b'S', &p);
        }
        frame(&mut out, b'Z', b"I");
        stream.write_all(&out)?;
        return Ok(());
    }
    Err(bad("too many startup negotiations"))
}
struct Session {
    manager: Arc<Mutex<Transactions>>,
    tx: Option<u64>,
}
impl Drop for Session {
    fn drop(&mut self) {
        if let Some(id) = self.tx.take() {
            if let Ok(mut m) = self.manager.lock() {
                let _ = m.rollback(id);
            }
        }
    }
}
fn serve_client(mut stream: TcpStream, manager: Arc<Mutex<Transactions>>) -> io::Result<()> {
    stream.set_read_timeout(Some(Duration::from_secs(30)))?;
    stream.set_write_timeout(Some(Duration::from_secs(30)))?;
    startup(&mut stream)?;
    let mut session = Session { manager, tx: None };
    loop {
        let mut kind = [0];
        match stream.read_exact(&mut kind) {
            Ok(()) => {}
            Err(e) if e.kind() == io::ErrorKind::UnexpectedEof => return Ok(()),
            Err(e) => return Err(e),
        }
        let len = read_length(&mut stream)?;
        let mut p = vec![0; len];
        stream.read_exact(&mut p)?;
        if kind[0] == b'X' {
            if !p.is_empty() {
                return Err(bad("invalid Terminate"));
            }
            return Ok(());
        }
        if kind[0] != b'Q' {
            let mut out = vec![];
            error(
                &mut out,
                "only simple Query is supported; extended protocol closes connection",
            );
            stream.write_all(&out)?;
            return Ok(());
        }
        let mut out = vec![];
        {
            let mut m = session
                .manager
                .lock()
                .map_err(|_| bad("database mutex poisoned"))?;
            let result = if p.last() != Some(&0) || p[..p.len().saturating_sub(1)].contains(&0) {
                Err(bad("Query requires exactly one trailing NUL"))
            } else {
                std::str::from_utf8(&p[..p.len() - 1])
                    .map_err(|_| bad("Query requires UTF-8"))
                    .and_then(|s| query(&mut m, &mut session.tx, s))
            };
            match result {
                Ok(reply) => out = reply,
                Err(e) => {
                    if let Some(id) = session.tx {
                        let _ = m.mark_failed(id);
                    }
                    error(&mut out, &e.to_string());
                }
            }
            let status = session.tx.and_then(|id| m.status(id)).unwrap_or('I');
            frame(&mut out, b'Z', &[status as u8]);
        }
        stream.write_all(&out)?;
    }
}
struct Permit(Arc<AtomicUsize>);
impl Drop for Permit {
    fn drop(&mut self) {
        self.0.fetch_sub(1, Ordering::SeqCst);
    }
}
const MAX_SQL_BYTES: usize = 16 * 1024;
fn read_sql(input: impl Read) -> io::Result<String> {
    let mut bytes = Vec::new();
    input
        .take((MAX_SQL_BYTES + 1) as u64)
        .read_to_end(&mut bytes)?;
    if bytes.len() > MAX_SQL_BYTES {
        return Err(bad("SQL exceeds 16384 bytes"));
    }
    String::from_utf8(bytes).map_err(|_| bad("SQL requires UTF-8"))
}
fn main() -> io::Result<()> {
    let args = std::env::args().skip(1).collect::<Vec<_>>();
    if args.len() < 2 {
        return Err(bad(
            "usage: server serve DIRECTORY [127.0.0.1:55432] | server sql DIRECTORY [--seq|--index]",
        ));
    }
    if args[0] == "serve" {
        let addr = args
            .get(2)
            .map(String::as_str)
            .unwrap_or("127.0.0.1:55432")
            .parse::<std::net::SocketAddr>()
            .map_err(|_| bad("numeric socket address required"))?;
        if !addr.ip().is_loopback() {
            return Err(bad("loopback binding required"));
        }
        let manager = Arc::new(Mutex::new(Transactions::open(Path::new(&args[1]))?));
        let listener = TcpListener::bind(addr)?;
        println!("LISTEN {}", listener.local_addr()?);
        io::stdout().flush()?;
        let active = Arc::new(AtomicUsize::new(0));
        for incoming in listener.incoming() {
            let stream = incoming?;
            if active.fetch_add(1, Ordering::SeqCst) >= 16 {
                active.fetch_sub(1, Ordering::SeqCst);
                drop(stream);
                continue;
            }
            let permit = Permit(active.clone());
            let m = manager.clone();
            std::thread::spawn(move || {
                let _permit = permit;
                if let Err(e) = serve_client(stream, m) {
                    eprintln!("session: {e}");
                }
            });
        }
        Ok(())
    } else if args[0] == "sql" {
        let sql = read_sql(io::stdin().lock())?;
        let mut m = Transactions::open(Path::new(&args[1]))?;
        let mode = match args.get(2).map(String::as_str) {
            None => AccessMode::Auto,
            Some("--seq") => AccessMode::Sequential,
            Some("--index") => AccessMode::ForceIndex,
            _ => return Err(bad("unknown access mode")),
        };
        let reply = m.autocommit_with(&sql, |p, s| engine::run_mode(p, s, mode))?;
        println!("{}", reply.json);
        Ok(())
    } else {
        Err(bad("unknown command"))
    }
}

// A necessary PK equality is safe under AND, never inferred through OR or NOT.
fn necessary_key(e: &Expr, pk: &str) -> Option<i64> {
    match e {
        Expr::Compare(Operand::Column(c), Cmp::Eq, Operand::Value(Datum::Int(n)))
        | Expr::Compare(Operand::Value(Datum::Int(n)), Cmp::Eq, Operand::Column(c))
            if c == pk =>
        {
            Some(*n)
        }
        Expr::And(a, b) => necessary_key(a, pk).or_else(|| necessary_key(b, pk)),
        _ => None,
    }
}
fn report(
    store: &storage::Store,
    fields: &[Field],
    filter: &Option<Expr>,
    mode: AccessMode,
) -> io::Result<PlanReport> {
    let estimate = store.heap_pages().saturating_mul(8).max(1);
    let key = filter
        .as_ref()
        .and_then(|e| necessary_key(e, &fields[0].name));
    let index_cost = key.map(|_| 3);
    let choose = key.is_some()
        && mode != AccessMode::Sequential
        && (mode == AccessMode::ForceIndex || estimate > 3);
    if mode == AccessMode::ForceIndex && key.is_none() {
        return Err(bad("no necessary primary-key equality for index lookup"));
    }
    Ok(PlanReport {
        access: if choose {
            "PrimaryKeyLookup"
        } else {
            "SeqScan"
        }
        .into(),
        estimated_rows: estimate,
        estimated_cost: if choose { 3 } else { estimate },
        seq_cost: estimate,
        index_cost,
        lookup_key: key,
        reason: if choose {
            "necessary primary-key equality; index model cost is lower"
        } else if key.is_none() {
            "no safe primary-key point predicate"
        } else {
            "sequential access requested or estimated scan is cheaper"
        }
        .into(),
    })
}
struct PointScan<'a> {
    store: &'a mut storage::Store,
    table: String,
    key: i64,
    done: bool,
    stats: Counters,
}
impl Op for PointScan<'_> {
    fn next(&mut self) -> io::Result<Option<Row>> {
        if self.done {
            return Ok(None);
        }
        self.done = true;
        let row = self.store.lookup(&self.table, self.key)?;
        if row.is_some() {
            self.stats.borrow_mut().scan_rows += 1;
        }
        Ok(row)
    }
}
pub fn inspect(dir: &Path, sql: &str, mode: AccessMode) -> io::Result<PlanReport> {
    let Stmt::Select {
        table,
        columns,
        filter,
        order,
        limit,
    } = language::ast(sql)?
    else {
        return Err(bad("EXPLAIN supports SELECT only"));
    };
    let store = storage::Store::open(dir, false)?;
    let fields = store.fields(&table)?;
    bind_select(&fields, columns, filter.clone(), order, limit)?;
    report(&store, &fields, &filter, mode)
}
// Bound bytes while collecting, before JSON and typed-response copies are built.
// Six bytes per UTF-8 byte covers JSON control escaping; per-cell overhead covers
// both JSON type wrappers and wire lengths. The budget is intentionally conservative.
fn collect_bounded(mut op: Box<dyn Op + '_>, stats: &Counters) -> io::Result<Vec<Row>> {
    let mut rows = Vec::new();
    let mut bytes = 4096usize;
    while let Some(row) = op.next()? {
        let row_bytes = row.iter().fold(0usize, |sum, value| {
            sum.saturating_add(64).saturating_add(match value {
                Datum::Text(s) => s.len().saturating_mul(6),
                Datum::Int(_) => 20,
                Datum::Null => 0,
            })
        });
        bytes = bytes.saturating_add(row_bytes);
        if bytes > 8 * 1024 * 1024 || rows.len() >= BUFFER_ROWS {
            return Err(bad(
                "result exceeds conservative 8 MiB or 10000 row buffer limit",
            ));
        }
        stats.borrow_mut().output_rows += 1;
        rows.push(row);
    }
    Ok(rows)
}

pub fn run_mode(dir: &Path, sql: &str, mode: AccessMode) -> io::Result<SqlReply> {
    let stmt = language::ast(sql)?;
    if let Stmt::Create { table, fields } = &stmt {
        validate_create(table, fields)?;
    }
    let mut store = storage::Store::open(dir, matches!(stmt, Stmt::Create { .. }))?;
    match stmt {
        Stmt::Select {
            table,
            columns,
            filter,
            order,
            limit,
        } => {
            let fields = store.fields(&table)?;
            let plan = bind_select(&fields, columns, filter.clone(), order, limit)?;
            let access = report(&store, &fields, &filter, mode)?;
            let stats = counters();
            let output_columns = plan
                .columns
                .iter()
                .map(|&i| SqlColumn {
                    name: fields[i].name.clone(),
                    kind: if fields[i].kind == Type::Int {
                        SqlType::Int
                    } else {
                        SqlType::Text
                    },
                })
                .collect();
            let source: Box<dyn Op + '_> = if access.access == "PrimaryKeyLookup" {
                Box::new(PointScan {
                    store: &mut store,
                    table,
                    key: access.lookup_key.unwrap(),
                    done: false,
                    stats: stats.clone(),
                })
            } else {
                Box::new(store.scan(&table, stats.clone())?)
            };
            let rows = collect_bounded(pipeline(source, &plan, stats.clone()), &stats)?;
            let json = output(&plan.names, &rows, &stats.borrow());
            Ok(SqlReply {
                columns: output_columns,
                rows: rows
                    .iter()
                    .map(|r| r.iter().map(sql_cell).collect())
                    .collect(),
                tag: format!("SELECT {}", rows.len()),
                json,
            })
        }
        s => {
            let tag = if matches!(&s, Stmt::Create { .. }) {
                "CREATE TABLE"
            } else {
                "INSERT 0 1"
            };
            let json = execute(&mut store, s)?;
            Ok(SqlReply {
                columns: vec![],
                rows: vec![],
                tag: tag.into(),
                json,
            })
        }
    }
}
pub fn explain(dir: &Path, sql: &str, analyze: bool) -> io::Result<SqlReply> {
    let p = inspect(dir, sql, AccessMode::Auto)?;
    let mut lines = vec![
        format!(
            "{} (estimated cost={}, rows={})",
            p.access, p.estimated_cost, p.estimated_rows
        ),
        format!("Reason: {}", p.reason),
        "Estimate: global heap pages × 8; model units, not measured I/O or time".into(),
    ];
    if analyze {
        let result = run_optimized(dir, sql)?;
        lines.push(format!("Actual output rows: {}", result.rows.len()));
        lines.push(result.json);
    }
    let rows = lines
        .iter()
        .map(|s| vec![SqlCell::Text(s.clone())])
        .collect::<Vec<_>>();
    let json = format!(
        "{{\"columns\":[\"QUERY PLAN\"],\"rows\":[{}]}}",
        lines
            .iter()
            .map(|s| format!("[{{\"type\":\"text\",\"value\":{}}}]", q(s)))
            .collect::<Vec<_>>()
            .join(",")
    );
    Ok(SqlReply {
        columns: vec![SqlColumn {
            name: "QUERY PLAN".into(),
            kind: SqlType::Text,
        }],
        rows,
        tag: "EXPLAIN".into(),
        json,
    })
}

        n=struct.unpack('!H',p[:2])[0];offset=2;row=[]
        for _ in range(n):
            size=struct.unpack('!i',p[offset:offset+4])[0];offset+=4
            row.append(None if size==-1 else p[offset:offset+size].decode());offset+=max(size,0)
        out.append(row)
    return out

6. 완료 기준과 확인 문제
  • SSLRequest N 응답 뒤 psql이 UTF-8·NULL·빈 TEXT·0행 결과를 읽습니다.
  • 한 Q의 여러 SQL은 일부 실행 없이 거부합니다.
  • 두 세션의 반복 읽기·쓰기 충돌·오류 후 E·ROLLBACK·연결 종료를 검사합니다.
  • 기본키 조회와 강제 SeqScan 결과가 같고 OR/NOT은 안전하게 SeqScan입니다.
  • LIMIT 0에서 바인딩은 수행하고 source pull은 생략합니다.
  • ACK 후 서버를 종료·재시작해 커밋 데이터만 남는지 확인합니다.
  • WAL 동기화 후 설치 실패는 복구가 필요하며 일반 rollback으로 성공 취소를 주장하지 않습니다.
Query의 length가 9이면 type을 포함한 프레임 길이는?
length에는 자신의 4바이트를 포함하지만 맨 앞의 type 1바이트는 포함하지 않습니다.
id = 3 OR age IS NULL에서 id=3만 조회해도 되나요?
색인 후보는 반드시 충족해야 하는 조건이어야 합니다.
거래 안에서 SQL 오류 뒤 ReadyForQuery 상태는?
ROLLBACK 전에는 E이며 일반 SQL과 COMMIT을 거부합니다.
scan_rows가 1이면 물리 디스크 읽기도 1회인가요?
스냅샷 파일 복사와 버퍼·색인 I/O는 이 카운터에 포함되지 않습니다.
COMMIT 뒤 응답이 도착하기 전에 연결이 끊겼다면?
durable commit 이후 네트워크 전달은 별도 경계입니다.
마지막 통합 실습 · 커밋에서 복구까지
이미 설치된 psql과 이 장의 서버 바이너리로 실행하세요. capstone.py는 임시 DB를 만들고 실제 psql 접속·COMMIT·ROLLBACK을 실행합니다. COMMIT 응답 뒤 서버를 강제 종료하고 같은 DB를 재시작한 다음, 기본키 조회와 순차 조회 결과를 비교합니다.

예상 결과: 복구 후 id=1의 Roy와 id=2의 NULL만 남고, ROLLBACK한 id=3은 없습니다. 같은 id=1 조회는 두 경로에서 동일한 행을 반환하며 논리 scan_rows는 Seq=2, Index=1입니다. CLI 비교 전에 서버를 종료해 같은 디렉터리 잠금이 충돌하지 않게 합니다. 마지막 PASS까지 확인하고 실제 출력·선택 경로·복구 순서를 실습 결과로 남기세요.
이 스크립트는 psql 설치가 필요해 기본 check-all에서는 실행하지 않습니다. 기본 검사는 의존성 없는 실제 소켓 프로토콜 검사를 포함합니다. 여기서 측정하는 scan_rows는 물리 I/O나 속도가 아닙니다.
실습 과제
  1. 반례부터 찾으세요. id=1 OR id=3을 기본키 단건으로 실행했을 때 잃는 행을 기록하고 실제 경로가 SeqScan인지 확인하세요.
  2. 추정과 실행을 분리하세요. 페이지 추정치를 바꾸어도 결과가 같은지 확인하고, 실제 source 행 수를 강제 순차·색인 경로에서 비교하세요.
  3. 네트워크 경계를 흔드세요. 헤더를 한 바이트씩 보내도 처리되는 검사와 잘못된 길이·UTF-8·내부 NUL 검사에 성공해야 합니다.
  4. 다음 통계를 설계하세요. 테이블별 행 수·NDV·NULL 비율을 카탈로그에 저장하고, 같은 조건에서 결과 동등성을 먼저 검사한 뒤 비용 모델을 확장하세요.


7. 완성한 엔진의 경계
9장까지 이어지는 작은 DB를 완성했습니다. psql → SQL 파서 → 바인딩 → 기본키 조회 또는 순차 실행 → 페이지·B+트리 → private snapshot → WAL 커밋과 복구가 하나의 코드 경로로 연결됩니다. 전체 소스와 실행 안내, 1~9장 통합 검사, 소스 ZIP을 함께 제공합니다.
SQL UPDATE·DELETE·JOIN 문법, 집계·보조 색인·통계 기반 다중 계획 탐색, 행 버전 MVCC·세밀한 잠금, 외부 정렬, 복제, 인증·암호화는 구현하지 않았습니다. 전체 파일 사본과 afterimage WAL은 작은 학습 데이터용입니다. fsync·rename 순서와 프로세스 크래시는 검사하지만 실제 전원 차단·장치 캐시의 내구성 보장은 별도입니다. Linux fsync와 macOS F_FULLFSYNC의 차이도 2·7장의 설명을 참고하세요.
