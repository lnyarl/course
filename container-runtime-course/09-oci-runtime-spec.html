OCI 런타임 스펙

1장에서 "우리가 만드는 myctr는 runc 자리"라고 했습니다. 이 장에서 실제로 그 자리에 앉힙니다. Docker는 컨테이너를 직접 만들지 않습니다. containerd에게 맡기고, containerd는 OCI 런타임 명세를 따르는 프로그램(기본값 runc)을 부릅니다. 이 명세는 "bundle 디렉터리에 config.json과 rootfs가 있고, create·start·state·kill·delete 명령으로 다룬다"는 약속입니다. myctr가 이 약속을 지키면, docker run --runtime=myctr로 Docker의 컨테이너가 myctr 위에서 돕니다. 1~8장에서 만든 모든 조각이 config.json의 한 줄 한 줄에 대응합니다.

학습 목표

  • OCI 런타임 명세의 bundle, config.json, 상태, 생명주기를 설명할 수 있다.
  • Docker → containerd → shim → 런타임으로 이어지는 호출을 관찰하고, 런타임이 받는 인자를 해석할 수 있다.
  • create와 start를 나누는 이유와 exec.fifo, O_PATH fd 재열기 같은 runc의 기법을 구현할 수 있다.
  • config.json의 네임스페이스·마운트·cgroup·capability·seccomp를 1~8장의 코드에 연결할 수 있다.
  • Docker 형식의 seccomp 프로파일을 BPF 필터로 번역할 수 있다.
  • myctr를 Docker 런타임으로 등록해 완료 기준 28개를 통과시킨다.
이 장은 8장 참조 구현에서 이어집니다 myctr run, pull, images는 그대로 두고, OCI 명령(spec, create, start, state, kill, delete, features)을 src/oci.rs에 새로 만듭니다. image.rs는 바뀌지 않습니다. 이 장의 모든 출력은 Docker 29.9.2(containerd, runc 1.5.2 기본 설치)를 docker-in-docker로 띄워 확인한 실제 결과입니다.

2. Docker는 런타임을 어떻게 부르나

추측하지 않고 관찰했습니다. 받은 인자와 config.json을 기록한 뒤 runc로 넘기는 셸 스크립트를 런타임으로 등록하고 docker run을 실행했습니다.

#!/bin/sh
# 감시용 런타임: 받은 인자와 config.json을 기록하고 runc로 넘긴다
echo "$(date +%T.%N | cut -c1-12) $*" >> /tmp/calls.log
prev=""
for a in "$@"; do
  if [ "$prev" = "--bundle" ]; then cp "$a/config.json" /tmp/config-$(date +%s%N).json; fi
  prev="$a"
done
exec runc "$@"
docker run과 docker stop 동안의 런타임 호출
기록된 실제 호출입니다(긴 경로와 컨테이너 id는 줄임). docker run -d ... sleep 100 후 docker stop -t 2를 한 경우입니다. 단계를 넘기며 각 호출의 의미를 보세요.
  • features는 실제로 쓰인다: 같은 docker run -v /vol:/data:ro에 대해 Docker는 runc에게 ["rbind", "rro", "rprivate"]를, myctr에게는 ["rbind", "ro", "rprivate"]를 넘겼습니다(둘 다 기록해 확인). rro는 하위 마운트까지 재귀적으로 읽기 전용으로 만드는 새 옵션(커널 5.12+ mount_setattr)인데, runc의 features에는 있고 myctr의 features에는 없기 때문입니다. 런타임이 지원하지 않는 옵션은 보내지 않는 협상입니다.
  • 전역 옵션은 명령 앞에 온다: --root(런타임 상태 디렉터리), --log(에러를 남길 JSON 파일), --log-format json. myctr는 clap의 global = true로 받습니다.
  • create는 기다리지 않고 끝나야 한다: containerd는 create가 끝나야 다음으로 갑니다. 컨테이너 프로세스는 계속 살아 있어야 하므로, myctr는 init을 만들어 두고 자신은 종료합니다. init은 shim(서브리퍼, 2장 7절)이 입양해 회수합니다.
  • delete --force는 두 번: 이미 지운 컨테이너를 다시 지워도 성공해야 합니다. runc도 그렇게 동작했습니다(runc delete --force nonexistent → 0).
  • stop = kill 15 → (기다림) → kill 9: sleep은 PID 1이라 SIGTERM을 무시했고(2장), 2초 뒤 SIGKILL을 받아 137로 끝났습니다.

3. config.json: 1~8장의 지도

Docker가 bundle에 넣은 실제 config.json입니다(docker run alpine:3.24 sleep 100, ociVersion 1.3.0). 지금까지 만든 기능이 거의 그대로 들어 있습니다. 왼쪽 항목을 누르면 내용과, 그것을 처음 다룬 장을 보여 줍니다.

값은 실제 파일에서 가져왔고, 긴 목록은 줄였습니다.

몇 가지는 예상과 달랐습니다. 이 장의 구현이 신경 쓴 부분입니다.

  • network 네임스페이스에 path가 없다: 새로 만들라는 뜻입니다. Docker는 create 뒤, start 전에 init의 PID로 그 네임스페이스를 찾아 veth를 꽂습니다(6장의 부모 역할을 Docker가 함). 그래서 myctr는 네트워크를 몰라도 -p 8080:80까지 동작했습니다.
  • time과 cgroup 네임스페이스를 요청한다: 둘 다 그냥 clone 플래그로는 처리할 수 없습니다(6절).
  • root.path는 이미 overlay로 마운트된 디렉터리다: Docker(containerd)가 8장의 일을 미리 해 둡니다. 런타임은 그 디렉터리로 pivot_root만 하면 됩니다.
  • seccomp는 allow-list: 기본값 SCMP_ACT_ERRNO와 허용 그룹 18개(이름 385개). 7장의 deny-list와 반대입니다(8절).

4. create와 start를 나누는 이유

myctr run은 컨테이너를 만들고 곧바로 프로그램을 실행했습니다. OCI는 이것을 둘로 나눕니다. create는 네임스페이스, cgroup, 마운트, 권한까지 모두 준비하고 사용자 프로그램 직전에서 멈춥니다. start는 그 멈춤을 풉니다. 그 사이에 바깥(Docker)이 할 일이 있기 때문입니다. 네트워크 연결이 대표적입니다. 프로그램이 시작될 때 이미 eth0이 있어야 하니까요(6장에서 파이프로 해결한 문제와 같습니다. 이번에는 기다리는 쪽이 프로세스 경계를 넘어 있을 뿐).

5. 상태와 생명주기

OCI 명세는 컨테이너 상태를 creating, created, running, stopped로 정합니다. myctr는 상태를 따로 기록하지 않고 사실로부터 계산합니다. state.json에는 init의 PID와 시작 시각만 남깁니다.

7. 마운트, 가리기, 읽기 전용

3장은 /proc와 /dev를 코드에 박아 넣었습니다. 이제는 config.json의 mounts 배열을 순서대로 처리하는 일반화된 마운트 루프가 필요합니다.

  • 옵션 문자열 해석: ro, nosuid, nodev, noexec, rbind, rprivate 등은 마운트 플래그로, 나머지(mode=755, newinstance, gid=5)는 파일시스템에 넘기는 데이터 문자열로 나눕니다.
  • bind는 두 번 마운트한다: bind 마운트는 처음 마운트할 때 MS_RDONLY 같은 플래그를 무시합니다. MS_REMOUNT | MS_BIND | MS_RDONLY로 다시 마운트해야 읽기 전용이 됩니다. docker run -v /vol:/data:ro에서 쓰기가 Read-only file system으로 거부되는 것을 확인했습니다.
  • 파일을 bind하려면 대상도 파일이어야 한다: Docker는 /etc/hostname, /etc/hosts, /etc/resolv.conf를 파일 bind로 넣습니다(8장에서 myctr가 직접 쓰던 그 파일들).
  • 대상 경로의 심볼릭 링크: rootfs 안의 경로 중간에 링크가 있으면 rootfs 밖을 가리킬 수 있습니다. runc는 링크를 rootfs 안에서만 풀어 주는 별도 라이브러리를 쓰고, myctr는 더 단순하게 링크가 있으면 거부합니다(8장 8절과 같은 이유).
  • cgroup 마운트: "type": "cgroup"은 이 코스가 v2만 다루므로 cgroup2로 마운트합니다. cgroup 네임스페이스 덕분에 자기 cgroup만 보입니다.

pivot_root 뒤에는 7장 8절에서 미뤘던 두 목록을 처리합니다. Docker로 실행해 확인한 결과입니다.

8. seccomp 프로파일 번역

Docker의 기본 seccomp 프로파일은 7장과 반대로 "기본 거부, 목록만 허용"입니다. 실제 config.json의 구조는 이렇습니다.

그룹action내용
1ALLOW시스템 콜 361개 (accept, read, openat, execve ...)
2ALLOWprocess_vm_readv/writev, ptrace (커널 4.8 이상에서 허용)
3~9ALLOW + 인자 조건socket: 첫 인자(주소 계열)가 38 미만이거나 39, 41~45일 때만
10~14ALLOW + 인자 조건personality: 특정 값만
16ALLOW + 인자 조건clone: (flags & 0x7E020000) == 0, 즉 네임스페이스 플래그가 없을 때만 (7장 deny-list의 한계를 막는 규칙)
17ERRNO(38)clone3: ENOSYS를 돌려준다. 인자가 구조체 포인터라 플래그를 검사할 수 없으니, "없는 시스템 콜"인 척해 glibc가 clone으로 되돌아가게 한다

seccompiler의 필터 하나는 "일치하면 이 action, 아니면 저 action" 두 가지뿐입니다. 그래서 프로파일을 필터 두 개로 번역합니다.

필터 1 (허용 목록): 불일치 → ERRNO(EPERM),  일치 → ALLOW   ← 그룹 1~16, 18
필터 2 (errno 38):  불일치 → ALLOW,         일치 → ERRNO(38) ← 그룹 17 (clone3)

clone3는 필터 1에도 없으니 EPERM, 필터 2에서는 ENOSYS입니다. 커널은 모든 필터를 실행해 가장 우선순위가 높은 판정을 고르고, 같은 우선순위(둘 다 ERRNO)면 나중에 설치한 필터의 값을 씁니다. 그래서 필터 2를 뒤에 설치하면 ENOSYS가 됩니다. 직접 만든 탐침으로 확인했습니다.

$ docker run --rm --runtime=myctr -v /x/clone3probe:/probe:ro alpine:3.24 /probe
clone3 -> -1 errno=38 (Function not implemented (os error 38))
$ docker run --rm --runtime=runc  -v /x/clone3probe:/probe:ro alpine:3.24 /probe
clone3 -> -1 errno=38 (Function not implemented (os error 38))     ← runc와 같다

이름을 번호로

프로파일은 시스템 콜을 이름으로 적습니다. 번호는 아키텍처마다 다르고(7장), chown32처럼 aarch64에는 아예 없는 이름도 섞여 있습니다. seccompiler는 이름표를 갖고 있지만 공개하지 않으므로, myctr는 프로파일을 seccompiler의 JSON 형식으로 바꿔 compile_from_json으로 컴파일하고, 없는 이름은 "이름 하나짜리 필터를 컴파일해 보는" 방식으로 걸러 냅니다. 결과는 BPF 명령 1405개(허용 목록)와 10개(clone3)였습니다.

실제로 겪은 버그: exit조차 막히다 처음 만든 코드로 docker run을 했더니 아무 출력 없이 멈췄습니다. init을 살펴보니 CPU를 100% 쓰며 exit(-1) = -1 EPERM을 끝없이 반복하고 있었습니다. 원인은 이름을 걸러 내는 시험용 필터였습니다. "일치 → allow, 불일치 → allow"로 만들었는데, seccompiler는 두 action이 같은 필터를 거부합니다. 그래서 모든 이름이 "없는 시스템 콜"로 판정되어 허용 목록이 비었고, 설치 뒤 init이 에러를 보고하고 끝내려는 exit까지 막혔습니다. glibc의 _exit는 실패하면 다시 시도하므로 무한 루프가 됩니다. seccomp를 설치한 뒤의 실패는 이렇게 프로세스가 스스로 끝나지도 못하는 형태로 나타날 수 있습니다. 시험용 필터의 일치 action을 errno로 바꿔 고쳤고, Docker에 넣기 전에 Docker 프로파일로 먼저 시험하는 순서를 지켰습니다.

한 가지 차이가 남습니다. seccompiler의 apply_filter는 no_new_privs를 스스로 켜므로(7장 5절), config의 noNewPrivileges가 false여도 seccomp가 있으면 켜집니다. runc는 CAP_SYS_ADMIN이 있을 때 no_new_privs 없이 필터를 설치합니다. 컨테이너 안의 setuid 프로그램(sudo 등)이 다르게 동작할 수 있는 지점입니다.

#[derive(Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
struct Saved {
    id: String,
    pid: i32,
    /// /proc/<pid>/stat의 starttime. PID가 재사용되어도 다른 프로세스를 가리키지 않게
    starttime: u64,
    bundle: PathBuf,
    rootfs: PathBuf,
    created: String,
    cgroup: PathBuf,
}

fn state_dir(root: &Path, id: &str) -> Result<PathBuf> {
    // id는 경로로 쓰이므로 글자를 제한한다
    if id.is_empty() || !id.bytes().all(|b| b.is_ascii_alphanumeric() || b"_.-".contains(&b)) {
        bail!("잘못된 컨테이너 id: {id}");
    }
    Ok(root.join(id))
}

fn load(root: &Path, id: &str) -> Result<Saved> {
    let path = state_dir(root, id)?.join("state.json");
    // from_reader에 File을 그대로 주면 1바이트씩 read한다 (strace로 확인). 통째로 읽어 해석한다
    let bytes = fs::read(&path).with_context(|| format!("컨테이너가 없습니다: {id}"))?;
    Ok(serde_json::from_slice(&bytes)?)
}

/// (상태 글자, starttime)
fn proc_stat(pid: i32) -> Option<(char, u64)> {
    let stat = fs::read_to_string(format!("/proc/{pid}/stat")).ok()?;
    // 두 번째 필드(comm)에 공백이나 괄호가 있을 수 있으므로 마지막 ')' 뒤부터 센다
    let rest = &stat[stat.rfind(')')? + 2..];
    let fields: Vec<&str> = rest.split(' ').collect();
    Some((fields[0].chars().next()?, fields[19].parse().ok()?))
}

fn status(root: &Path, s: &Saved) -> &'static str {
    match proc_stat(s.pid) {
        Some((state, start)) if start == s.starttime && state != 'Z' => {
            if root.join(&s.id).join("exec.fifo").exists() { "created" } else { "running" }
        }
        _ => "stopped",
    }
}

pub fn start(root: &Path, id: &str) -> Result<()> {
    let s = load(root, id)?;
    if status(root, &s) != "created" {
        bail!("{id}: created 상태가 아닙니다 ({})", status(root, &s));
    }
    // init은 쓰기용으로 fifo를 열고 기다리는 중이다. 읽기용으로 열면 서로 풀려난다.
    // 막히지 않게 열고, init이 1바이트를 쓸 때까지 확인하며 기다린다
    let fifo = state_dir(root, id)?.join("exec.fifo");
    let mut f = fs::OpenOptions::new().read(true).custom_flags(libc::O_NONBLOCK).open(&fifo)?;
    let mut buf = [0u8; 1];
    loop {
        match f.read(&mut buf) {
            Ok(1) => break,
            Ok(_) | Err(_) if status(root, &s) == "stopped" => bail!("{id}: init이 이미 끝났습니다"),
            _ => std::thread::sleep(Duration::from_millis(5)),
        }
    }
    fs::remove_file(&fifo)?;
    Ok(())
}

pub fn kill_cmd(root: &Path, id: &str, signal: &str) -> Result<()> {
    let s = load(root, id)?;
    if status(root, &s) == "stopped" {
        bail!("{id}: 실행 중이 아닙니다");
    }
    kill(Pid::from_raw(s.pid), parse_signal(signal)?)?;
    Ok(())
}

/// "15", "TERM", "SIGTERM" 을 모두 받는다
fn parse_signal(s: &str) -> Result<Signal> {
    if let Ok(n) = s.parse::<i32>() {
        return Ok(Signal::try_from(n)?);
    }
    let name = s.to_ascii_uppercase();
    let full = if name.starts_with("SIG") { name } else { format!("SIG{name}") };
    Ok(full.parse()?)
}

pub fn delete(root: &Path, id: &str, force: bool) -> Result<()> {
    let dir = state_dir(root, id)?;
    let s = match load(root, id) {
        Ok(s) => s,
        // runc처럼, 이미 없는 컨테이너를 --force로 지우는 것은 성공으로 친다
        Err(_) if force => return Ok(()),
        Err(e) => return Err(e),
    };
    match status(root, &s) {
        "stopped" => {}
        _ if force => {
            let _ = kill(Pid::from_raw(s.pid), Signal::SIGKILL);
            for _ in 0..500 {
                if status(root, &s) == "stopped" {
                    break;
                }
                std::thread::sleep(Duration::from_millis(10));
            }
        }
        other => bail!("{id}: {other} 상태라 지울 수 없습니다 (--force)"),
    }
    // 마지막 프로세스가 나간 직후에는 잠깐 EBUSY일 수 있다
    for i in 0..100 {
        match fs::remove_dir(&s.cgroup) {
            Ok(()) => break,
            Err(e) if e.kind() == std::io::ErrorKind::NotFound => break,
            Err(_) if i < 99 => std::thread::sleep(Duration::from_millis(10)),
            Err(e) => return Err(e).with_context(|| format!("cgroup 지우기 {}", s.cgroup.display())),
        }
    }
    fs::remove_dir_all(&dir)?;
    Ok(())
}

/// clone된 init에게 넘길 것. 할당이 필요한 일은 clone 전에 끝내 둔다
struct InitConfig {
    spec: Spec,
    rootfs: PathBuf,
    fifo: PathBuf,
    /// path가 있는 네임스페이스: 새로 만들지 않고 합류한다
    join: Vec<(PathBuf, CloneFlags)>,
    new_cgroup_ns: bool,
    argv: Vec<CString>,
    env: Vec<CString>,
    path: String,
    seccomp: Vec<BpfProgram>,
    /// 부모 → init: cgroup 배치가 끝났다
    sync: (RawFd, RawFd),
    /// init → 부모: 준비가 끝났다("ok") 또는 에러 메시지
    ready: (RawFd, RawFd),
}

pub fn create(root: &Path, id: &str, bundle: &Path, pid_file: Option<&Path>) -> Result<()> {
    let dir = state_dir(root, id)?;
    if dir.exists() {
        bail!("이미 있는 컨테이너입니다: {id}");
    }
    let bundle = fs::canonicalize(bundle).with_context(|| format!("bundle {}", bundle.display()))?;
    let spec: Spec = serde_json::from_slice(&fs::read(bundle.join("config.json"))?)
        .context("config.json 해석")?;
    if spec.process.terminal {
        bail!("터미널(process.terminal, docker run -t)은 지원하지 않습니다");
    }
    let rootfs = fs::canonicalize(bundle.join(&spec.root.path)).context("root.path")?;

    // 네임스페이스. path가 있으면 합류, 없으면 새로
    let mut flags = CloneFlags::empty();
    let mut join = Vec::new();
    let mut new_cgroup_ns = false;
    let mut new_time_ns = false;
    for ns in &spec.linux.namespaces {
        let flag = match ns.kind.as_str() {
            "pid" => CloneFlags::CLONE_NEWPID,
            "network" => CloneFlags::CLONE_NEWNET,
            "mount" => CloneFlags::CLONE_NEWNS,
            "uts" => CloneFlags::CLONE_NEWUTS,
            "ipc" => CloneFlags::CLONE_NEWIPC,
            "cgroup" => CloneFlags::CLONE_NEWCGROUP,
            "time" => CloneFlags::from_bits_retain(libc::CLONE_NEWTIME),
            other => bail!("지원하지 않는 네임스페이스: {other}"),
        };
        match (&ns.path, ns.kind.as_str()) {
            (Some(p), "network" | "ipc" | "uts") => join.push((p.clone(), flag)),
            (Some(_), other) => bail!("{other} 네임스페이스 합류(path)는 지원하지 않습니다"),
            (None, "cgroup") => new_cgroup_ns = true, // cgroup에 들어간 뒤 init이 직접 unshare
            (None, "time") => new_time_ns = true,     // clone 플래그로는 만들 수 없다
            (None, _) => flags |= flag,
        }
    }
    let seccomp = match &spec.linux.seccomp {
        Some(s) => compile_seccomp(s)?,
        None => Vec::new(),
    };
    let env = to_cstrings(&spec.process.env)?;
    let path = spec.process.env.iter().find_map(|e| e.strip_prefix("PATH=")).unwrap_or(DEFAULT_PATH).to_string();
    let argv = to_cstrings(&spec.process.args)?;
    if argv.is_empty() {
        bail!("process.args가 비어 있습니다");
    }

    fs::create_dir_all(&dir)?;
    let fifo = dir.join("exec.fifo");
    mkfifo(&fifo, Mode::from_bits_truncate(0o622)).context("exec.fifo")?;
    let cg = create_cgroup(&spec, id)?;

    let (sync_rd, sync_wr) = pipe2(OFlag::O_CLOEXEC)?;
    let (ready_rd, ready_wr) = pipe2(OFlag::O_CLOEXEC)?;
    let init = InitConfig {
        spec, rootfs: rootfs.clone(), fifo, join, new_cgroup_ns, argv, env, path, seccomp,
        sync: (sync_rd.as_raw_fd(), sync_wr.as_raw_fd()),
        ready: (ready_rd.as_raw_fd(), ready_wr.as_raw_fd()),
    };
    if new_time_ns {
        // PID 네임스페이스처럼, 호출자가 아니라 이후의 자식부터 새 time 네임스페이스에 들어간다
        unshare(CloneFlags::from_bits_retain(libc::CLONE_NEWTIME)).context("time 네임스페이스")?;
    }
    let mut stack = vec![0u8; STACK_SIZE];
    let cb = Box::new(|| container_init(&init));
    let child = unsafe { clone(cb, &mut stack, flags, Some(Signal::SIGCHLD as i32)) }.context("clone")?;
    drop(sync_rd);
    drop(ready_wr);

    let result = (|| -> Result<()> {
        fs::write(cg.join("cgroup.procs"), child.to_string()).context("cgroup 배치")?;
        write(&sync_wr, &[1])?;
        drop(sync_wr);
        // init이 마운트부터 seccomp까지 끝내고 "ok"를 보내거나, 에러 메시지를 보낸다
        let mut msg = String::new();
        File::from(ready_rd).read_to_string(&mut msg)?;
        if msg != "ok" {
            bail!("컨테이너 준비 실패: {}", if msg.is_empty() { "init이 응답 없이 끝났습니다" } else { &msg });
        }
        Ok(())
    })();
    if let Err(e) = result {
        let _ = kill(child, Signal::SIGKILL);
        let _ = waitpid(child, None);
        let _ = fs::remove_dir(&cg);
        let _ = fs::remove_dir_all(&dir);
        return Err(e);
    }

    let starttime = proc_stat(child.as_raw()).context("init의 /proc/<pid>/stat")?.1;
    let saved = Saved { id: id.to_string(), pid: child.as_raw(), starttime, bundle, rootfs, created: now_rfc3339(), cgroup: cg };
    fs::write(dir.join("state.json"), serde_json::to_vec(&saved)?)?;
    if let Some(p) = pid_file {
        fs::write(p, child.to_string())?;
    }
    // init을 기다리지 않고 끝낸다. init은 containerd-shim(서브리퍼)이 입양해 회수한다
    Ok(())
}

/// cgroupsPath (예: /docker/<id>)에 cgroup을 만들고 자원 제한을 쓴다
fn create_cgroup(spec: &Spec, id: &str) -> Result<PathBuf> {
    let rel = spec.linux.cgroups_path.clone().unwrap_or_else(|| format!("/myctr/{id}"));
    if rel.contains(':') {
        bail!("systemd 형식 cgroupsPath는 지원하지 않습니다: {rel}");
    }
    let root = Path::new("/sys/fs/cgroup");
    let path = root.join(rel.trim_start_matches('/'));
    // 위에서 아래로 컨트롤러를 켠다 (4장 규칙 ①). 켤 수 없는 것은 넘어간다
    let mut cur = root.to_path_buf();
    for part in path.strip_prefix(root)?.components() {
        let _ = fs::write(cur.join("cgroup.subtree_control"), "+memory +cpu +pids");
        cur.push(part);
        if !cur.exists() {
            fs::create_dir(&cur).with_context(|| format!("{} 만들기", cur.display()))?;
        }
    }
    let r = &spec.linux.resources;
    let set = |file: &str, v: String| {
        fs::write(path.join(file), &v).with_context(|| format!("{file} = {v}"))
    };
    if let Some(m) = &r.memory {
        if let Some(limit) = m.limit.filter(|l| *l > 0) {
            set("memory.max", limit.to_string())?;
            // OCI의 swap은 메모리 + 스왑 합계, cgroup v2의 memory.swap.max는 스왑만
            if let Some(swap) = m.swap.filter(|s| *s >= limit) {
                if path.join("memory.swap.max").exists() {
                    set("memory.swap.max", (swap - limit).to_string())?;
                }
            }
        }
    }
    if let Some(c) = &r.cpu {
        if let Some(q) = c.quota.filter(|q| *q > 0) {
            set("cpu.max", format!("{q} {}", c.period.unwrap_or(100_000)))?;
        }
    }
    if let Some(p) = r.pids.as_ref().filter(|p| p.limit > 0) {
        set("pids.max", p.limit.to_string())?;
    }
    Ok(path)
}

// ---------------------------------------------------------------- init (컨테이너 안)

fn container_init(c: &InitConfig) -> isize {
    let _ = close(c.sync.1);
    let _ = close(c.ready.0);
    let mut buf = [0u8; 1];
    loop {
        match read(c.sync.0, &mut buf) {
            Ok(1) => break,
            Err(Errno::EINTR) => continue,
            _ => return 1,
        }
    }
    let _ = close(c.sync.0);

    let fifo_fd = match init_setup(c) {
        Ok(fd) => fd,
        Err(e) => {
            write_raw(c.ready.1, format!("{e:#}").as_bytes());
            return 1;
        }
    };
    write_raw(c.ready.1, b"ok");
    let _ = close(c.ready.1);

    // start가 fifo를 열 때까지 여기서 잠든다. pivot_root 뒤라 원래 경로는 보이지 않으므로
    // 미리 열어 둔 O_PATH fd를 /proc/self/fd 로 다시 연다
    let path = format!("/proc/self/fd/{fifo_fd}");
    let Ok(fd) = open(path.as_str(), OFlag::O_WRONLY | OFlag::O_CLOEXEC, Mode::empty()) else { return 1 };
    write_raw(fd, b"0");
    let _ = close(fd);
    let _ = close(fifo_fd);

    let prog = find_in_path(&c.argv[0], &c.path);
    let err = execve(&prog, &c.argv, &c.env).unwrap_err();
    eprintln!("myctr: {}: {err}", c.argv[0].to_string_lossy());
    127
}

fn write_raw(fd: RawFd, data: &[u8]) {
    let _ = write(unsafe { std::os::fd::BorrowedFd::borrow_raw(fd) }, data);
}

/// create 단계의 init 준비. 성공하면 exec.fifo의 O_PATH fd를 돌려준다
fn init_setup(c: &InitConfig) -> Result<RawFd> {
    let spec = &c.spec;
    // 1. path로 지정된 네임스페이스에 합류 (예: 쿠버네티스 pause 컨테이너의 network)
    for (path, flag) in &c.join {
        let f = File::open(path).with_context(|| format!("{} 열기", path.display()))?;
        setns(&f, *flag).with_context(|| format!("{} 합류", path.display()))?;
    }
    // 2. 부모가 우리를 cgroup에 넣은 뒤이므로, 지금 만들면 그 cgroup이 네임스페이스의 루트가 된다
    if c.new_cgroup_ns {
        unshare(CloneFlags::CLONE_NEWCGROUP).context("cgroup 네임스페이스")?;
    }
    if let Some(h) = &spec.hostname {
        sethostname(h).context("sethostname")?;
    }

    // 3. 마운트: rootfs 안에 config의 mounts를 차례로
    mount(None::<&str>, "/", None::<&str>, MsFlags::MS_REC | MsFlags::MS_PRIVATE, None::<&str>)
        .context("/ 를 rprivate으로")?;
    mount(Some(&c.rootfs), &c.rootfs, None::<&str>, MsFlags::MS_BIND | MsFlags::MS_REC, None::<&str>)
        .context("rootfs bind")?;
    for m in &spec.mounts {
        do_mount(&c.rootfs, m).with_context(|| format!("마운트 {}", m.destination.display()))?;
    }
    default_devices(&c.rootfs)?;
    // exec.fifo는 pivot_root 뒤에는 보이지 않는다. 지금 O_PATH로 열어 둔다
    let fifo_fd = open(&c.fifo, OFlag::O_PATH | OFlag::O_CLOEXEC, Mode::empty()).context("exec.fifo")?;

    // 4. pivot_root(".", "."): 이전 루트를 걸어 둘 디렉터리 없이 루트를 바꾸는 runc의 방법
    chdir(&c.rootfs)?;
    pivot_root(".", ".").context("pivot_root")?;
    umount2(".", MntFlags::MNT_DETACH).context("이전 루트 분리")?;
    chdir("/")?;

    // 5. sysctl → 민감한 경로 가리기 → 읽기 전용 경로 (sysctl이 /proc/sys를 막기 전에)
    for (key, value) in &spec.linux.sysctl {
        let p = format!("/proc/sys/{}", key.replace('.', "/"));
        fs::write(&p, value).with_context(|| format!("sysctl {key}"))?;
    }
    for p in &spec.linux.masked_paths {
        mask_path(p).with_context(|| format!("maskedPath {}", p.display()))?;
    }
    for p in &spec.linux.readonly_paths {
        readonly_path(p).with_context(|| format!("readonlyPath {}", p.display()))?;
    }
    if spec.root.readonly {
        mount(None::<&str>, "/", None::<&str>, MsFlags::MS_REMOUNT | MsFlags::MS_BIND | MsFlags::MS_RDONLY, None::<&str>)
            .context("루트를 읽기 전용으로")?;
    }
    chdir(spec.process.cwd.as_str()).with_context(|| format!("cwd {}", spec.process.cwd))?;

    // 6. 프로세스 속성과 권한 (7장)
    for r in &spec.process.rlimits {
        set_rlimit(r)?;
    }
    apply_user_and_caps(&spec.process, &c.seccomp)?;
    Ok(fifo_fd)
}

/// rootfs 안의 경로로 바꾼다. 경로 중간의 심볼릭 링크는 rootfs 밖을 가리킬 수 있으므로 거부한다
fn inside(rootfs: &Path, dest: &Path) -> Result<PathBuf> {
    let mut p = rootfs.to_path_buf();
    for comp in dest.components() {
        match comp {
            Component::RootDir | Component::CurDir => {}
            Component::Normal(name) => {
                p.push(name);
                if fs::symlink_metadata(&p).is_ok_and(|m| m.file_type().is_symlink()) {
                    bail!("경로에 심볼릭 링크가 있습니다: {}", p.display());
                }
            }
            _ => bail!("허용하지 않는 경로: {}", dest.display()),
        }
    }
    Ok(p)
}

/// 마운트 옵션 문자열 → (플래그, 전파 플래그, 나머지 데이터)
fn parse_options(options: &[String]) -> (MsFlags, Option<MsFlags>, String) {
    let mut flags = MsFlags::empty();
    let mut propagation = None;
    let mut data = Vec::new();
    for o in options {
        match o.as_str() {
            "ro" => flags |= MsFlags::MS_RDONLY,
            "rw" => flags -= MsFlags::MS_RDONLY,
            "nosuid" => flags |= MsFlags::MS_NOSUID,
            "nodev" => flags |= MsFlags::MS_NODEV,
            "noexec" => flags |= MsFlags::MS_NOEXEC,
            "relatime" => flags |= MsFlags::MS_RELATIME,
            "strictatime" => flags |= MsFlags::MS_STRICTATIME,
            "noatime" => flags |= MsFlags::MS_NOATIME,
            "bind" => flags |= MsFlags::MS_BIND,
            "rbind" => flags |= MsFlags::MS_BIND | MsFlags::MS_REC,
            "private" => propagation = Some(MsFlags::MS_PRIVATE),
            "rprivate" => propagation = Some(MsFlags::MS_PRIVATE | MsFlags::MS_REC),
            "slave" => propagation = Some(MsFlags::MS_SLAVE),
            "rslave" => propagation = Some(MsFlags::MS_SLAVE | MsFlags::MS_REC),
            "shared" => propagation = Some(MsFlags::MS_SHARED),
            "rshared" => propagation = Some(MsFlags::MS_SHARED | MsFlags::MS_REC),
            other => data.push(other),
        }
    }
    (flags, propagation, data.join(","))
}

fn do_mount(rootfs: &Path, m: &Mount) -> Result<()> {
    let dest = inside(rootfs, &m.destination)?;
    let (flags, propagation, data) = parse_options(&m.options);
    let data = (!data.is_empty()).then_some(data.as_str());
    if m.kind == "bind" || flags.contains(MsFlags::MS_BIND) {
        // 파일을 bind하려면 대상도 파일이어야 한다
        if Path::new(&m.source).is_dir() {
            fs::create_dir_all(&dest)?;
        } else {
            fs::create_dir_all(dest.parent().unwrap())?;
            if !dest.exists() {
                File::create(&dest)?;
            }
        }
        let bind = flags & (MsFlags::MS_BIND | MsFlags::MS_REC);
        mount(Some(m.source.as_str()), &dest, None::<&str>, bind, None::<&str>)?;
        // bind는 처음 마운트할 때 ro 같은 플래그를 무시한다. 다시 마운트해서 건다
        let rest = flags - (MsFlags::MS_BIND | MsFlags::MS_REC);
        if !rest.is_empty() {
            mount(None::<&str>, &dest, None::<&str>, MsFlags::MS_REMOUNT | MsFlags::MS_BIND | rest, None::<&str>)?;
        }
    } else {
        fs::create_dir_all(&dest)?;
        // 이 코스는 cgroup v2만 다룬다
        let fstype = if m.kind == "cgroup" { "cgroup2" } else { m.kind.as_str() };
        mount(Some(m.source.as_str()), &dest, Some(fstype), flags, data)?;
    }
    if let Some(p) = propagation {
        mount(None::<&str>, &dest, None::<&str>, p, None::<&str>)?;
    }
    Ok(())
}

/// 3장처럼 호스트의 장치 파일을 빌려 온다 (아직 pivot_root 전이라 /dev는 호스트의 것)
fn default_devices(rootfs: &Path) -> Result<()> {
    let dev = inside(rootfs, Path::new("/dev"))?;
    for name in DEVICES {
        let target = dev.join(name);
        if !target.exists() {
            File::create(&target)?;
        }
        let source = format!("/dev/{name}");
        mount(Some(source.as_str()), &target, None::<&str>, MsFlags::MS_BIND, None::<&str>)
            .with_context(|| format!("{source} bind"))?;
    }
    for (link, to) in [
        ("fd", "/proc/self/fd"),
        ("stdin", "/proc/self/fd/0"),
        ("stdout", "/proc/self/fd/1"),
        ("stderr", "/proc/self/fd/2"),
        ("ptmx", "pts/ptmx"),
    ] {
        let _ = symlink(to, dev.join(link));
    }
    Ok(())
}

fn mask_path(p: &Path) -> Result<()> {
    let Ok(meta) = fs::metadata(p) else { return Ok(()) }; // 없으면 가릴 것도 없다
    if meta.is_dir() {
        mount(Some("tmpfs"), p, Some("tmpfs"), MsFlags::MS_RDONLY, None::<&str>)?;
    } else {
        mount(Some("/dev/null"), p, None::<&str>, MsFlags::MS_BIND, None::<&str>)?;
    }
    Ok(())
}

fn readonly_path(p: &Path) -> Result<()> {
    if !p.exists() {
        return Ok(());
    }
    mount(Some(p), p, None::<&str>, MsFlags::MS_BIND | MsFlags::MS_REC, None::<&str>)?;
    mount(None::<&str>, p, None::<&str>, MsFlags::MS_REMOUNT | MsFlags::MS_BIND | MsFlags::MS_RDONLY | MsFlags::MS_REC, None::<&str>)?;
    Ok(())
}

fn set_rlimit(r: &Rlimit) -> Result<()> {
    let resource = match r.kind.as_str() {
        "RLIMIT_NOFILE" => libc::RLIMIT_NOFILE,
        "RLIMIT_NPROC" => libc::RLIMIT_NPROC,
        "RLIMIT_CORE" => libc::RLIMIT_CORE,
        "RLIMIT_STACK" => libc::RLIMIT_STACK,
        "RLIMIT_AS" => libc::RLIMIT_AS,
        "RLIMIT_MEMLOCK" => libc::RLIMIT_MEMLOCK,
        other => bail!("지원하지 않는 rlimit: {other}"),
    };
    let lim = libc::rlimit { rlim_cur: r.soft, rlim_max: r.hard };
    if unsafe { libc::setrlimit(resource, &lim) } != 0 {
        return Err(std::io::Error::last_os_error()).context(r.kind.clone());
    }
    Ok(())
}

/// 7장의 lock_down을 config.json 기준으로. 사용자 전환이 끼어든다
fn apply_user_and_caps(p: &Process, seccomp: &[BpfProgram]) -> Result<()> {
    let caps = p.capabilities.as_ref();
    let set = |names: Option<&Vec<String>>| -> Result<CapsHashSet> {
        names.map(|v| v.iter().map(|n| parse_cap(n)).collect()).unwrap_or(Ok(CapsHashSet::new()))
    };
    let bounding = set(caps.map(|c| &c.bounding))?;
    let effective = set(caps.map(|c| &c.effective))?;
    let permitted = set(caps.map(|c| &c.permitted))?;
    for cap in caps::runtime::thread_all_supported() {
        if !bounding.contains(&cap) {
            caps::drop(None, CapSet::Bounding, cap)?;
        }
    }
    caps::clear(None, CapSet::Inheritable)?;
    caps::clear(None, CapSet::Ambient)?;
    // UID가 0이 아니게 바뀌면 커널이 capability를 비운다. keepcaps로 permitted를 지킨다
    prctl::set_keepcaps(true)?;
    let gids: Vec<Gid> = p.user.additional_gids.iter().map(|g| Gid::from_raw(*g)).collect();
    setgroups(&gids).context("setgroups")?;
    setgid(Gid::from_raw(p.user.gid)).context("setgid")?;
    setuid(Uid::from_raw(p.user.uid)).context("setuid")?;
    prctl::set_keepcaps(false)?;
    caps::set(None, CapSet::Effective, &effective).context("effective")?;
    caps::set(None, CapSet::Permitted, &permitted).context("permitted")?;
    // seccompiler::apply_filter는 설치 전에 스스로 no_new_privs를 켠다 (7장 5절).
    // 그래서 seccomp가 있으면 myctr는 config의 noNewPrivileges와 상관없이 켜진다
    for bpf in seccomp {
        seccompiler::apply_filter(bpf).context("seccomp 설치")?;
    }
    Ok(())
}

/// OCI seccomp 프로파일 → seccompiler 필터들.
/// 허용 규칙은 하나의 허용 목록 필터로, errno 규칙은 errno 값마다 필터 하나로 만든다.
/// 같은 우선순위의 판정이 겹치면 커널은 나중에 설치한 필터의 값을 쓰므로 errno 필터를 뒤에 둔다
fn compile_seccomp(s: &Seccomp) -> Result<Vec<BpfProgram>> {
    let arch: TargetArch = std::env::consts::ARCH.try_into()?;
    let default = action_json(&s.default_action, s.default_errno_ret)?;
    let mut allow = Vec::new();
    let mut errno: BTreeMap<u32, Vec<Value>> = BTreeMap::new();
    for rule in &s.syscalls {
        let args: Vec<Value> = rule.args.iter().map(arg_json).collect::<Result<_>>()?;
        for name in &rule.names {
            // 이 아키텍처에 없는 이름(예: aarch64의 chown32)은 건너뛴다
            if !syscall_exists(name, arch.clone()) {
                continue;
            }
            let r = if args.is_empty() { json!({ "syscall": name }) } else { json!({ "syscall": name, "args": args }) };
            match action_json(&rule.action, rule.errno_ret)? {
                Value::String(a) if a == "allow" => allow.push(r),
                Value::Object(o) if o.contains_key("errno") => {
                    errno.entry(o["errno"].as_u64().unwrap() as u32).or_default().push(r)
                }
                _ => bail!("지원하지 않는 seccomp action: {}", rule.action),
            }
        }
    }
    let mut filters = json!({ "allow": { "mismatch_action": default, "match_action": "allow", "filter": allow } });
    let mut order = vec!["allow".to_string()];
    for (n, rules) in errno {
        let name = format!("errno_{n}");
        filters[&name] = json!({ "mismatch_action": "allow", "match_action": { "errno": n }, "filter": rules });
        order.push(name);
    }
    let mut map = seccompiler::compile_from_json(filters.to_string().as_bytes(), arch).context("seccomp 컴파일")?;
    Ok(order.iter().map(|n| map.remove(n).unwrap()).collect())
}

/// 이름 하나짜리 필터를 컴파일해 본다. seccompiler는 두 action이 같은 필터를 거부하므로 서로 다르게 준다
fn syscall_exists(name: &str, arch: TargetArch) -> bool {
    let probe = json!({ "p": { "mismatch_action": "allow", "match_action": { "errno": 1 }, "filter": [{ "syscall": name }] } });
    seccompiler::compile_from_json(probe.to_string().as_bytes(), arch).is_ok()
}

fn action_json(action: &str, errno_ret: Option<u32>) -> Result<Value> {
    Ok(match action {
        "SCMP_ACT_ALLOW" => json!("allow"),
        "SCMP_ACT_ERRNO" => json!({ "errno": errno_ret.unwrap_or(libc::EPERM as u32) }),
        "SCMP_ACT_KILL" | "SCMP_ACT_KILL_THREAD" => json!("kill_thread"),
        "SCMP_ACT_KILL_PROCESS" => json!("kill_process"),
        "SCMP_ACT_LOG" => json!("log"),
        other => bail!("지원하지 않는 seccomp action: {other}"),
    })
}

/// OCI의 MASKED_EQ는 value가 마스크, valueTwo가 기대값이다
fn arg_json(a: &SeccompArg) -> Result<Value> {
    let (op, val) = match a.op.as_str() {
        "SCMP_CMP_EQ" => (json!("eq"), a.value),
        "SCMP_CMP_NE" => (json!("ne"), a.value),
        "SCMP_CMP_LT" => (json!("lt"), a.value),
        "SCMP_CMP_LE" => (json!("le"), a.value),
        "SCMP_CMP_GT" => (json!("gt"), a.value),
        "SCMP_CMP_GE" => (json!("ge"), a.value),
        "SCMP_CMP_MASKED_EQ" => (json!({ "masked_eq": a.value }), a.value_two),
        other => bail!("지원하지 않는 seccomp 비교: {other}"),
    };
    Ok(json!({ "index": a.index, "type": "qword", "op": op, "val": val }))
}

/// 지금 시각을 RFC 3339 (UTC)로. 날짜 계산은 "days from civil"의 역변환
fn now_rfc3339() -> String {
    let secs = SystemTime::now().duration_since(UNIX_EPOCH).map(|d| d.as_secs()).unwrap_or(0) as i64;
    let (days, rem) = (secs.div_euclid(86_400), secs.rem_euclid(86_400));
    let z = days + 719_468;
    let era = z.div_euclid(146_097);
    let doe = z - era * 146_097;
    let yoe = (doe - doe / 1460 + doe / 36_524 - doe / 146_096) / 365;
    let doy = doe - (365 * yoe + yoe / 4 - yoe / 100);
    let mp = (5 * doy + 2) / 153;
    let d = doy - (153 * mp + 2) / 5 + 1;
    let m = if mp < 10 { mp + 3 } else { mp - 9 };
    let y = yoe + era * 400 + i64::from(m <= 2);
    format!("{y:04}-{m:02}-{d:02}T{:02}:{:02}:{:02}Z", rem / 3600, rem % 3600 / 60, rem % 60)
}

    /// 명령을 새 네임스페이스와 cgroup 안에서 실행한다
    Run {
        /// 컨테이너 안에서 보일 hostname
        #[arg(long, default_value = "myctr")]
        hostname: String,
        /// PID 1에 작은 init을 두고 명령은 PID 2로 실행한다
        #[arg(long)]
        init: bool,
        /// 메모리 상한 (예: 64M, 1G, 바이트 수)
        #[arg(long, value_parser = parse_bytes)]
        memory: Option<u64>,
        /// CPU 상한 (코어 수, 예: 0.5)
        #[arg(long)]
        cpus: Option<f64>,
        /// 최대 프로세스(스레드) 수
        #[arg(long)]
        pids: Option<u64>,
        /// (root 전용) 컨테이너의 UID/GID 0..65535 를 이 호스트 ID부터 매핑한다
        #[arg(long)]
        userns_base: Option<u32>,
        /// 네트워크 모드
        #[arg(long, value_enum, default_value = "none")]
        net: Net,
        /// 기본 capability에 더한다 (예: NET_ADMIN)
        #[arg(long = "cap-add", value_name = "CAP")]
        cap_add: Vec<String>,
        /// 기본 capability에서 뺀다 (ALL이면 전부)
        #[arg(long = "cap-drop", value_name = "CAP")]
        cap_drop: Vec<String>,
        /// seccomp 필터를 설치하지 않는다
        #[arg(long)]
        no_seccomp: bool,
        /// 이 디렉터리를 루트로 쓴다 (3장)
        #[arg(long, conflicts_with = "image")]
        rootfs: Option<PathBuf>,
        /// 이 이미지를 overlayfs로 쌓아 루트로 쓴다. 없으면 받아 온다
        #[arg(long)]
        image: Option<String>,
        /// 실행할 프로그램과 인자 (--image면 생략 시 이미지의 Cmd)
        #[arg(trailing_var_arg = true, allow_hyphen_values = true)]
        cmd: Vec<String>,
    },
}

struct Limits {
    memory: Option<u64>,
    cpus: Option<f64>,
    pids: Option<u64>,
}

impl Limits {
    fn any(&self) -> bool {
        self.memory.is_some() || self.cpus.is_some() || self.pids.is_some()
    }
}

/// 컨테이너의 루트를 어디서 가져오나
enum RootSpec {
    /// 호스트 파일시스템 그대로 (4~7장)
    Host,
    /// 디렉터리 하나 (3장)
    Dir(PathBuf),
    /// 이미지 레이어를 overlayfs로 쌓는다 (아래 → 위 순서)
    Image(Vec<PathBuf>),
}

/// 무엇을 실행하나
struct Program {
    argv: Vec<CString>,
    /// 이미지의 환경 변수. None이면 호스트 환경을 물려받는다
    env: Option<Vec<CString>>,
    /// 프로그램을 찾을 PATH (이미지 기준)
    path: String,
    workdir: String,
}

/// 자식이 새 루트를 꾸밀 때 쓰는 정보
struct RootSetup {
    /// pivot_root할 디렉터리 (Dir이면 그 디렉터리, Image면 merged)
    target: PathBuf,
    /// Image일 때 overlayfs 마운트 옵션
    overlay: Option<String>,
    /// 새 루트에 써 넣을 파일 (pivot_root 뒤, 컨테이너 경로 기준)
    files: Vec<(PathBuf, String)>,
}

/// clone된 자식에게 넘길 설정
struct Config {
    hostname: String,
    init: bool,
    program: Program,
    root: Option<RootSetup>,
    /// 부모가 준비를 마쳤다고 알려 주는 파이프 (읽는 쪽, 쓰는 쪽)
    sync: (RawFd, RawFd),
    userns: bool,
    clear_groups: bool,
    security: Security,
}

/// exec 직전에 적용할 권한 제한. 할당이 필요한 일은 clone 전에 끝내 둔다
struct Security {
    caps: CapsHashSet,
    seccomp: Option<BpfProgram>,
}

fn main() {
    let cli = Cli::parse();
    if let Err(e) = dispatch(&cli) {
        let msg = format!("{e:#}");
        if let Some(log) = &cli.log {
            oci::log_error(log, cli.log_format == "json", &msg);
        }
        eprintln!("myctr: {msg}");
        std::process::exit(1);
    }
}

fn dispatch(cli: &Cli) -> Result<()> {
    if cli.systemd_cgroup {
        bail!("--systemd-cgroup은 지원하지 않습니다 (Docker의 cgroup 드라이버를 cgroupfs로)");
    }
    let root = cli.root.as_path();
    match &cli.command {
        Command::Spec { rootfs } => oci::spec(rootfs)?,
        Command::Create { bundle, pid_file, console_socket, id } => {
            if console_socket.is_some() {
                bail!("--console-socket(터미널)은 지원하지 않습니다");
            }
            oci::create(root, id, bundle, pid_file.as_deref())?
        }
        Command::Start { id } => oci::start(root, id)?,
        Command::State { id } => oci::state(root, id)?,
        Command::Kill { id, signal, .. } => oci::kill_cmd(root, id, signal)?,
        Command::Delete { force, id } => oci::delete(root, id, *force)?,
        Command::Features => oci::features()?,
        Command::Exec { .. } => bail!("exec(docker exec)는 지원하지 않습니다"),
        Command::Pull { image } => {
            image::pull(image)?;
        }
        Command::Images => image::list()?,
        Command::Run {
            hostname, init, memory, cpus, pids, userns_base, net, cap_add, cap_drop, no_seccomp,
            rootfs, image, cmd,
        } => {
            let security = Security::new(cap_add, cap_drop, *no_seccomp)?;
            let (root, program) = prepare_root(rootfs.clone(), image.clone(), cmd.clone(), hostname)?;
            let limits = Limits { memory: *memory, cpus: *cpus, pids: *pids };
            let code = run(hostname.clone(), *init, root, program, &limits, *userns_base, *net, security)?;
            std::process::exit(code);
        }
    }
    Ok(())
}

fn to_cstrings(words: &[String]) -> Result<Vec<CString>> {
    words
        .iter()
        .map(|s| CString::new(s.as_bytes()))
        .collect::<Result<_, _>>()
        .context("인자에 NUL 바이트가 있습니다")
}

/// 루트와 실행할 프로그램을 정한다. 이미지면 Entrypoint + (명령 또는 Cmd), Env, WorkingDir
fn prepare_root(
    rootfs: Option<PathBuf>,
    image: Option<String>,
    cmd: Vec<String>,
    hostname: &str,
) -> Result<(RootSpec, Program)> {
    let Some(name) = image else {
        if cmd.is_empty() {
            bail!("실행할 명령이 없습니다");
        }
        let root = match rootfs {
            // 자식은 cwd가 바뀌기 전에 경로를 해석해야 하므로 절대 경로로 만든다
            Some(dir) => RootSpec::Dir(
                fs::canonicalize(&dir)
                    .with_context(|| format!("rootfs를 찾을 수 없습니다: {}", dir.display()))?,
            ),
            None => RootSpec::Host,
        };
        let program = Program { argv: to_cstrings(&cmd)?, env: None, path: String::new(), workdir: "/".into() };
        return Ok((root, program));
    };
    let img = image::ensure(&name)?;
    let c = img.config;
    let mut words = c.entrypoint.unwrap_or_default();
    words.extend(if cmd.is_empty() { c.cmd.unwrap_or_default() } else { cmd });
    if words.is_empty() {
        bail!("{name}: 이미지에 Cmd가 없으니 실행할 명령을 주세요");
    }
    // Docker처럼 HOSTNAME과 HOME을 더한다 (이미지에 없을 때만)
    let mut env = c.env;
    for (k, v) in [("HOSTNAME", hostname), ("HOME", "/root")] {
        if !env.iter().any(|e| e.starts_with(&format!("{k}="))) {
            env.push(format!("{k}={v}"));
        }
    }
    let path = env.iter().find_map(|e| e.strip_prefix("PATH=")).unwrap_or(DEFAULT_PATH).to_string();
    let workdir = if c.working_dir.is_empty() { "/".to_string() } else { c.working_dir };
    let program = Program { argv: to_cstrings(&words)?, env: Some(to_cstrings(&env)?), path, workdir };
    Ok((RootSpec::Image(img.layers), program))
}

/// "64M", "1G", "512K", "1048576" 을 바이트 수로
fn parse_bytes(s: &str) -> Result<u64, String> {
    let (num, mul) = match s.chars().last() {
        Some('K' | 'k') => (&s[..s.len() - 1], 1 << 10),
        Some('M' | 'm') => (&s[..s.len() - 1], 1 << 20),
        Some('G' | 'g') => (&s[..s.len() - 1], 1 << 30),
        _ => (s, 1),
    };
    num.parse::<u64>().map(|n| n * mul).map_err(|e| format!("{s}: {e}"))
}

fn run(
    hostname: String,
    init: bool,
    root: RootSpec,
    program: Program,
    limits: &Limits,
    userns_base: Option<u32>,
    net: Net,
    security: Security,
) -> Result<i32> {
    let rootless = !Uid::effective().is_root();
    let idmap = match (rootless, userns_base) {
        (true, Some(_)) => bail!("--userns-base는 root로 실행할 때만 쓸 수 있습니다"),
        (true, None) => Some(IdMap::rootless()),
        (false, Some(base)) => {
            if base.checked_add(USERNS_RANGE - 1).is_none_or(|last| last == u32::MAX) {
                bail!("--userns-base는 0..4294901759 범위여야 합니다 (65536개 ID, UID/GID -1 제외)");
            }
            Some(IdMap::range(base))
        },
        (false, None) => None,
    };
    if rootless && net == Net::Bridge {
        // veth·브리지·iptables는 호스트(최상위) 네트워크 네임스페이스를 바꾸는 일이다
        bail!("--net bridge는 root로 실행할 때만 쓸 수 있습니다");
    }
    if rootless && !matches!(root, RootSpec::Host) {
        bail!("--rootfs/--image는 root로 실행할 때만 쓸 수 있습니다");
    }
    let id = std::process::id();
    // 이미지면 컨테이너 전용 overlay 작업 공간. 끝나면 지운다 (docker run --rm 처럼)
    let workspace = match &root {
        RootSpec::Image(_) => Some(Workspace::create(id)?),
        _ => None,
    };
    let root_setup = match &root {
        RootSpec::Host => None,
        RootSpec::Dir(dir) => Some(RootSetup { target: dir.clone(), overlay: None, files: vec![] }),
        RootSpec::Image(layers) => {
            let ws = workspace.as_ref().unwrap();
            Some(RootSetup {
                target: ws.merged(),
                overlay: Some(ws.overlay_options(layers)),
                files: etc_files(&hostname, net)?,
            })
        }
    };
    let cgroup = if rootless {
        if limits.any() {
            bail!("rootless 모드에서는 --memory/--cpus/--pids를 쓸 수 없습니다 (cgroup 위임이 필요합니다)");
        }
        None
    } else {
        Some(Cgroup::create(&format!("ctr-{id}"), limits)?)
    };

    // O_CLOEXEC: 사용자 프로그램으로 새지 않게
    let (sync_rd, sync_wr) = pipe2(OFlag::O_CLOEXEC).context("pipe")?;
    let cfg = Config {
        hostname, init, program,
        root: root_setup,
        sync: (sync_rd.as_raw_fd(), sync_wr.as_raw_fd()),
        userns: idmap.is_some(),
        // 특권 range 모드에서는 상속한 호스트 보조 그룹을 남기지 않는다.
        // rootless는 setgroups=deny이므로 변경할 수 없다.
        clear_groups: idmap.as_ref().is_some_and(|map| !map.deny_setgroups),
        security,
    };

    let mut flags = CloneFlags::CLONE_NEWUTS | CloneFlags::CLONE_NEWPID;
    if idmap.is_some() {
        flags |= CloneFlags::CLONE_NEWUSER;
    }
    if net != Net::Host {
        flags |= CloneFlags::CLONE_NEWNET;
    }
    if cfg.root.is_some() {
        flags |= CloneFlags::CLONE_NEWNS;
    }
    let mut stack = vec![0u8; STACK_SIZE];
    let cb = Box::new(|| container_main(&cfg));
    let child = unsafe { clone(cb, &mut stack, flags, Some(Signal::SIGCHLD as i32)) }
        .context("clone 실패")?;
    drop(sync_rd);

    // 준비 실패 시 먼저 파이프를 닫는다. 자식은 EOF를 받고 종료하며,
    // 부모는 반드시 wait로 회수한 뒤 cgroup을 정리한다.
    let prepared = (|| -> Result<()> {
        if let Some(cg) = &cgroup {
            cg.add(child)?;
        }
        if let Some(map) = &idmap {
            map.write(child)?;
        }
        // 매핑까지 끝난 뒤에 네트워크. 자식은 아직 파이프에서 기다린다
        let ns = NetnsEnter { child, via_userns: rootless };
        match net {
            Net::Host => {}
            Net::None => ns.run(&["ip", "link", "set", "lo", "up"])?,
            Net::Bridge => setup_bridge_net(&ns, id)?,
        }
        unsafe { signal(Signal::SIGINT, SigHandler::SigIgn) }
            .context("signal 설정 실패")?;
        write(&sync_wr, &[1]).context("자식 깨우기")?;
        Ok(())
    })();
    drop(sync_wr);
    if let Err(error) = prepared {
        // EOF로 종료한 PID 1을 회수하기 전에 Cgroup::drop이 실행되면
        // cgroup.procs가 비어 있지 않아 정리가 실패할 수 있다.
        wait_exit_code(child).context("준비 실패한 자식 회수")?;
        return Err(error);
    }
    let code = wait_exit_code(child)?;
    if cgroup.as_ref().is_some_and(|cg| cg.oom_kills() > 0) {
        eprintln!("myctr: 메모리 상한을 넘어 OOM killer가 프로세스를 종료했습니다");
    }
    // overlay 마운트는 자식의 마운트 네임스페이스에만 있었으므로 이미 사라졌다.
    // 여기서 cgroup과 작업 공간(upper, work)이 drop되며 지워진다
    Ok(code)
}

/// 컨테이너 하나의 overlay 작업 공간: upper(쓰기), work(overlayfs 내부용), merged(마운트 지점)
struct Workspace {
    dir: PathBuf,
}

impl Workspace {
    fn create(id: u32) -> Result<Self> {
        let dir = Path::new(image::STORE).join("containers").join(format!("ctr-{id}"));
        for sub in ["upper", "work", "merged"] {
            fs::create_dir_all(dir.join(sub)).with_context(|| format!("{} 만들기", dir.display()))?;
        }
        Ok(Workspace { dir })
    }

    fn merged(&self) -> PathBuf {
        self.dir.join("merged")
    }

    /// lowerdir는 위 레이어가 앞에 온다
    fn overlay_options(&self, layers: &[PathBuf]) -> String {
        let lower: Vec<_> = layers.iter().rev().map(|p| p.display().to_string()).collect();
        format!(
            "lowerdir={},upperdir={},workdir={}",
            lower.join(":"),
            self.dir.join("upper").display(),
            self.dir.join("work").display()
        )
    }
}

impl Drop for Workspace {
    fn drop(&mut self) {
        if let Err(e) = fs::remove_dir_all(&self.dir) {
            eprintln!("myctr: 작업 공간 정리 실패 {}: {e}", self.dir.display());
        }
    }
}

/// 이미지 루트에 써 넣을 /etc 파일. overlay의 upper에 기록되므로 이미지는 바뀌지 않는다
fn etc_files(hostname: &str, net: Net) -> Result<Vec<(PathBuf, String)>> {
    Ok(vec![
        ("/etc/hostname".into(), format!("{hostname}\n")),
        ("/etc/hosts".into(), format!("127.0.0.1\tlocalhost\n::1\tlocalhost\n127.0.1.1\t{hostname}\n")),
        ("/etc/resolv.conf".into(), resolv_conf(net)),
    ])
}

/// 호스트의 resolv.conf. 단, 127.0.0.53 같은 loopback 주소는 컨테이너의 네트워크
/// 네임스페이스에서 닿지 않으므로 systemd-resolved의 실제 상위 서버 목록으로 바꾼다 (Docker와 같은 방식)
fn resolv_conf(net: Net) -> String {
    let loopback = |s: &str| s.lines().any(|l| l.trim_start().starts_with("nameserver 127."));
    let host = fs::read_to_string("/etc/resolv.conf").unwrap_or_default();
    if net == Net::Host || !loopback(&host) {
        return host;
    }
    match fs::read_to_string("/run/systemd/resolve/resolv.conf") {
        Ok(upstream) if !loopback(&upstream) => upstream,
        _ => "nameserver 8.8.8.8\nnameserver 8.8.4.4\n".into(),
    }
}

fn wait_exit_code(child: Pid) -> Result<i32> {
    loop {
        match waitpid(child, None) {
            Ok(WaitStatus::Exited(_, code)) => return Ok(code),
            Ok(WaitStatus::Signaled(_, sig, _)) => return Ok(128 + sig as i32),
            Ok(other) => bail!("예상하지 못한 상태: {other:?}"),
            Err(Errno::EINTR) => continue,
            Err(error) => return Err(error).context("waitpid 실패"),
        }
    }
}

/// 외부 명령을 실행하고 실패하면 stderr를 에러에 담는다
fn sh(args: &[&str]) -> Result<()> {
    let out = Cmd::new(args[0])
        .args(&args[1..])
        .output()
        .with_context(|| format!("{} 실행", args[0]))?;
    if !out.status.success() {
        bail!("{}: {}", args.join(" "), String::from_utf8_lossy(&out.stderr).trim());
    }
    Ok(())
}

/// 성공 여부만 본다 (규칙이 이미 있는지 확인할 때)
fn sh_ok(args: &[&str]) -> bool {
    Cmd::new(args[0]).args(&args[1..]).output().is_ok_and(|o| o.status.success())
}

/// 자식의 네트워크 네임스페이스 안에서 명령을 실행하는 방법
struct NetnsEnter {
    child: Pid,
    /// rootless: 호스트에서 권한이 없으므로 자식의 user 네임스페이스를 거쳐 들어간다
    via_userns: bool,
}

impl NetnsEnter {
    fn run(&self, args: &[&str]) -> Result<()> {
        let target = self.child.to_string();
        let mut full = vec!["nsenter", "-t", target.as_str()];
        if self.via_userns {
            // 5장의 setgroups=deny 때문에 nsenter가 자격 증명을 바꾸지 않게 한다
            full.extend_from_slice(&["-U", "--preserve-credentials"]);
        }
        full.push("-n");
        full.extend_from_slice(args);
        sh(&full)
    }
}

/// 브리지, 포워딩, NAT. 모든 컨테이너가 공유하므로 없을 때만 만든다
fn ensure_bridge() -> Result<()> {
    if !sh_ok(&["ip", "link", "show", BRIDGE]) {
        sh(&["ip", "link", "add", BRIDGE, "type", "bridge"])?;
        sh(&["ip", "addr", "add", &format!("{GATEWAY}/24"), "dev", BRIDGE])?;
    }
    sh(&["ip", "link", "set", BRIDGE, "up"])?;
    fs::write("/proc/sys/net/ipv4/ip_forward", "1").context("ip_forward 켜기")?;
    let rules: [&[&str]; 3] = [
        &["-t", "nat", "POSTROUTING", "-s", SUBNET, "!", "-o", BRIDGE, "-j", "MASQUERADE"],
        &["-t", "filter", "FORWARD", "-i", BRIDGE, "-j", "ACCEPT"],
        &["-t", "filter", "FORWARD", "-o", BRIDGE, "-m", "conntrack", "--ctstate", "RELATED,ESTABLISHED", "-j", "ACCEPT"],
    ];
    for rule in rules {
        // iptables -t <표> -C <체인> ... 로 있는지 보고, 없으면 -A
        let (table, rest) = rule.split_at(2);
        let mut check = vec!["iptables"];
        check.extend_from_slice(table);
        check.push("-C");
        check.extend_from_slice(rest);
        if !sh_ok(&check) {
            check[3] = "-A";
            sh(&check)?;
        }
    }
    Ok(())
}

fn setup_bridge_net(ns: &NetnsEnter, id: u32) -> Result<()> {
    ensure_bridge()?;
    // 인터페이스 이름은 15자 제한. 컨테이너 쪽은 옮긴 뒤 eth0으로 바꾼다
    let host_if = format!("veth{id}");
    let peer_if = format!("ceth{id}");
    // 간단한 주소 배정: 10.88.0.2 ~ 10.88.0.254
    let ip = format!("10.88.0.{}/24", 2 + id % 253);

    sh(&["ip", "link", "add", &host_if, "type", "veth", "peer", "name", &peer_if])?;
    sh(&["ip", "link", "set", &host_if, "master", BRIDGE, "up"])?;
    sh(&["ip", "link", "set", &peer_if, "netns", &ns.child.to_string()])?;

impl Cgroup {
    fn create(name: &str, limits: &Limits) -> Result<Self> {

            cg.write("memory.max", &bytes.to_string())?;

            if cg.path.join("memory.swap.max").exists() {
                cg.write("memory.swap.max", "0")?;
            }

            let quota = (cpus * CPU_PERIOD_US as f64) as u64;
            cg.write("cpu.max", &format!("{quota} {CPU_PERIOD_US}"))?;
        }
        if let Some(n) = limits.pids {
            cg.write("pids.max", &n.to_string())?;
        }
        Ok(cg)
    }

    fn write(&self, file: &str, value: &str) -> Result<()> {
        fs::write(self.path.join(file), value)
            .with_context(|| format!("{}/{file} 에 {value} 쓰기", self.path.display()))
    }

        self.write("cgroup.procs", &pid.to_string())

    }

/// clone된 자식. 새 네임스페이스 안의 PID 1이다.
fn container_main(cfg: &Config) -> isize {
    // 부모가 cgroup, ID 매핑, 네트워크를 끝낼 때까지 기다린다.
    // 쓰는 쪽을 닫아 두어야 부모가 죽었을 때 read가 EOF(0)로 깨어난다
    let _ = close(cfg.sync.1);
    let mut buf = [0u8; 1];
    loop {
        match read(cfg.sync.0, &mut buf) {
            Ok(1) => break,
            Err(Errno::EINTR) => continue,
            _ => {
                eprintln!("myctr: 부모가 준비를 마치지 못했습니다");
                return 1;
            }
        }
    }
    let _ = close(cfg.sync.0);

    if let Err(e) = setup(cfg) {
        eprintln!("myctr: {e:#}");
        return 1;
    }
    if cfg.init { mini_init(&cfg.program) } else { exec(&cfg.program) }
}

/// fork와 exec 사이에서 컨테이너의 모양을 만든다
fn setup(cfg: &Config) -> Result<()> {
    if cfg.userns {
        // 매핑은 ID의 대응표만 만든다. 특히 range 모드에서 host UID 0은
        // 매핑 밖이므로, 새 namespace의 ID 0으로 자격 증명을 옮긴다.
        if cfg.clear_groups {
            setgroups(&[]).context("보조 그룹 비우기")?;
        }
        setgid(Gid::from_raw(0)).context("컨테이너 GID 0으로 전환")?;
        setuid(Uid::from_raw(0)).context("컨테이너 UID 0으로 전환")?;
    }
    sethostname(&cfg.hostname).context("sethostname")?;
    if let Some(root) = &cfg.root {
        setup_root(root)?;
    }
    chdir(cfg.program.workdir.as_str())
        .with_context(|| format!("작업 디렉터리 {}", cfg.program.workdir))?;
    // 위의 일들은 권한이 필요하다. 다 끝났으니 마지막으로 권한을 내려놓는다
    lock_down(&cfg.security)
}

/// 새 루트로 갈아탄다 (3장의 순서에 overlay 마운트와 /etc 파일 쓰기를 더한 것)
fn setup_root(root: &RootSetup) -> Result<()> {
    // 1. 이후의 마운트가 호스트로 전파되지 않도록 모든 마운트를 private으로
    mount(None::<&str>, "/", None::<&str>, MsFlags::MS_REC | MsFlags::MS_PRIVATE, None::<&str>)
        .context("/ 를 rprivate으로 바꾸기")?;

    // 2. 이미지: 레이어 위에 컨테이너 전용 upper를 얹어 merged에 마운트
    if let Some(opts) = &root.overlay {
        mount(Some("overlay"), &root.target, Some("overlay"), MsFlags::empty(), Some(opts.as_str()))
            .context("overlayfs 마운트")?;
    }

    // 3. pivot_root의 new_root는 마운트 지점이어야 하므로 자기 자신에게 bind
    mount(Some(&root.target), &root.target, None::<&str>, MsFlags::MS_BIND | MsFlags::MS_REC, None::<&str>)
        .context("rootfs bind mount")?;

    // 4. 루트를 바꾼다. 이전 루트는 /.oldroot 에 걸린다
    let old_root = root.target.join(OLD_ROOT);
    fs::create_dir_all(&old_root).context(".oldroot 만들기")?;
    pivot_root(&root.target, &old_root).context("pivot_root")?;
    chdir("/").context("chdir /")?;

    // 5. /etc 파일. pivot_root 뒤에 써야 이미지 안의 심볼릭 링크가 호스트 경로로 풀리지 않는다
    for (path, content) in &root.files {
        if let Some(dir) = path.parent() {
            fs::create_dir_all(dir)?;
        }
        let _ = fs::remove_file(path); // 링크였다면 링크 자체를 지운다
        fs::write(path, content).with_context(|| format!("{} 쓰기", path.display()))?;
    }

    // 6. 이 PID 네임스페이스 기준의 procfs
    mount(
        Some("proc"),
        "/proc",
        Some("proc"),
        MsFlags::MS_NOSUID | MsFlags::MS_NODEV | MsFlags::MS_NOEXEC,
        None::<&str>,
    )
    .context("/proc 마운트")?;

    // 7. 최소한의 /dev. 장치 파일은 아직 붙어 있는 이전 루트에서 bind로 빌려 온다
    setup_dev().context("/dev 구성")?;

    // 8. 이전 루트를 떼어 내고 흔적을 지운다
    let old = format!("/{OLD_ROOT}");
    umount2(old.as_str(), MntFlags::MNT_DETACH).context("이전 루트 분리")?;
    fs::remove_dir(&old).context(".oldroot 지우기")?;
    Ok(())
}

fn setup_dev() -> Result<()> {
    mount(
        Some("tmpfs"),
        "/dev",
        Some("tmpfs"),
        MsFlags::MS_NOSUID | MsFlags::MS_STRICTATIME,
        Some("mode=755,size=65536k"),
    )?;
    for dev in DEVICES {
        let target = format!("/dev/{dev}");
        File::create(&target).with_context(|| format!("{target} 만들기"))?;
        let source = format!("/{OLD_ROOT}/dev/{dev}");
        mount(Some(source.as_str()), target.as_str(), None::<&str>, MsFlags::MS_BIND, None::<&str>)
            .with_context(|| format!("{target} bind"))?;
    }
    for (link, to) in [
        ("/dev/fd", "/proc/self/fd"),
        ("/dev/stdin", "/proc/self/fd/0"),
        ("/dev/stdout", "/proc/self/fd/1"),
        ("/dev/stderr", "/proc/self/fd/2"),
    ] {
        symlink(to, link).with_context(|| format!("{link} 링크"))?;
    }
    Ok(())
}

impl Security {
    fn new(add: &[String], drop: &[String], no_seccomp: bool) -> Result<Self> {
        let mut caps: CapsHashSet = DEFAULT_CAPS.into_iter().collect();
        for name in drop {
            if name.eq_ignore_ascii_case("ALL") {
                caps.clear();
            } else {
                caps.remove(&parse_cap(name)?);
            }
        }
        for name in add {
            caps.insert(parse_cap(name)?);
        }
        let seccomp = if no_seccomp { None } else { Some(seccomp_filter()?) };
        Ok(Security { caps, seccomp })
    }
}

/// "net_admin", "NET_ADMIN", "CAP_NET_ADMIN" 을 모두 받는다
fn parse_cap(name: &str) -> Result<Capability> {
    let upper = name.to_ascii_uppercase();
    let full = if upper.starts_with("CAP_") { upper } else { format!("CAP_{upper}") };
    full.parse().map_err(|_| anyhow!("알 수 없는 capability: {name}"))
}

/// 목록의 시스템 콜은 EPERM, 나머지는 허용하는 BPF 프로그램
fn seccomp_filter() -> Result<BpfProgram> {
    let rules: BTreeMap<i64, Vec<SeccompRule>> =
        BLOCKED_SYSCALLS.iter().map(|&(_, nr)| (nr, vec![])).collect();
    let filter = SeccompFilter::new(
        rules,
        SeccompAction::Allow,                        // 목록에 없으면
        SeccompAction::Errno(libc::EPERM as u32),    // 목록에 있으면
        std::env::consts::ARCH.try_into().context("seccomp 아키텍처")?,
    )
    .context("seccomp 필터 만들기")?;
    filter.try_into().context("seccomp BPF 컴파일")
}

/// exec 직전의 마지막 단계: 권한을 줄이고 시스템 콜을 막는다
fn lock_down(sec: &Security) -> Result<()> {
    // 1. bounding set: exec를 거쳐도 다시 얻을 수 없는 상한
    for cap in caps::runtime::thread_all_supported() {
        if !sec.caps.contains(&cap) {
            caps::drop(None, CapSet::Bounding, cap).with_context(|| format!("bounding에서 {cap} 빼기"))?;
        }
    }
    // 2. 지금 가진 권한도 같은 범위로. inheritable과 ambient는 비운다
    caps::clear(None, CapSet::Inheritable).context("inheritable 비우기")?;
    caps::clear(None, CapSet::Ambient).context("ambient 비우기")?;
    caps::set(None, CapSet::Effective, &sec.caps).context("effective 설정")?;
    caps::set(None, CapSet::Permitted, &sec.caps).context("permitted 설정")?;
    // 3. setuid 비트나 파일 capability로 권한을 다시 얻지 못하게
    prctl::set_no_new_privs().context("no_new_privs")?;
    // 4. 마지막에 seccomp. 이 뒤로는 막힌 시스템 콜을 부를 수 없다
    if let Some(bpf) = &sec.seccomp {
        seccompiler::apply_filter(bpf).context("seccomp 설치")?;
    }
    Ok(())
}

/// 성공하면 돌아오지 않는다. 돌아오면 127.
fn exec(p: &Program) -> isize {
    if let Err(e) = unsafe { signal(Signal::SIGPIPE, SigHandler::SigDfl) } {
        eprintln!("myctr: SIGPIPE 복원 실패: {e}");
        return 1;
    }
    let err = match &p.env {
        // 이미지: 이미지의 PATH로 찾고 이미지의 환경 변수만 넘긴다
        Some(env) => execve(&find_in_path(&p.argv[0], &p.path), &p.argv, env).unwrap_err(),
        // 호스트나 디렉터리 루트: 1장처럼 지금 환경 그대로
        None => execvp(&p.argv[0], &p.argv).unwrap_err(),
    };
    eprintln!("myctr: {}: {err}", p.argv[0].to_string_lossy());
    127
}

/// PATH의 디렉터리에서 실행 파일을 찾는다. 이름에 /가 있거나 못 찾으면 그대로 돌려준다.
/// execvp는 이 프로세스의 (호스트에서 물려받은) PATH를 쓰므로 직접 찾는다
fn find_in_path(name: &CStr, path: &str) -> CString {
    let bytes = name.to_bytes();
    if !bytes.contains(&b'/') {
        for dir in path.split(':').filter(|d| !d.is_empty()) {
            let mut candidate = dir.as_bytes().to_vec();
            candidate.push(b'/');
            candidate.extend_from_slice(bytes);
            let is_file = Path::new(OsStr::from_bytes(&candidate)).is_file();
            if let Ok(c) = CString::new(candidate) {
                if is_file && access(c.as_c_str(), AccessFlags::X_OK).is_ok() {
                    return c;
                }
            }
        }
    }
    name.to_owned()
}

/// PID 1로 남아 명령을 PID 2로 띄우고, 입양된 고아까지 거두다가
/// 명령이 끝나면 그 종료 코드로 끝난다.
fn mini_init(p: &Program) -> isize {
    let main_child = match unsafe { fork() } {
        Ok(ForkResult::Child) => unsafe { libc::_exit(exec(p) as i32) },
        Ok(ForkResult::Parent { child }) => child,
        Err(e) => {
            eprintln!("myctr-init: fork: {e}");
            return 1;
        }
    };
    loop {
        match waitpid(None, None) {
            Ok(WaitStatus::Exited(pid, code)) if pid == main_child => return code as isize,
            Ok(WaitStatus::Signaled(pid, sig, _)) if pid == main_child => return 128 + sig as isize,
            Ok(_) => continue,
            Err(Errno::EINTR) => continue,
            Err(e) => {
                eprintln!("myctr-init: waitpid: {e}");
                return 1;
            }
        }
    }
}

/// "alpine", "alpine:3.24", "nginx:alpine", "user/app:1.0"
struct Reference {
    repo: String,
    tag: String,
}

impl Reference {
    fn parse(s: &str) -> Result<Self> {
        let (name, tag) = match s.rsplit_once(':') {
            Some((n, t)) if !t.contains('/') => (n, t),
            _ => (s, "latest"),
        };
        if name.split('/').next().is_some_and(|first| first.contains('.') || first.contains(':')) {
            bail!("{s}: Docker Hub 이미지만 지원합니다 (레지스트리 주소 없이 써 주세요)");
        }
        let repo = if name.contains('/') { name.to_string() } else { format!("library/{name}") };
        Ok(Reference { repo, tag: tag.to_string() })
    }

    fn ref_path(&self) -> PathBuf {
        Path::new(STORE).join("refs").join(&self.repo).join(&self.tag)
    }
}

            .with_context(|| format!("{name}: {os}/{arch} 플랫폼이 없습니다"))?;
        println!("index  {} → {os}/{arch} {}", short(&digest), short(&d.digest));

    }

    println!("manifest {} ({})", short(&digest), manifest.media_type);

    // 2. config와 레이어 blob. 받으면서 sha256을 계산해 digest와 비교한다
    let config = manifest.config.as_ref().context("매니페스트에 config가 없습니다")?;
    fetch_blob(&r.repo, &config.digest, &token)?;
    for layer in &manifest.layers {
        fetch_blob(&r.repo, &layer.digest, &token)?;
        unpack_layer(layer)?;
    }

    // 3. 이름표는 마지막에 붙인다. 중간에 실패하면 이름이 생기지 않는다
    let ref_path = r.ref_path();
    fs::create_dir_all(ref_path.parent().unwrap())?;
    fs::write(&ref_path, &digest)?;
    println!("{}:{} → {}", r.repo, r.tag, short(&digest));
    load(&digest)
}

/// 로컬 이미지 목록
pub fn list() -> Result<()> {
    let refs = Path::new(STORE).join("refs");
    let mut found = Vec::new();
    walk_refs(&refs, &refs, &mut found)?;
    println!("{:<32} {:<14} {:>6}", "IMAGE", "MANIFEST", "LAYERS");
    for (name, digest) in found {
        let layers = read_manifest(&digest).map(|m| m.layers.len()).unwrap_or(0);
        println!("{name:<32} {:<14} {layers:>6}", short(&digest));
    }
    Ok(())
}

fn walk_refs(root: &Path, dir: &Path, out: &mut Vec<(String, String)>) -> Result<()> {
    let Ok(entries) = fs::read_dir(dir) else { return Ok(()) };
    for e in entries {
        let path = e?.path();
        if path.is_dir() {
            walk_refs(root, &path, out)?;
        } else {
            let rel = path.strip_prefix(root)?;
            let tag = rel.file_name().unwrap().to_string_lossy();
            let repo = rel.parent().unwrap().to_string_lossy();
            out.push((format!("{repo}:{tag}"), fs::read_to_string(&path)?.trim().to_string()));
        }
    }
    Ok(())
}

fn load(manifest_digest: &str) -> Result<Image> {
    let manifest = read_manifest(manifest_digest)?;
    let config = manifest.config.context("매니페스트에 config가 없습니다")?;
    let blob: ConfigBlob = serde_json::from_slice(&fs::read(blob_path(&config.digest)?)?)
        .context("이미지 config 해석")?;
    let layers = manifest
        .layers
        .iter()
        .map(|l| layer_path(&l.digest))
        .collect::<Result<_>>()?;
    Ok(Image { layers, config: blob.config })
}

fn read_manifest(digest: &str) -> Result<Manifest> {
    let bytes = fs::read(blob_path(digest)?).with_context(|| format!("매니페스트 {digest}"))?;
    serde_json::from_slice(&bytes).context("매니페스트 해석")
}

/// uname의 아키텍처 이름 → OCI 플랫폼 이름
fn platform_arch() -> &'static str {
    match std::env::consts::ARCH {
        "x86_64" => "amd64",
        "aarch64" => "arm64",
        other => other,
    }
}

fn short(digest: &str) -> &str {
    let hex = digest.strip_prefix("sha256:").unwrap_or(digest);
    &hex[..hex.len().min(12)]
}

/// "sha256:<64자리>" 만 받는다. 경로로 쓰이므로 다른 글자가 섞이면 안 된다
fn digest_hex(digest: &str) -> Result<&str> {
    match digest.strip_prefix("sha256:") {
        Some(h) if h.len() == 64 && h.bytes().all(|b| b.is_ascii_hexdigit()) => Ok(h),
        _ => bail!("지원하지 않는 digest: {digest}"),
    }
}

fn blob_path(digest: &str) -> Result<PathBuf> {
    Ok(Path::new(STORE).join("blobs/sha256").join(digest_hex(digest)?))
}

fn layer_path(digest: &str) -> Result<PathBuf> {
    Ok(Path::new(STORE).join("layers").join(digest_hex(digest)?))
}

/// 익명 pull 토큰 (Docker Hub)
fn token(repo: &str) -> Result<String> {
    #[derive(Deserialize)]
    struct Token {
        token: String,
    }
    let url = format!("{AUTH}&scope=repository:{repo}:pull");
    let t: Token = ureq::get(&url).call().context("토큰 요청")?.into_json()?;
    Ok(t.token)
}

/// 매니페스트를 받아 (digest, 원본 바이트)를 돌려준다
fn fetch_manifest(repo: &str, reference: &str, token: &str) -> Result<(String, Vec<u8>)> {
    let url = format!("{REGISTRY}/v2/{repo}/manifests/{reference}");
    let resp = ureq::get(&url)
        .set("Authorization", &format!("Bearer {token}"))
        .set("Accept", ACCEPT)
        .call()
        .with_context(|| format!("매니페스트 요청 {repo}:{reference}"))?;
    let mut bytes = Vec::new();
    resp.into_reader().read_to_end(&mut bytes)?;
    // digest는 원본 바이트의 sha256이다. 서버가 알려 주는 값을 믿지 않고 직접 계산한다
    let digest = format!("sha256:{:x}", Sha256::digest(&bytes));
    if reference.starts_with("sha256:") && reference != digest {
        bail!("매니페스트 digest 불일치: 요청 {reference}, 실제 {digest}");
    }
    Ok((digest, bytes))
}

fn store_blob(digest: &str, bytes: &[u8]) -> Result<()> {
    let path = blob_path(digest)?;
    fs::create_dir_all(path.parent().unwrap())?;
    fs::write(&path, bytes)?;
    Ok(())
}

/// blob을 받으며 sha256을 계산하고, 맞을 때만 제자리에 놓는다
fn fetch_blob(repo: &str, digest: &str, token: &str) -> Result<()> {
    let path = blob_path(digest)?;
    if path.exists() {
        println!("blob   {} 이미 있음", short(digest));
        return Ok(());
    }
    fs::create_dir_all(path.parent().unwrap())?;
    let url = format!("{REGISTRY}/v2/{repo}/blobs/{digest}");
    // 레지스트리는 CDN 주소로 리다이렉트한다. ureq는 다른 호스트로 갈 때 Authorization을 떼어 낸다
    let resp = ureq::get(&url)
        .set("Authorization", &format!("Bearer {token}"))
        .call()
        .with_context(|| format!("blob 요청 {digest}"))?;
    let tmp = path.with_extension("partial");
    let mut out = File::create(&tmp)?;
    let mut hasher = Sha256::new();
    let mut reader = resp.into_reader();
    let mut buf = vec![0u8; 64 * 1024];
    let mut total = 0u64;
    loop {
        let n = reader.read(&mut buf)?;
        if n == 0 {
            break;
        }
        hasher.update(&buf[..n]);
        out.write_all(&buf[..n])?;
        total += n as u64;
    }
    let actual = format!("sha256:{:x}", hasher.finalize());
    if actual != digest {
        let _ = fs::remove_file(&tmp);
        bail!("blob digest 불일치: 기대 {digest}, 실제 {actual}");
    }
    fs::rename(&tmp, &path)?;
    println!("blob   {} {:.1} MB 검증 완료", short(digest), total as f64 / 1e6);
    Ok(())
}

/// 레이어 tar를 풀어 둔다. OCI whiteout을 overlayfs 형식으로 바꾼다
fn unpack_layer(layer: &Descriptor) -> Result<()> {
    let dest = layer_path(&layer.digest)?;
    if dest.exists() {
        return Ok(());
    }
    let file = File::open(blob_path(&layer.digest)?)?;
    let reader: Box<dyn Read> = if layer.media_type.ends_with("gzip") {
        Box::new(GzDecoder::new(file))
    } else if layer.media_type.ends_with(".tar") || layer.media_type.ends_with("tar") {
        Box::new(file)
    } else {
        bail!("지원하지 않는 레이어 형식: {}", layer.media_type);
    };
    // 다 풀린 뒤에 이름을 바꿔, 반쯤 풀린 레이어가 쓰이지 않게 한다
    let tmp = dest.with_extension("partial");
    let _ = fs::remove_dir_all(&tmp);
    fs::create_dir_all(&tmp)?;

    let mut archive = tar::Archive::new(reader);
    archive.set_preserve_permissions(true);
    archive.set_preserve_ownerships(true);
    archive.set_unpack_xattrs(true);
    let mut whiteouts = 0;
    for entry in archive.entries()? {
        let mut entry = entry?;
        let path = entry.path()?.into_owned();
        let name = path.file_name().map(|n| n.to_string_lossy().into_owned()).unwrap_or_default();
        if name.starts_with(".wh.") {
            // whiteout 경로는 tar 크레이트의 경로 검사를 거치지 않으므로 직접 확인한다
            if !path.components().all(|c| matches!(c, Component::Normal(_) | Component::CurDir)) {
                bail!("잘못된 whiteout 경로: {}", path.display());
            }
            let dir = tmp.join(path.parent().unwrap_or(Path::new("")));
            fs::create_dir_all(&dir)?;
            if name == ".wh..wh..opq" {
                // 디렉터리 전체 가리기: 아래 레이어의 같은 디렉터리 내용을 보이지 않게
                set_opaque(&dir)?;
            } else {
                // 파일 하나 가리기: 같은 이름의 0:0 문자 장치
                let hidden = dir.join(&name[4..]);
                mknod(&hidden, SFlag::S_IFCHR, Mode::empty(), makedev(0, 0))
                    .with_context(|| format!("whiteout {}", hidden.display()))?;
            }
            whiteouts += 1;
            continue;
        }
        entry.unpack_in(&tmp).with_context(|| format!("{} 풀기", path.display()))?;
    }
    fs::rename(&tmp, &dest)?;
    println!("layer  {} 풀기 완료 (whiteout {whiteouts}개)", short(&layer.digest));
    Ok(())
}

fn set_opaque(dir: &Path) -> Result<()> {
    let path = CString::new(dir.as_os_str().as_bytes())?;
    let rc = unsafe {
        libc::setxattr(path.as_ptr(), c"trusted.overlay.opaque".as_ptr(), b"y".as_ptr().cast(), 1, 0)
    };
    if rc != 0 {
        return Err(io::Error::last_os_error()).with_context(|| format!("opaque {}", dir.display()));
    }
    Ok(())
}

11. 돌아보기와 다음 걸음

fork() 한 번에서 시작해 Docker의 런타임이 되었습니다. 지금 myctr가 컨테이너 하나를 만들 때 하는 일을 장별로 다시 적으면 이렇습니다.

장더한 것config.json에서
1fork · exec · wait, 종료 코드process.args
2clone, UTS·PID 네임스페이스, PID 1과 initlinux.namespaces, hostname
3마운트 네임스페이스, pivot_root, /proc·/devroot, mounts
4cgroup v2 자원 제한, OOMlinux.cgroupsPath, linux.resources
5user 네임스페이스, ID 매핑, 파이프 장벽linux.uidMappings (myctr OCI 모드는 미지원)
6네트워크 네임스페이스, veth, 브리지, NAT(Docker가 담당)
7capability, no_new_privs, seccompprocess.capabilities, linux.seccomp
8OCI 이미지, overlayfs, 이미지 설정(containerd가 담당, process.env·cwd)
9OCI CLI, create/start 분리, 상태전체

myctr에 없는 것 (runc와의 차이)

  • 터미널(docker run -t): console socket으로 pty 마스터 fd를 Unix 소켓의 SCM_RIGHTS로 넘겨야 합니다.
  • docker exec: 실행 중인 컨테이너의 네임스페이스들에 setns로 들어가 프로세스를 하나 더 만듭니다. PID 네임스페이스 때문에 setns 후 fork가 필요합니다(2장).
  • user 네임스페이스와 rootless: 5장의 코드를 OCI 모드와 rootfs에 합치는 일(5장 11절).
  • systemd cgroup 드라이버, cgroup v2 장치 제어(BPF), hooks, 체크포인트/복원(CRIU)

여기서 더 나아가고 싶다면 Rust로 쓰인 실제 런타임 youki의 소스를 이 코스의 장 순서대로 읽어 보세요. 거의 모든 함수가 "아, 그 장에서 한 그것"으로 보일 겁니다.

핵심 요약

  • OCI 런타임 명세는 bundle(config.json + rootfs)과 create·start·state·kill·delete CLI의 약속입니다. 이것만 지키면 Docker와 containerd가 어떤 런타임이든 부를 수 있습니다.
  • Docker는 features → create --bundle --pid-file → start → (kill 15 → kill 9) → delete → delete --force 순으로 부르고, 전역 --root·--log를 넘깁니다. 에러는 --log의 JSON으로 전달합니다.
  • create는 모든 준비를 마치고 exec.fifo에서 멈춘 init을 남기고 끝납니다. 그 사이에 Docker가 네트워크를 꾸미고, start가 fifo를 열어 실행시킵니다. init은 shim이 입양합니다.
  • 상태는 PID와 starttime으로 계산합니다(PID 재사용 대비). time 네임스페이스는 부모의 unshare로, cgroup 네임스페이스는 cgroup 배치 후 init의 unshare로 만듭니다.
  • mounts는 일반화된 루프로, bind의 읽기 전용은 다시 마운트로, maskedPaths·readonlyPaths는 pivot_root 뒤에 처리합니다.
  • Docker의 seccomp allow-list는 허용 필터와 errno 필터 두 개로 번역합니다. 같은 우선순위면 나중 필터의 값이 이겨 clone3가 ENOSYS가 됩니다.

확인 문제

myctr create가 끝난 직후, 컨테이너 init은 무엇을 하고 있나?
create는 네임스페이스·마운트·권한까지 끝낸 init을 fifo 앞에 세워 두고 끝납니다. start가 fifo를 읽기용으로 열어야 init이 풀려나 execve합니다.
init이 exec.fifo를 pivot_root 전에 O_PATH로 열어 두는 이유는?
상태 디렉터리는 호스트 쪽에 있습니다. 루트를 바꾸기 전에 fd로 잡아 두고, 나중에 /proc/self/fd/N을 쓰기용으로 다시 엽니다. 쓰기용으로 바로 열면 그 자리에서 막혀 버리므로 O_PATH로 엽니다.
config.json의 {"type": "time"}을 clone 플래그로 처리할 수 없는 이유는?
clone()은 flags의 하위 바이트를 종료 시그널로 씁니다. 그래서 time 네임스페이스는 unshare나 clone3로만 만들 수 있고, myctr는 부모가 unshare해 이후의 자식이 그 안에서 태어나게 합니다.
docker stop -t 2로 sleep 컨테이너를 멈췄더니 종료 코드가 137이었다. 왜인가?
2장의 PID 1 규칙 그대로입니다. 기록에도 kill ... 15 후 약 2초 뒤 kill ... 9가 보입니다. runc로 실행해도 같습니다.
PID만 기록하고 starttime을 기록하지 않으면 생길 수 있는 문제는?
PID는 재사용됩니다. /proc/<pid>/stat의 starttime까지 같아야 같은 프로세스입니다.
Docker 프로파일을 필터 두 개로 번역했을 때 clone3가 EPERM이 아니라 ENOSYS가 되는 이유는?
커널은 모든 필터를 실행해 우선순위가 가장 높은 판정을 고르고, 같으면 가장 최근에 설치한 필터의 판정을 씁니다. 그래서 errno 필터를 뒤에 설치합니다.
myctr가 모르는 명령(exec)을 받았을 때 clap 에러로 끝내면 안 되는 이유는?
실제로 Docker에는 "log.json을 열 수 없다"는 엉뚱한 메시지가 나왔습니다. 명령을 받아 직접 에러를 내고 로그에 남기자 "exec(docker exec)는 지원하지 않습니다"가 그대로 전달됐습니다.
