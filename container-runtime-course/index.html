컨테이너 런타임 만들기
Rust로 한 단계씩 쌓아 올리는 나만의 myctr

컨테이너는 마법이 아니라 평범한 Linux 프로세스에 커널 기능 몇 가지를 덧씌운 것입니다. 이 코스는 fork 한 번에서 출발해 네임스페이스, cgroup, 네트워크, seccomp, OCI 이미지까지 직접 구현하며 Docker 아래에서 무슨 일이 일어나는지 손으로 확인합니다. 코드는 여러분이 짭니다. 각 장은 개념 · 도식 · 시뮬레이터 · 구현 가이드 · 완료 기준을 제공합니다.
